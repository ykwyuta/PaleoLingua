## 現存最古のヒッタイト語文書

**アニッタ文書**は、クッシャラ（アナトリア中部の一都市）の王ピタナとその子アニッタの事績を語る文書で、現存するヒッタイト語文献の中でも最古の内容を伝えると考えられている。原文は古ヒッタイト語期に遡ると考えられるが、現存する写本の多くは後代（新ヒッタイト語期）に書き写されたものである。文書は、アニッタが周辺の都市国家（ネシャ、ハットゥシャなど）を征服していく過程を、一人称の語りに近い形式で記録している。

## ハットゥシャ征服と呪詛

アニッタ文書で特に有名なのが、アニッタがハットゥシャの街を征服し破壊した後に残したとされる**呪詛の言葉**である。アニッタはこの街を再建する者に対して、天候神の怒りが下ることを宣言したと伝えられている。

以下は、この呪詛の趣旨を伝える定型的な言い回しを基に、学習用に単純化した例文である（特定の1行の逐語引用ではなく、テキストの内容を要約的に示す文である点に注意されたい）。

```
ku-iš-wa a-pé-e-el EGIR-an LUGAL-uš ki-ša-ri
クイシュワ・アペール・エゲラン・ルガルウシュ・キシャリ
誰か（引用）-それ（属格）後で-王（主格）-なる-3単現（中動態）
「誰であれ、彼の後に王となる者は」

nu-wa URU-an EGIR-pa a-pí-ya i-ya-zi
ヌワ・ウルアン・エゲルパ・アピヤ・イヤツィ
そして（引用）-都市（対格）再び-そこに-作る-3単現
「そして、その都市を再びそこに建てるならば」

nu-wa-an-kán dU-aš tar-ḫu-i-li-uš wa-al-aḫ-du
ヌワンカン・タルフンナシュ・タルフイリウシュ・ワラフドゥ
そして（引用）-彼を-（局所小詞）-天候神-力強き者-打て-命令法3単
「（天の）力強き天候神が彼を打ちますように」
```

## 語彙・文法のポイント

- **ki-ša-ri**「なる」は[中動態](/hittite/grammar/mediopassive-voice/)の3人称単数現在形で、[デポネント動詞](/hittite/grammar/mediopassive-voice/)としてよく用いられる kiš-「なる、起こる」の活用例である。
- **-wa**（引用小詞）は[接語連鎖](/hittite/grammar/enclitic-pronoun-chain/)で説明した、直接話法・引用を示す接語であり、この一節全体がアニッタ自身の「発言」として引用されていることを示す。
- **dU-aš**（天候神が）に見える限定符 D は、[限定符](/hittite/script-and-phonology/determinatives-in-hittite/)で説明したとおり、神名の前に置かれ発音されない記号である。

## 呪詛文書としての意義

このような「都市を再建する者への呪い」は、古代西アジアの碑文文学に広く見られる修辞的な型であり、征服者が自らの勝利を永続的なものとして記念する常套手段の一つであった。アニッタ文書のこの一節は、ヒッタイト王国が後にまさにこのハットゥシャを新たな首都として選んだという歴史的な経緯と合わせて読むと、興味深い逆説を示す文書としても知られている。
