## 能動態と中動態

ヒッタイト語の動詞は、[mi活用・hi活用](/hittite/grammar/mi-conjugation-hi-conjugation/)という活用の種類とは別に、**態（ヴォイス）**の区別も持つ。態には**能動態（active）**と**中動態（mediopassive）**の2つがあり、中動態はその名のとおり、印欧諸語に広く見られる「中動態」（動作の結果が主語自身に及ぶことを示す態）と「受動態」の両方の機能を兼ねている。

## 中動態の人称語尾

中動態は、能動態とは異なる専用の人称語尾一式を持つ。

| 人称・数 | 現在形（中動態） | 過去形（中動態） |
|---|---|---|
| 1人称単数 | -ḫa(ri) | -ḫat(i) |
| 2人称単数 | -ta(ri) | -tat(i) |
| 3人称単数 | -a(ri) / -ta(ri) | -at(i) / -tat(i) |
| 3人称複数 | -anta(ri) | -antat(i) |

```
ki-ša-ri
キシャリ
なる／起こる-3単現（中動態）
「（それは）起こる、〜になる」
```

## 受動的な意味を表す中動態

中動態は、対応する能動態動詞の目的語を主語に昇格させる、受動態に近い意味で使われることがある。

```
能動態：kuen-zi「彼は殺す」
中動態：kunna-ri「彼／それは殺される」
```

このように、能動文の目的語であったものが、中動態の文では主語として現れ、動作主（誰が殺したか）は必ずしも明示されない、という受動文に典型的な構文上のふるまいを見せる。

## 中動態でしか現れない動詞（デポネント動詞）

ヒッタイト語には、対応する能動態の形を持たず、常に中動態の形でのみ現れる動詞がある。これは古典語文法でいう「デポネント動詞」に相当する。たとえば「なる、起こる」を意味する kiš- は、通常中動態の形（kišari など）でのみ用いられ、対応する能動態の活用形は実質的に用いられない。このような動詞では、中動態はもはや「受動」や「動作が自分自身に及ぶ」という積極的な意味を持たず、単にその動詞の基本的な活用形として定着していると考えられる。

## 印欧語比較言語学における位置づけ

能動態・中動態という2分法自体は、古代ギリシア語やサンスクリットにも見られる印欧祖語以来の古い体系の反映と考えられている。ヒッタイト語の中動態の語尾（-ḫa, -ta, -a など）は、これらの言語の中動態語尾と系統的に対応すると考えられており、[mi活用とhi活用](/hittite/grammar/mi-conjugation-hi-conjugation/)の対立とあわせて、ヒッタイト語の動詞体系が印欧祖語の複雑な形態論を独自のかたちで受け継いでいることを示す証拠の一つとなっている。
