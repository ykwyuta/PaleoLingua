## 形容詞は名詞の後ろに置く

古エジプト語の形容詞は、修飾する名詞の性・数に一致し、かつ**名詞の後**に置かれる。これは日本語や英語（「偉大な神」great god）とは逆の語順で、フランス語（dieu grand）などロマンス諸語に近い発想である。

<p class="hieroglyph">𓈖𓍿𓂋𓂝𓄿</p>

```
nṯr ꜥꜣ
ネチェル・アア
神・偉大な
「偉大な神」（直訳：神・偉大な）
```

このように「名詞＋形容詞」の語順が基本であることをまず押さえておこう。形容詞は名詞と同じく性・数の一致（[名詞の性と数](/old-egyptian/grammar/noun-gender-number/)を参照）を受けるため、女性名詞・複数名詞を修飾するときはそれぞれ -t、-w/-wt などの語尾が形容詞側にも現れる。

## ニスバ形容詞：名詞から形容詞を作る -y

エジプト語には、名詞（特に地名や普通名詞）に接尾辞 **-y** を付けて「〜の、〜に属する、〜に関する」という意味の形容詞を派生させる、生産的な仕組みがある。これを**ニスバ形容詞**（nisbe adjective）と呼ぶ。この呼び方はアラビア語文法の「ニスバ」（nisbah、同じく名詞に -ī を付けて関係形容詞を作る仕組み）にちなむもので、同じアフロ・アジア語族に属するエジプト語とアラビア語のあいだに見られる興味深い類型的並行例のひとつである。

たとえば「民、人々」を意味する **rmṯ** に -y を付けると、「人に属する、人間の」といった意味あいの形容詞的な形を作ることができる（これは -y 接尾辞の生産性を示す一般的なパターンとして挙げるもので、特定の1語だけを暗記する必要はない）。

<p class="hieroglyph">𓂋𓅓𓍿</p>

```
rmṯ
レメチュ
「民、人々」
```

<p class="hieroglyph">𓂋𓅓𓍿𓇌</p>

```
rmṯy
レメチイ
rmṯ（人々）+ -y（ニスバ接尾辞）
「人間の、人に属する」（-y 接尾辞の使い方を示す例）
```

## ニスバ形容詞は名詞にもなる

ニスバ形容詞のもう一つの重要な特徴は、それ自体が独立した**名詞**としても使われる点である。とりわけ地名から作られたニスバは「〜出身の人」「〜の住人」という職業・民族・出身を表す名詞になり、また役職名・専門職名を作る場合にも同じ -y 接尾辞のパターンが用いられる。つまりニスバ形容詞は「形容詞としての用法」と「名詞化した用法」の両方を持つ、エジプト語の語形成の中でも特に重要な仕組みである。
