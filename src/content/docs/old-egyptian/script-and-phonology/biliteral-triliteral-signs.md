## 単子音記号だけではない

前の記事「[単子音記号：ヒエログリフの「アルファベット」24字](/old-egyptian/script-and-phonology/uniliteral-signs-alphabet/)」では、1つの子音だけを表す24の単子音記号を見た。しかしヒエログリフの表音文字にはこれ以外にも、**2つの子音の並びをまとめて表す二子音記号（biliteral sign）**と、**3つの子音の並びをまとめて表す三子音記号（triliteral sign）**が数多く存在する。これらを使うと、単子音記号を1字ずつ並べるよりも短く単語を綴ることができる。

## 二子音記号の例：nfr（良い、美しい）

もっとも有名な二子音記号の1つが、「良い、美しい、完全な、若い」を意味する nfr である。この記号1字だけで n・f・r という2つではなく3つの子音を表すが（厳密には三子音記号に分類されることもある。伝統的にエジプト学では nfr を代表的な複子音記号の例として扱う）、単独でも意味の通じる重要な語として頻出する。

<p class="hieroglyph">𓄤</p>

```
nfr
ネフェル
良い、美しい、完全な、若い（複数の子音をまとめて表す記号1字）
```

## 音声補完（フォネティック・コンプリメント）

書記官は、二子音記号や三子音記号を使ったとき、読み手が正しく読めるように、記号が表す子音の一部を**単子音記号でもう一度重ねて書く**ことがよくあった。これを**音声補完（フォネティック・コンプリメント、phonetic complement）**と呼ぶ。冗長ではあるが、読みの確認や美的なバランスのために好んで用いられた。nfr の場合、しばしば末尾の f と r を単子音記号で重ねて書く綴りが見られる。

<p class="hieroglyph">𓄤𓆑𓂋</p>

```
nfr-f-r
ネフェル
良い、美しい（二子音記号 nfr ＋ 音声補完 f・r）
```

このように f と r の音は nfr の記号の中にすでに含まれているにもかかわらず、単子音記号 𓆑（f）と 𓂋（r）が「念押し」として重複して添えられている。これは日本語の送り仮名が漢字の読みを補助するのにどこか似た発想と言えるだろう。

## 三子音記号（あるいは複数記号による三子音語根）

3つの子音をまとめて表す専用の三子音記号も存在するが、多くの三子音語根は専用の1字を持たず、単子音記号を組み合わせて綴られる。たとえば「言葉、話す、杖」を意味する mdw（「神の言葉」mdw-nṯr はヒエログリフそのものを指す表現としても知られる）は、専用の三子音記号を持たないため、単子音記号 m・d・w を並べて綴られる。

<p class="hieroglyph">𓅓𓂧𓅱</p>

```
mdw
メドゥ
言葉、話す、杖（単子音記号 m + d + w による綴り）
```

このように、専用の二・三子音記号を持つ語根と、単子音記号の組み合わせに頼る語根が混在している点も、ヒエログリフを読むうえで押さえておきたいポイントである。
