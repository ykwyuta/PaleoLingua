## 2つの基本的な指示代名詞

ヒッタイト語には、話し手からの距離（近称・遠称）を区別する指示代名詞が複数存在するが、中心となるのは次の2つである。

- **kā-**：「これ、この」。話し手に近いもの、直前の文脈で話題になったばかりのものを指す近称の指示代名詞。
- **apā-**：「それ、あれ、その」。話し手から離れたもの、または既出の文脈を指し示す遠称・照応的な指示代名詞。

これらは名詞と同様に性（共通性・中性）と格に応じて語形変化する。

## 具体例

```
kā-aš an-tu-uḫ-ša-aš
カーシュ・アントゥフシャシュ
これ（主格）人（主格）
「この人は」

a-pa-a-aš LUGAL-uš
アパーアシュ・ルガルウシュ
それ（主格）王（主格）
「あの王は」（既出の王を指す）
```

## apā- が果たすもう一つの役割：3人称代名詞の代用

ヒッタイト語の大きな特徴の一つは、英語の he/she/it やラテン語の is/ea/id に相当する**独立した3人称人称代名詞を持たない**ことである。その代わりに、遠称・照応の指示代名詞 apā- が、文脈上「彼、彼女、それ」を指す3人称代名詞としての役割を兼ねている。

```
a-pa-a-aš pa-it
アパーアシュ・パイト
それ／彼（主格）行く-3単過
「彼（その人）は行った」
```

上の例のように、apā- は「その（既出の）人・物」という指示代名詞本来の意味と、「彼・彼女・それ」という3人称代名詞的な用法との間で、文脈に応じて連続的に機能する。この二重の役割は、指示代名詞が人称代名詞へと文法化していく、言語変化の一般的な傾向の一例としても興味深い。

## 接語代名詞との違い

[接語代名詞連鎖](/hittite/grammar/enclitic-pronoun-chain/)で扱った -mu「私に」、-at「それを」などの接語代名詞は、それ自体で独立して文頭に立つことができない。これに対し、kā- と apā- は独立した語として文中の任意の位置に置くことができ、強調したい場合や、接語だけでは指示対象が曖昧になる場合に用いられる。
