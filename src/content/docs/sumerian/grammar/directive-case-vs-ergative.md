## 同じ「-e」が2つの顔を持つ

[格接尾辞の一覧](/sumerian/grammar/case-suffixes-overview/)の記事で触れたとおり、シュメール語には見た目がまったく同じ `-e` という接尾辞が2種類存在する。一つは[能格・絶対格](/sumerian/grammar/sumerian-ergative/)の記事で見た「能格」であり、もう一つは「向格（directive、処格2とも呼ばれる）」である。両者は語形が同一であるため、学習者を混乱させやすい代表的なポイントである。

| 用法 | 主に付く名詞 | 意味 |
|---|---|---|
| 能格 | 動作主（主に有生・人や神） | 他動詞の主語であることを示す |
| 向格 | 無生物 | 「〜に向かって」「〜に接して」という方向・接触点を示す |

## 能格の -e：動作主を示す

```
𒈗𒂊     𒂍     𒈬𒁺
lugal-e  e2   mu-du3
ルガル・エ エ   ム・ドゥ
王-能格   家   彼が建てた
```

「王が家を建てた」。`lugal`（王）は他動詞 `du3`（建てる）の動作主であり、有生名詞に付く能格の `-e` を伴う。

## 向格の -e：無生物への方向・接触

```
𒂍𒂊
e2-e
エ・エ
家-向格
「家に（向かって）、家に接して」
```

向格の `-e` は、`igi...du8`（〜を見る、直訳「〜に目を開く」）のように、無生物の対象に対して「向かう」「接する」という空間的な関係を表す動詞とともに現れる。人や神など有生の対象には基本的に使われない点が、能格との大きな違いである。

## 処格 -a との比較

同じ「家」でも、格接尾辞によって空間的な意味合いが変わる。

```
𒂍𒀀
e2-a
エ・ア
家-処格
「家の中で」（内部にいることを表す）
```

処格 `-a` が「（内部）において」という静的な位置を表すのに対し、向格 `-e` は「〜に向かって・接して」という接触点や方向性を表す点で使い分けられる（[与格・終端格・処格ほか](/sumerian/grammar/dative-terminative-locative/)も参照）。

## 見分け方のコツ

`-e` を見たときにどちらの用法か判断する手がかりは、その名詞が有生か無生か、そして文中でその名詞がどんな役割（動作主か、場所・対象か）を担っているかである。

| 手がかり | 能格 | 向格 |
|---|---|---|
| 名詞の性質 | 有生（人・神など）が多い | 無生物 |
| 文中の役割 | 他動詞の動作主 | 方向・接触の対象 |
