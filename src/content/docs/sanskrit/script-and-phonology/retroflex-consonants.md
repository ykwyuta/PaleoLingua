## そり舌音とは何か

サンスクリット語の伝統的な音声学では、そり舌子音は**ムールダニヤ（मूर्धन्य mūrdhanya、「頭頂の」の意）**と呼ばれる。これは舌先を口蓋の奥、歯茎よりさらに後方（硬口蓋の前部）に反り返らせて（カールさせて）調音することに由来する名称である。英語の音声学では「retroflex（反舌音）」と呼ばれ、日本語では「そり舌音」「反舌音」などと訳される。

サンスクリット語のそり舌系列は、[ヴァルガ体系](/sanskrit/script-and-phonology/sanskrit-phoneme-inventory/)の中で独立した1行を占める。

| デーヴァナーガリー | IAST | 説明 |
|---|---|---|
| ट | ṭ | 無声無気そり舌閉鎖音 |
| ठ | ṭh | 無声有気そり舌閉鎖音 |
| ड | ḍ | 有声無気そり舌閉鎖音 |
| ढ | ḍh | 有声有気そり舌閉鎖音 |
| ण | ṇ | そり舌鼻音 |
| ष | ṣ | そり舌歯擦音（閉鎖音の系列とは別枠） |
| ऌ | ḷ | 母音的なそり舌側面音（ヴェーダ語に多い。ḍの弱化形として現れることもある） |

## 歯音との対比

そり舌音は、[歯音系列](/sanskrit/script-and-phonology/sanskrit-phoneme-inventory/)（t, th, d, dh, n）と明確に対立する独立した音素である。

| 歯音 | そり舌音 | 対立例 |
|---|---|---|
| त tan（「伸ばす」語根 √tan） | ट taṭa「岸、崖」 | 語頭子音の位置で最小対立をなす |
| दान dāna「布施」 | डाल ḍāla（俗語・方言的な語に多い） | dとḍの対立 |

歯音は上の前歯の裏に舌先を当てて調音する（IPAでいう歯音 [t̪] に近い）のに対し、そり舌音は舌先を口蓋に向けて反り返らせて調音する。この2系列を耳と口の両方で区別できるようになることが、サンスクリット語の発音習得の大きな山場の一つである。

## そり舌音の起源

そり舌音の起源については、大きく2つの経路が指摘されている。

1. **サンディ（連声）による派生**：歯音の n や s が、直前または直後の r, ṛ, ṣ などのそり舌的な音の影響を受けて、そり舌音 ṇ や ṣ に変化する現象（レトロフレクション・サンディ、[ヌ音法則（न-त्व niṣedha）](/sanskrit/script-and-phonology/sandhi-external-internal/)として文法学で扱われる）。これは印欧祖語の段階には存在しなかった、インド・アーリア語内部での音韻変化と考えられる。
2. **基層言語（インド在来言語）からの影響**：ドラヴィダ語族や他の南アジア在来の言語には、もともとそり舌音が音韻対立として存在していたと考えられており、インド・アーリア語話者が南アジアに進出する過程で、これらの言語との言語接触（バイリンガリズムや基層の影響）を通じてそり舌音がインド・アーリア語の音韻体系に定着した、という仮説が広く支持されている。

実際には、この2つの要因は排他的ではなく、内的なサンディによる派生が引き金となった変化が、基層言語との接触によって音素として定着・拡張したとする複合的な説明が有力である。

## インド言語圏（Sprachbund）の指標としてのそり舌音

そり舌音の存在は、系統の異なる南アジアの諸言語（インド・アーリア語派、ドラヴィダ語族、ムンダ語族など）に共通して見られる特徴の一つであり、**インド言語圏（South Asian linguistic area / Sprachbund）**を定義する代表的な指標としてしばしば引用される。つまり、そり舌音の広がりは単一の語族内の系統関係ではなく、地理的に隣接する言語同士が長期の接触を通じて音韻特徴を共有するに至った「地域的類型論」の典型例なのである。この点は、[サンディ（連声）](/sanskrit/script-and-phonology/sandhi-external-internal/)の複雑な規則とあわせて、サンスクリット語の音韻論を南アジアという地理的文脈の中に位置づける重要な視点を与えてくれる。
