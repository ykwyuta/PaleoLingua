## アッカド語の基礎データ

アッカド語（Akkadian、現地語で *akkadûm*）は、古代メソポタミア（現在のイラクを中心とする地域）で話され、**楔形文字で記録された最古級の文献言語のひとつ**である。セム語族の中で最も古くから文字資料が残る言語であり、シュメール語に代わって古代オリエント世界の主要な書記言語となった。

| 項目 | 内容 |
|---|---|
| 話された地域 | メソポタミア（現在のイラク、シリア北東部一帯）。南部のバビロニアと北部のアッシリアの2大地域 |
| 文字記録の期間 | 前2350年頃〜西暦1世紀頃（天文学関連文書を最後に楔形文字での使用が途絶える） |
| 系統 | アフロ・アジア語族セム語派の東セム語群（西セム語群のヘブライ語・アラム語・アラビア語などとは別枝） |
| 文字 | 楔形文字（[シュメール語から借用](/akkadian/script-and-phonology/cuneiform-akkadian-writing-system/)した音節文字＋シュメログラム＋限定符） |
| 基本語順 | SOV（主語－目的語－動詞）。セム語族としては珍しい語順で、シュメール語との長期の言語接触が一因とされる |
| 方言・時代区分 | 大きくバビロニア方言群とアッシリア方言群に分かれ、それぞれ複数の時代段階を持つ（[詳細記事を参照](/akkadian/script-and-phonology/akkadian-dialects-and-periods/)） |
| 発見・解読 | 19世紀、ヘンリー・ローリンソンらによるベヒストゥン碑文（古代ペルシア語・エラム語・バビロニア語の三言語碑文）の研究を通じて解読が進んだ |

## セム語族の中の位置づけ

アッカド語は、アラビア語やヘブライ語などが属する**セム語族**の一員でありながら、その中でも独立した**東セム語群**を形成する（もう一つの東セム語として、シリアのエブラ遺跡から出土したエブラ語が知られる）。ヘブライ語・アラム語・アラビア語などの**西セム語群**とは、文字が生まれるはるか以前に分岐したと考えられている。

アッカド語が西セム語群の言語と大きく異なる点として、次のような特徴が挙げられる。

- 基本語順が**SOV**（動詞文末）である点。多くの西セム語族は基本的にVSO（動詞－主語－目的語）型の語順を持つが、アッカド語ではシュメール語（膠着的でやはり動詞文末型）との数百年にわたる接触の結果、語順がシュメール語型に近づいたと考えられている。
- 名詞の格変化に**ミメーション**（語末の -m）を伴う点（例：主格 *šarrum*、属格 *šarrim*、対格 *šarram*）。
- 楔形文字という、本来セム語族の音韻構造向けに作られていない文字体系を採用している点（詳しくは[アッカド楔形文字の書記体系](/akkadian/script-and-phonology/cuneiform-akkadian-writing-system/)を参照）。

## なぜアッカド語を学ぶのか

アッカド語で書かれた楔形文字文書は、現存する古代文献の中でも群を抜いて量が多く、内容も多岐にわたる。

- **法**：『ハンムラビ法典』をはじめとする法典・裁判記録・契約文書。
- **神話・文学**：『ギルガメシュ叙事詩』『エヌマ・エリシュ（創世叙事詩）』などの物語文学。
- **書簡**：アマルナ文書（エジプトと近東諸国の外交書簡）、古アッシリア商人の商業書簡など、当時の国際関係や経済活動を生々しく伝える資料。
- **行政・経済文書**：神殿・王宮の会計記録、契約書、勅令など、日常生活の実態を伝える膨大な資料群。

さらに、アッカド語は前2千年紀には東地中海世界全体の**外交共通語（リングワ・フランカ）**としても用いられ、エジプトの王やヒッタイトの王も互いにアッカド語で書簡をやり取りした。このため、アッカド語を学ぶことは、古代オリエント世界の政治・経済・宗教・文学のほぼすべての側面にアクセスする鍵となる。

## 発見と解読

アッカド語（バビロニア語・アッシリア語）の解読は、古代ペルシア語の解読と並行して進んだ19世紀言語学史上の一大成果である。イラン西部のベヒストゥン山には、アケメネス朝ペルシアの王ダレイオス1世の事績を**古代ペルシア語・エラム語・バビロニア語（アッカド語）**の3言語で刻んだ碑文があり、イギリスの軍人・学者ヘンリー・ローリンソンが命がけでこの碑文を模写・収集したことが解読の突破口となった。まず比較的単純な文字体系を持つ古代ペルシア語の解読が進み、その成果を手がかりに、アイルランドの聖職者エドワード・ヒンクスやフランスの学者ジュール・オッペール、ローリンソン自身らが1850年代を通じてバビロニア楔形文字（アッカド語）の解読を進めた。1857年には、新たに発見されたアッシリア王ティグラト・ピレセル1世の碑文を4人の学者が独立に翻訳し、その内容が一致することを検証するという公開実験が王立アジア協会で行われ、アッカド語の解読が確かなものであることが広く認められた。

以下は、アッカド語の姿を実際に見てみるための基本語彙である。

## アッカド語の名前の由来

「アッカド語」という呼び名は、紀元前24世紀頃にサルゴン（Sargon of Akkad）が築いたアッカド王国の都**アッカド（Akkad／Agade）**に由来する。アッカド語話者自身は自らの言葉を *akkadûm*（「アッカドの（言葉）」）と呼び、シュメール語（*šumerûm*、あるいはシュメール語では *eme-gir₁₅*）と区別していた。
