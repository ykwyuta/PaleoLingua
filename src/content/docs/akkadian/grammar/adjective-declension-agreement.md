## 形容詞は名詞と一致する

アッカド語の形容詞は、修飾する名詞と**性（男性／女性）・数（単数／複数）・格（主格／属格／対格）**において一致する。つまり形容詞自体も名詞と同様に語尾変化（格変化）する語類であり、日本語の形容詞のように無変化のまま名詞にかぶさるわけではない。

## 単数の格変化：名詞とほぼ同じパターン

形容詞の単数の格語尾は、基本的に名詞の単数格語尾（主格 `-um`、属格 `-im`、対格 `-am`）と同じ形を取る。`šarrum`（王、男性名詞）と形容詞 `dannum`（強い、力強い）を組み合わせた「力強い王」という句で見てみよう。

<p class="cuneiform">𒊭𒅈𒊒𒌝 𒁕𒀭𒉡𒌝</p>

```
šarrum   dannum
シャ・アル・ル・ウム ダ・アン・ヌ・ウム
王-主格   強い-主格（男性単数）
「力強い王」
```

`šarrum` 𒊭𒅈𒊒𒌝（王が、主格）にも、`dannum` 𒁕𒀭𒉡𒌝（強い、主格）にも同じ `-um` 語尾が付いており、両者が性・数・格で一致していることが一目で分かる。この語順（名詞→形容詞）はアッカド語の名詞句の基本パターンで、形容詞は修飾する名詞の直後に置かれる。

## 複数形は名詞と異なるパターンを取る

単数では名詞と形容詞がほぼ同じ格語尾を共有するのに対し、**複数形では形容詞は名詞とは異なる独自の語尾**を取る。名詞の男性複数主格が `-ū` であるのに対し、形容詞の男性複数はしばしば `-ūtum` という専用の語尾（女性複数形に由来するとされる集合的な形）を取る。

| 語 | 品詞 | 単数（主格） | 複数（主格） |
|---|---|---|---|
| šarrum「王」 | 名詞 | -um | -ū |
| dannum「強い」 | 形容詞 | -um | -ūtum |

<p class="cuneiform">𒊭𒅈𒊒 𒁕𒀭𒉡𒌈</p>

```
šarrū    dannūtum
シャ・アル・ル ダ・アン・ヌ・トゥム
王たち-主格（複数） 強い-主格（男性複数）
「力強い王たち」
```

このように、アッカド語の形容詞の格変化は名詞の格変化と「似ているが同一ではない」体系であり、特に複数形でその違いがはっきり現れる。学習の初期段階では、単数形の類似に引きずられて複数形も名詞と同じだと思い込みやすいので注意したい。

## 限定用法と述語用法

形容詞には、名詞を直接修飾する**限定用法**（attributive、「力強い王」のように名詞句の一部を成す用法）と、「王は力強い」のように文の述語となる**述語用法**（predicative）がある。アッカド語では、この2つの用法で形が異なる点が重要である。

- 限定用法：上で見たように、形容詞は名詞と同じ格語尾を取って名詞句に組み込まれる（`šarrum dannum` 「力強い王」）。
- 述語用法：アッカド語では形容詞の述語的な用法は、通常の格変化形ではなく、[状態動詞形（永続相・スタティヴ）](/akkadian/grammar/stative-permansive/)と呼ばれる特別な形で表される。たとえば「王は強い」は `šarrum dan`（王 + 強い＝dannumの語根から作られたスタティヴ形）のように表現される。

<p class="cuneiform">𒊭𒅈𒊒𒌝 𒆗</p>

```
šarrum   dan
シャ・アル・ル・ウム ダン
王-主格   強い（スタティヴ・3人称男性単数）
「王は強い」
```

このように、同じ「強い」という語根から、限定用法では格変化した形容詞形（`dannum`）、述語用法ではスタティヴ形（`dan`）という異なる形が使われる。スタティヴ形の詳しいパラダイムと文法的性格については[状態動詞形（永続相）](/akkadian/grammar/stative-permansive/)の記事で扱う。
