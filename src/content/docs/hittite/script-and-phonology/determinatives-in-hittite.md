## 限定符とは何か

**限定符（決定詞、determinative）**は、それ自体は発音されないが、直後（まれに直前）に来る語がどのような意味カテゴリーに属するかを読者に示す記号である。楔形文字を用いる多くの言語と同様、ヒッタイト語のテキストにも限定符が豊富に用いられ、翻字では上付き文字で示される。限定符はシュメール語の単語に由来するものが多く、その大半はシュメログラムとしての性格も併せ持つ。

## 主な限定符一覧

| 限定符 | 由来・意味 | 置かれる位置 | 例 |
|---|---|---|---|
| D | シュメール語 DINGIR「神」 | 神名の前 | ᴰIŠTAR「女神イシュタル」 |
| URU | シュメール語「都市」 | 地名の前 | ᵁᴿᵁḪattuša「ハットゥシャ市」 |
| KUR | シュメール語「山、国」 | 国名の前 | ᴷᵁᴿḪatti「ハッティの国」 |
| ᴵ（またはᵐ） | 人名の印 | 男性の人名の前 | ᴵMuršili「ムルシリ（王名）」 |
| MUNUS | シュメール語「女性」 | 女性の人名の前 | ᴹᵁᴺᵁˢPuduḫepa「プドゥヘパ（王妃名）」 |
| GIŠ | シュメール語「木」 | 木製の器物名の前 | ᴳᴵŠGU.ZA「（木製の）玉座」 |
| DUG | シュメール語「壺、容器」 | 土器・容器名の前 | ᴰᵁᴳḫupuwai-「壺の一種」 |

## 位置と発音されない性質

限定符の多くは名詞の**前**に置かれるが、URU（都市名）のように語の**後ろ**に置かれる用法が見られる限定符もある（ただし前置される用法もあり、書記官・時代によって揺れがある）。限定符は文法的な役割語（格語尾など）とは異なり、それ自体が音として発音されたとは考えられていない。あくまで読者・書記官にとっての「注釈」「ラベル」として機能した視覚的な補助記号である。

```
ᴵmu-ur-ši-li-iš
ムルシリシュ
（人名限定符）ムルシリ-主格
「ムルシリ（王）は」
```

上の例で ᴵ は「これは男性の人名である」ということを示すラベルであり、翻訳・音読の際には読み飛ばされる。

## 限定符が果たす実用的な役割

多言語混在・多文書量の官僚制の中で、限定符は読み手が語を素早く分類する助けとなった。特に人名・神名・地名は、ヒッタイト語固有の語だけでなく、フルリ語・ルウィ語・アッカド語など多様な言語に由来する固有名詞が入り混じるため、限定符によって「これは神の名前だ」「これは都市の名前だ」と一目で識別できることは、複雑な行政文書・条約文書を扱う書記官にとって大きな助けとなった。
