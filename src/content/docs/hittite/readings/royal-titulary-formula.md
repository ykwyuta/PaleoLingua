## 個人名から称号へ：タバルナとタワナンナ

ヒッタイトの公文書・条約・碑文の冒頭には、王の名に添えて一連の定型的な称号が並ぶ。その代表格が **タバルナ（Tabarna、Labarna とも）**である。この語はもともと、ヒッタイト古王国の初代王とされる**ラバルナ**個人の名前であったが、後代には特定の個人名ではなく、ヒッタイトの王一般を指す**称号**として定着した。同様に、王妃の称号 **タワナンナ（Tawananna）**も、もともとある王妃の個人名であったものが、後代の王妃全般を指す称号に転じたと考えられている。これは、エジプトの「ファラオ」やローマの「カエサル」が、特定の個人名から一般的な称号へと転じたのと類似した現象である。

## 大王・英雄という称号

タバルナに続いて、王の称号にはしばしば次のような要素が組み合わされる。

```
LUGAL.GAL LUGAL KUR URUḪa-at-ti UR.SAG
ルガル・ガル・ルガル・クル・ウルハッティ・ウルサグ
王・大いなる（大王）　王　国　ハッティ　英雄
「大王、ハッティの国の王、英雄」
```

**LUGAL.GAL**「大王」は、周辺の対等な大国（エジプト、アッシリア、バビロニアなど）の王と自らを同格に位置づける外交上の称号であり、[カデシュの和平条約](/hittite/readings/treaty-of-kadesh-bilingual/)のような対等な大国間の条約で特に重視された。**UR.SAG**「英雄」は、王の武勇を讃える称号として、多くの碑文・条約の前文に現れる。

## 「太陽である我が身」という自称

ヒッタイトの王が自らを指して用いる印象的な自称表現に **DUTU-ŠI**（アッカドグラムで「わが太陽」を意味する）がある。

```
DUTU-ŠI-ma-za a-pu-u-un me-mi-an ḫa-an-da-a-iz-zi
ドゥトゥシ・マザ・アプーン・メミアン・ハンダーイッツィ
我が太陽（王の自称）-しかし（再帰）その　言葉を　守る-3単現
「しかし、わが太陽（王）はその言葉（約束）を守る」
```

この「太陽」を王の称号に用いる発想は、[プドゥヘパ王妃の祈り](/hittite/readings/queen-puduhepa-prayer/)で見た最高位の女神が「アリンナの太陽女神」と呼ばれることとも呼応しており、王権と太陽神信仰とを結びつける、ヒッタイトの王権思想の中心的なモチーフの一つとなっている。エジプトのファラオが太陽神ラーの化身とされたこととも比較される、古代西アジア・北アフリカに広く見られる王権と太陽の結びつきの一例である。

## 定型句が果たす機能

このような称号の連なりは、単なる美辞麗句ではなく、文書の冒頭で発話者（王）の正統性・権威を確立するという実務的な機能を持っていた。特に条約文書においては、称号の書き方一つで、相手国との力関係（対等な大国か、従属的な同盟国か）が暗に示されることもあり、称号の選択そのものが外交上の意味を持っていたと考えられている。
