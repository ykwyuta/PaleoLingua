## 与格 -ra：受け手・受益者

与格接尾辞 `-ra` は、行為の受け手や受益者を表す。主に人間や神など、有生（生きている、または人格を持つ）とみなされる名詞に付く。

<p class="cuneiform">𒈗𒊏   𒂍   𒈬𒈾𒆕</p>

```
lugal-ra   e2   mu-na-du3
ルガル・ラ エ   ム・ナ・ドゥ
王-与格    家   彼が彼のために建てた
「彼は王のために家を建てた」
```

## 処格 -a：場所

処格接尾辞 `-a` は「〜において」という場所を表す。主に無生物（建物や土地など）に付く。

<p class="cuneiform">𒂍𒀀</p>

```
e2-a
エ・ア
家-処格
「家において」「家の中で」
```

## 終端格 -še3：到達点・目的

終端格接尾辞 `-še3` は「〜まで」「〜に向かって」という到達点や、「〜のために」という目的を表す。

<p class="cuneiform">𒌷𒂠</p>

```
uru-še3
ウル・シェ
都市-終端格
「都市へ（向かって）」
```

## 奪格・具格 -ta：起点・手段

`-ta` は「〜から」という空間的・時間的起点、または「〜によって」という手段を表す。

<p class="cuneiform">𒆳𒋫</p>

```
kur-ta
クル・タ
山（外国）-奪格
「山から」「外国から」
```

## 共格 -da：同伴

`-da` は「〜と一緒に」という同伴・随伴の関係を表す。

<p class="cuneiform">𒁮𒀀𒉌𒁕</p>

```
dam-a-ni-da
ダム・ア・ニ・ダ
妻-彼の-共格
「彼の妻と一緒に」
```

## まとめ表

| 格 | 接尾辞 | 楔形文字 | カタカナ読み | 意味の中心 |
|---|---|---|---|---|
| 与格 | `-ra` | 𒊏 | ラ | 〜のために、〜に（受け手） |
| 処格 | `-a` | 𒀀 | ア | 〜において（場所） |
| 終端格 | `-še3` | 𒂠 | シェ | 〜まで、〜のために（到達点・目的） |
| 奪格・具格 | `-ta` | 𒋫 | タ | 〜から、〜によって |
| 共格 | `-da` | 𒁕 | ダ | 〜と一緒に |
