## 2種類の否定辞

ヒッタイト語には、否定したい文の**法（ムード）**に応じて使い分けられる、2つの主要な否定辞がある。

- **natta**：平叙文（事実を述べる文）を否定する。「〜ではない」に相当する。
- **lē**：命令文・要求文を否定する。「〜するな」という禁止を表す。

この2つの否定辞は互いに置き換えることができず、文の法に応じて機械的に使い分けられる。

## natta による平叙文の否定

```
natta ú-e-mi-ya-ḫu-un
ナッタ・ウエミヤフン
〜ない　見つける-1単過
「私は（それを）見つけなかった」
```

natta はしばしばアッカドグラム **UL** で書かれることも多い。これは「〜ない」を意味するアッカド語の否定辞をそのまま借用表記として流用したものであり、[シュメログラムとアッカドグラム](/hittite/script-and-phonology/sumerograms-and-akkadograms/)で説明した借用表語文字の一例でもある。

```
UL-ma ú-iz-zi
ウルマ・ウィッツィ
〜ない（アッカドグラム）-しかし　来る-3単現
「しかし彼は来ない」
```

## lē による禁止表現

```
lē i-ya-ši
レー・イヤシ
〜するな　する-2単現
「（お前は）するな」
```

lē は、命令法（あるいは命令的に用いられた現在形）とともに用いられ、話し手が聞き手に対してある行為をしないよう求める禁止の意味を表す。natta が事実の否定であるのに対し、lē は意志・要求に関わる否定であるという点で、両者は機能上はっきりと分かれている。

## 印欧諸語に共通する類型

平叙文の否定辞と禁止（命令文）の否定辞を別の語で表すという体系は、ヒッタイト語に限らず、他の古い印欧諸語にも広く見られる類型である。たとえばラテン語の non（平叙文の否定）と nē（禁止の否定）、古典ギリシア語の ou（平叙文の否定）と mē（禁止の否定）、サンスクリットの na（平叙文の否定）と mā（禁止の否定）などが、ヒッタイト語の natta / lē と機能的に対応する。このような対応関係は、印欧祖語の段階ですでに平叙・禁止の否定辞が区別されていたことを示す証拠の一つとして、比較言語学で重視されている。
