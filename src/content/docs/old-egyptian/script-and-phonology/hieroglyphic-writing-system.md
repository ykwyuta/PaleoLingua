## ヒエログリフは「表音文字」ではない

ヒエログリフ（聖刻文字、hieroglyph）と聞くと、多くの人は「一つ一つの絵が音を表すアルファベット」を想像するかもしれない。しかし実際には、ヒエログリフは性質の異なる3種類の記号――**表語文字（ロゴグラム）**・**表音文字（フォノグラム）**・**限定符（デテルミナティヴ）**――を組み合わせて1語を綴る、非常に複合的な文字体系である。1つの単語の中に、これら3種類の記号が同時に現れることも珍しくない。

## 3種類の記号

| 種類 | 働き | 例 |
|---|---|---|
| 表語文字（ロゴグラム） | 1つの記号が単語（の意味とおおよその音）をまるごと表す | 𓉐（家の平面図）＝ pr「家」 |
| 表音文字（フォノグラム） | 発音（子音の並び）のみを表し、意味とは無関係。単子音・二子音・三子音記号に分かれる | 𓅓＝m（単子音）、𓄤＝nfr（二子音） |
| 限定符（デテルミナティヴ） | それ自体は発音されず、直前の語がどの意味カテゴリーに属するかを示す無音の記号 | 𓂻（歩く脚）＝移動を表す動詞に添える |

表音文字はさらに、1つの子音だけを表す**単子音記号**（次の記事で扱う24字）、2つの子音の並びを表す**二子音記号**、3つの子音の並びを表す**三子音記号**に分かれる。これらの分類は次の記事「[単子音記号：ヒエログリフの「アルファベット」24字](/old-egyptian/script-and-phonology/uniliteral-signs-alphabet/)」と「[二子音記号と三子音記号](/old-egyptian/script-and-phonology/biliteral-triliteral-signs/)」で詳しく扱う。

## 実例：1語の中で組み合わさる仕組み

エジプト語の単語は、しばしば「音を綴る表音文字」＋「意味を確定する限定符」という組み合わせで書かれる。たとえば「良い、美しい」を意味する nfr は、二子音記号1字（𓄤）で音を示し、その後に抽象概念を示す限定符（𓏛、パピルスの巻物）を添えて書かれることがある。

<p class="hieroglyph">𓄤𓏛</p>

```
nfr
ネフェル
良い、美しい、完全な（二子音記号＋抽象概念の限定符）
```

同じ nfr という音は、フルに音だけで綴ることもできる。その場合は単子音記号3つを並べる。

<p class="hieroglyph">𓈖𓆑𓂋</p>

```
nfr
ネフェル
良い、美しい、完全な（単子音記号3字による全音節綴り）
```

このように、同じ単語でも「表語文字1字で済ませる」「表音文字だけで綴る」「表音文字＋限定符で綴る」など複数の書き方が並存しうる点も、ヒエログリフの大きな特徴である。なお、この記事で示すカタカナ読みはあくまで現代エジプト学の慣例的な発音の目安であり、古代の実際の発音を復元したものではない（詳しくは「[古エジプト語の子音体系と再建音価](/old-egyptian/script-and-phonology/egyptian-consonant-phonology/)」を参照）。

## なぜ母音を書かないのか

ヒエログリフの表音文字が表すのは**子音（と半母音 j・w）のみ**であり、母音は原則として文字に書き表されない。これはエジプト語が、セム語などと同じアフロ・アジア語族に属し、単語の基本的な意味が子音の並び（語根）によって担われる言語だったためと考えられている。語根さえ分かれば、当時の読み手は文脈と自身の母語知識から適切な母音を補って読むことができた――ちょうどアラビア語やヘブライ語の伝統的な表記法が母音符号を省略できるのと似た理屈である。したがって、ヒエログリフは「絵文字」でも古典的な意味の「アルファベット」でもなく、**表語性と表音性を併せ持つ、子音中心の複合文字体系**として理解するのが正確である。
