## KBo・KUBという略号

ヒッタイト語の条約文書を扱う研究論文では、しばしば **KBo**（Keilschrifttexte aus Boghazköi「ボアズキョイ楔形文字文書集」）や **KUB**（Keilschrifturkunden aus Boghazköi「ボアズキョイ楔形文字文書」）という略号に番号を付けたかたちでテキストが引用される。これらはハットゥシャ（ボアズキョイ）出土の楔形文字粘土板を収録した、ドイツの学術出版シリーズの名称である。ヒッタイトの条約文書の多くは、こうした番号付きの粘土板として現在に伝わっている。

## 属国条約の定型構成

ヒッタイトの大王が周辺の属国の王と結んだ条約文書（いわゆる「属国条約」）は、驚くほど共通した構成を持つ。

| 構成要素 | 内容 |
|---|---|
| 前文 | 条約を発する大王の名と称号を名乗る |
| 歴史的序文 | これまでの両国の関係の経緯を語り、条約締結の正当性を示す |
| 条項 | 属国の王が守るべき具体的な義務（軍事協力、逃亡者の引き渡しなど）を列挙する |
| 保管・朗読規定 | 条約文書の写しを神殿に保管し、定期的に読み上げることを定める |
| 神々の証人リスト | 両国の神々を条約の証人として列挙する |
| 祝福と呪詛 | 条約を守れば祝福を、破れば神々の呪いが下ることを宣言する |

## 神々の証人リストの定型句

条約末尾の神々のリストは、両国それぞれの主要な神々を、しばしば長々と列挙する形で現れる。

```
DINGIR.MEŠ ku-i-e-eš tup-pí-ya-za ka-tan
ディンギルメーシュ・クイエーシュ・トゥッピヤザ・カタン
神々（複数）　この文書の中に　（局所小詞）
「この文書に記された神々」

nu-uš-ma-aš iš-ta-ma-aš-du-uš
ヌシュマシュ・イシュタマシュドゥシュ
そして彼らに　聞いてください（命令法3複）
「（その神々が）彼ら（両国の当事者）に耳を傾けてくださるように」
```

## 祝福と呪詛の定型句

条約は必ず、条項を守った場合の祝福と、破った場合の呪詛の対句で締めくくられる。

```
ku-iš ke-e up-pí-ya-uš ḫa-an-da-a-iz-zi
クイシュ・ケー・ウッピヤウシュ・ハンダーイッツィ
誰であれ　これらの　言葉（複数対格）　守る-3単現
「誰であれ、これらの言葉（条項）を守るならば」

nu-uš-ši DINGIR.MEŠ ke-e-el li-in-ga-aš a-ša-an-du
ヌッシ・ディンギルメーシュ・ケーエル・リンガシュ・アシャンドゥ
彼に　神々　この誓約の　あれ-命令法3複
「この誓約の神々が彼に（味方して）あるように」
```

## なぜこれほど定型化されていたのか

条約文書がこれほど画一的な構成を取っていた背景には、条約という文書の性質上、内容の正当性・拘束力を明確にする必要があったことが挙げられる。神々を証人として列挙し、祝福と呪詛を明示することで、条約は単なる政治的合意にとどまらず、宗教的な誓約としての重みを持たされていた。このような構成は、後代の聖書における契約（covenant）の記述形式との類似性が指摘されることもあり、古代西アジアにおける「条約」という文書ジャンルの広がりを示す好例とされる。
