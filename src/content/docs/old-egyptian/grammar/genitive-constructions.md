## 「AのB」を表す2つの方法

古エジプト語には「名詞＋名詞」で所有・所属関係（「AのB」）を表す方法が2種類ある。ひとつは名詞を単に並べるだけの**直接属格**（direct genitive）、もうひとつは属格形容詞 **n(y)** 「〜の」を挟む**間接属格**（indirect genitive）である。

## 直接属格：名詞を並べるだけ

直接属格では、「所有されるもの＋所有するもの」の順で2つの名詞を並べるだけでよい。間に何も挟まない、もっともシンプルな所有表現である。

<p class="hieroglyph">𓊪𓂋𓈖𓍿𓂋</p>

```
pr nṯr
プル・ネチェル
家・神
「神の家」（＝神殿。直訳：家・神）
```

直接属格は、所有物とその持ち主の間に密接で本質的な結びつきがある場合（体の部位、家族関係、あるいは pr nṯr「神殿」のように制度的に固定された組み合わせなど）によく使われる、簡潔で日常的な表現方法である。

## 間接属格：属格形容詞 n(y) を挟む

間接属格では、2つの名詞のあいだに属格形容詞 **n(y)**（男性）／**n.t**（女性）／**n.w**（男性複数）を挟む。この語は「〜の」を意味し、他の形容詞と同じように**所有されるもの（先行する名詞）**の性・数に一致する。

<p class="hieroglyph">𓊪𓂋𓈖𓈖𓍿𓂋</p>

```
pr n(y) nṯr
プル・ニィ・ネチェル
家・〜の（男性）・神
「神の家」（間接属格。より明示的・強調的な言い方）
```

直接属格の pr nṯr と間接属格の pr n(y) nṯr は、どちらも「神の家」と訳せるが、間接属格のほうがより明示的で、所有関係をはっきりと際立たせた言い方になる。一般に、直接属格は密接で慣用的な結びつきに、間接属格はより緩やかな、あるいは強調したい所有関係に使われる、という使い分けの傾向がある。

## 属格形容詞 n(y) は普通の形容詞と同じ振る舞いをする

n(y) は独立した単語というより、名詞の後に置かれて性・数の一致を示す「属格形容詞」（genitival adjective）として分析される。これは[形容詞とニスバ形容詞](/old-egyptian/grammar/nisbe-adjectives/)の記事で見た、名詞の後に形容詞を置く基本語順とも整合的である。
