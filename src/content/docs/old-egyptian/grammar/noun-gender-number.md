## エジプト語名詞の2つの性

古エジプト語の名詞には**男性**（masculine）と**女性**（feminine）の2つの文法上の性がある。男性名詞は特別な語尾を持たない（無標）のに対し、女性名詞は語末に **-t** を付けて作られる。

たとえば「神」を意味する **nṯr**（男性）に -t を付けると「女神」を意味する **nṯrt**（女性）になる。これは日本語の「彼／彼女」のような自然な性の区別だけでなく、無生物の名詞にも文法上の性が割り振られる点で、フランス語やドイツ語の文法性に近い。

<p class="hieroglyph">𓈖𓍿𓂋</p>

```
nṯr
ネチェル
「神」（男性・無標）
```

<p class="hieroglyph">𓈖𓍿𓂋𓏏</p>

```
nṯrt
ネチェレト
「女神」（女性、nṯr + -t）
```

このカタカナ表記は現代エジプト学における慣用の読み方であり、古代エジプト人が実際にどう発音していたかを復元したものではない点に注意してほしい（母音は書かれないため、慣習的にe/eなどを補って読む）。

## エジプト語名詞の3つの数

数については、単数・複数に加えて**双数**（dual、「2つ」をちょうど指す特別な形）という3番目のカテゴリーがある。これはアラビア語やヘブライ語などセム語派の言語にも見られる特徴で、古典ギリシア語の双数とも類型的に似ている。

- **単数**：無標
- **複数**：男性 **-w**、女性 **-wt**
- **双数**：男性 **-wy**、女性 **-ty**

## nṯr（神）の完全パラダイム

Table 1の単子音記号（n, ṯ, r, t, w, y）だけを使って、この6つの形をすべて音声どおりに綴ることができる。

| 形 | 翻字 | ヒエログリフ | カタカナ読み | 形態素分析 | 意味 |
|---|---|---|---|---|---|
| 男性単数 | nṯr | 𓈖𓍿𓂋 | ネチェル | nṯr（神） | 神 |
| 女性単数 | nṯrt | 𓈖𓍿𓂋𓏏 | ネチェレト | nṯr + -t（女性） | 女神 |
| 男性複数 | nṯrw | 𓈖𓍿𓂋𓅱𓏥 | ネチェルウ | nṯr + -w（男性複数） | 神々 |
| 女性複数 | nṯrwt | 𓈖𓍿𓂋𓅱𓏏𓏥 | ネチェルウト | nṯr + -wt（女性複数） | 女神たち |
| 男性双数 | nṯrwy | 𓈖𓍿𓂋𓅱𓏭 | ネチェルウィ | nṯr + -wy（男性双数） | 2柱の神 |
| 女性双数 | nṯrty | 𓈖𓍿𓂋𓏏𓏭 | ネチェルティ | nṯr + -ty（女性双数） | 2柱の女神 |

複数形の後ろに添えた 𓏥（Z2、「3本の縦線」＝複数を表す限定符）に注目してほしい。これは -w や -wt が音声として書かれているかどうかに関わらず、複数であることを目で見てすぐわかるように添える慣習的な記号である。双数の場合は同じ発想で2本の縦線（𓏭、Z4「対になった線」）が使われることが多い。つまりエジプト語の複数・双数表記は「音を綴る」文字体系と「意味のカテゴリーを一目で示す」限定符の二重の仕組みで支えられている。

## 女性形 -t の広い役割

女性を表す -t は、単に「女性名詞である」というだけでなく、抽象名詞（例：「〜であること」）を作る派生接尾辞としても働くなど、エジプト語の中で非常に生産的な形態素である。まずは基本の男性／女性の対立と、単数・双数・複数の3分法をしっかり押さえておこう。
