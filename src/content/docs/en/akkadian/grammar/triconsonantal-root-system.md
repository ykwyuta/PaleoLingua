## Root and Pattern: A Core Semitic Idea

Akkadian words, like those of the Semitic languages generally, are built from two independent components: a **root** and a **pattern**. This is a rather different mechanism from Indo-European word formation (where a single stem simply accumulates affixes), and it is one of the first principles to grasp when approaching Akkadian vocabulary and grammar.

- **Root**: usually three consonants (no vowels), carrying the core lexical meaning, or "semantic field," of the word. For instance `PRS` (p-r-s) covers the field "to cut, separate, decide," while `ŠPR` (š-p-r) covers "to send."
- **Pattern**: the vowels inserted between the root consonants, plus prefixes and suffixes attached before and after, which carry grammatical information — tense/aspect, voice, part of speech, and so on.

It helps to think of the root as answering "what is this word about," and the pattern as answering "in what grammatical shape." A bare consonant skeleton like `√PRS` is not itself a pronounceable word, nor a dictionary headword — it is only an abstract frame. Only once a vowel pattern is poured into that frame does a pronounceable form like *iprus* emerge.

## The Root √PRS "to Decide, Cut" Across Forms

Combining the root `PRS` with different vowel patterns and affixes yields a range of verbal forms. Since all of them share the same consonant sequence p-r-s, the semantic core ("to cut/decide") stays constant while only the grammatical information — who is acting, when, and in what state — changes.

| Transliteration | Cuneiform | Grammatical form | Meaning |
|---|---|---|---|
| iprus | 𒅁𒊒𒊻 | Preterite | "he decided" |
| iparras | 𒄿𒉺𒅈𒊏𒀸 | Present/Durative | "he decides" |
| paris | 𒉺𒊑𒄑 | Stative/Permansive | "it is decided / has been settled" |

These three forms differ only in the vowel pattern inserted *between* the root consonants (i-a, i-a-a, a-i, etc.) and in the affixes attached before and after (i- for the preterite, no affix for the stative). The full person-by-person conjugation and the finer distinctions in meaning among these forms are treated in the dedicated articles [G-Stem Conjugation](/en/akkadian/grammar/g-stem-conjugation/) and [The Stative/Permansive](/en/akkadian/grammar/stative-permansive/). Here the point is simply to establish the big picture: the same root wearing different patterns yields different grammatical forms.

## A Second Example: √ŠPR "to Send"

The same mechanism applies to other roots. The dictionary citation form (infinitive) of the verb built on the root `ŠPR` "to send" is spelled as follows.

<p class="cuneiform">𒊭 𒉺 𒊒 𒌝</p>

```
šapārum
šapār (infinitive pattern of the root ŠPR) + -um (nominative case vowel + mimation)
"to send" (infinitive/citation form)
```

The infinitive `šapārum` is itself nothing more than the root ŠPR combined with a nominal pattern used specifically for infinitives (the "PaRāS-um" pattern). In other words, even a verb's basic dictionary form is already a product of the root-and-pattern system — the bare root `√ŠPR` never appears on its own in any dictionary entry.

## A Brief Comparison to Other Semitic Languages

This "root plus pattern" mechanism of word formation is not unique to Akkadian; it is a defining feature shared across the Semitic language family. Readers with some background in comparative Semitic linguistics, Arabic, or Hebrew will recognize the following parallels.

- Arabic: the root `k-t-b` "to write" yields *kataba* "he wrote" and *yaktubu* "he writes" — the same consonantal skeleton takes on different vowel patterns.
- Hebrew: the root `k-t-v` "to write" similarly yields *katav* "he wrote" and *yikhtov* "he will write," with the consonantal skeleton held constant while only the vowel pattern shifts.

The relationship between *iprus*, *iparras*, and *paris* in Akkadian is precisely the East Semitic instance of this same principle. Because Akkadian is the earliest well-attested literary Semitic language, it also serves as an important comparandum for understanding how this root-and-pattern system originated and how it subsequently developed in the later West Semitic languages such as Arabic and Hebrew.
