## 翻字とは何か

「翻字（transliteration）」とは、粘土板に刻まれた楔形文字の記号1つ1つを、それが表す音や単語に対応するローマ字表記に置き換えたものである。アッカド語学（アッシリア学）では、実際の粘土板の写真や模写から、まずこの翻字を作成し、そこから文法分析・翻訳へと進む。本サイトの例文もすべてこの翻字の形で提示する。

学術論文では音節綴りの語はイタリック体で示すのが慣例だが（例：*šarrum*）、本サイトでは読みやすさを優先し、イタリックを用いない通常の等幅表記で統一する（例：`šarrum`）。

## 特殊な文字

アッカド語の翻字には、英語のアルファベットにない特殊文字がいくつか登場する。

| 文字 | 音価の目安 | 備考 |
|---|---|---|
| š | 英語の *sh* に近い音 | シュメール語の翻字とも共通 |
| ṣ | 強勢のある *s*（口蓋化・咽頭化を伴う「強い」s） | セム語比較言語学でいう強勢音の一つ |
| ṭ | 強勢のある *t* | 同上 |
| ḫ | 喉の奥で摩擦する音（ドイツ語の *ch* に近い） | ヒッタイト語の ḫ とも同じ記号を用いる |
| ʾ | 声門閉鎖音（アレフ） | 母音の前でのみ現れることが多い |

## 長母音の表記：マクロンとサーカムフレックス

アッカド語には短母音と長母音の対立があり、翻字では長母音を母音の上に記号を付けて示す。

| 記号 | 意味 | 生じる原因 |
|---|---|---|
| ā・ī・ū・ē（マクロン） | 語源的・文法的に元から長い母音 | 語根や語形変化パターンに由来する長さ |
| â・î・û（サーカムフレックス） | 母音融合（縮約）によって生じた長母音 | 隣り合う2つの母音が1つに融合した結果 |

マクロンの例として、`mātum`「国、地」を見てみよう。この語の *ā* は語源的に長い母音で、粘土板でも母音を重ねて綴ることでその長さが示されることが多い。

<p class="cuneiform">𒈠 𒀀 𒌈</p>

```
ma-a-tum
マ・ア・トゥム
mātum「国、地」（女性・主格・単数、a音節を重ねて長母音を示す）
```

一方サーカムフレックスは、母音融合によって生じる。動詞「言う」（語根 √QBʾ）の完了法（プレテリット）形 `iqbi`「彼は言った」に、従属節（関係節など）で用いられる従属マーカー *-u* が付くと、語末の *i* と *-u* が融合して長母音 *û* を生む。

<p class="cuneiform">𒄿 𒅅 𒁍 𒌑</p>

```
i-iq-bu-u2
イ・イク・ブ・ウ
iqbû「彼が言った（従属節形）」（i-（3人称単数）+ qbi（語根）+ -u（従属マーカー）の融合）
```

## ハイフン：単語内の記号の切れ目

同一単語内で複数の音節記号を連ねて書く「音節綴り（破損綴り）」では、記号同士をハイフンで区切るのが慣例である。先ほどの `ma-a-tum` や `i-iq-bu-u2` のハイフンも、この規則に従っている。次の例は「王」を意味する `šarrum` を音節綴りで書いたものである。

<p class="cuneiform">𒊭 𒅈 𒊒 𒌝</p>

```
ša-ar-ru-um
シャ・アル・ル・ウム
šarrum「王」（男性・主格・単数）
```

## 下付き索引番号：同音異字の区別

シュメール語由来の楔形文字には、同じ音を表す記号が複数存在する（同音異字）。これらを区別するため、翻字では下付きの索引番号を付ける。たとえば「ドゥ」という音を表す記号は複数あり、`du`・`du₂`・`du₃` のように区別される。

| 翻字 | 楔形文字 | カタカナ読み | 対応するサイン名 |
|---|---|---|---|
| du | 𒁺 | ドゥ | DU |
| du₂ | 𒌅 | ドゥ | TU |
| du₃ | 𒆕 | ドゥ | KAK |

索引番号はあくまで「どの字形を使っているか」を示す学術的な目印であり、発音そのものの違いを示すものではない。読むときは番号を無視してよい。

## 大文字表記：シュメログラム（表語文字）

アッカド語の書記官は、しばしばシュメール語由来の表語文字（ロゴグラム）を使って単語を丸ごと1つの記号で書いた。こうしたシュメール語源の綴り（シュメログラム）は、翻字では全て大文字で示すのが慣例である。次の例は「王」を意味する `šarrum` を、音節綴りではなくシュメログラムで書いたものである。

<p class="cuneiform">𒈗</p>

```
LUGAL
ルガル
šarrum「王」を表語文字（もとはシュメール語 lugal「王」）で書いたもの
```

## 上付き文字：限定符（デテルミナティヴ）

限定符（デテルミナティヴ）は、それ自体は発音されない補助記号で、直前・直後の単語が属する意味カテゴリー（神名・地名・木製品・職業名など）を示す。翻字では上付き文字で示す。次の例は太陽神シャマシュ（本サイトのマスコットキャラクターの一人）の名を、神名を示す限定符 `d`（ディンギル）付きで書いたものである。

<p class="cuneiform">𒀭𒌓</p>

```
dUTU
（ディンギル）ウトゥ
Šamaš「シャマシュ神」――dは発音されない神名限定符、UTUは「太陽」を表す表語文字
```

## 破損（音節）綴りとシュメログラムの併用

同じ単語でも、文法情報をどこまで明示するかによって綴り方が変わる。シュメログラム `LUGAL` だけでは「王」という語であることは分かっても、格や数といった文法情報は示されない。そこで書記官は、シュメログラムの末尾に文法語尾を示す「音声補語（phonetic complement）」を音節記号で添えることがある。

<p class="cuneiform">𒈗𒌝</p>

```
LUGAL-um
ルガル・ウム
šarrum「王」（LUGALは表語文字、-umは主格語尾を示す音声補語）
```

これに対して、先に見た `ša-ar-ru-um` のような完全な音節（破損）綴りは、格語尾 `-um` まで含めて全ての音を記号で綴るため、文法形式が翻字の上でも明確に分かる。パラダイム表など、文法変化を示したい場面では音節綴りが好まれる理由はここにある。
