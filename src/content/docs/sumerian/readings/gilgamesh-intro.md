## シュメール語版「ギルガメシュ」は1つの叙事詩ではない

後代の12枚の粘土板にまとめられたアッカド語版『ギルガメシュ叙事詩』（標準版）とは異なり、シュメール語で伝わるギルガメシュ関連の作品は、もともと独立した5編の詩として作られた。これらは主にウル第三王朝〜古バビロニア時代（紀元前21〜18世紀頃）の写本、とりわけ学術都市ニップルから出土した写本を通じて今日に伝わっている。

| 詩の題名（慣用的な英語題） | 内容の概要 |
|---|---|
| ギルガメシュとフワワ（生ける者の国） | ギルガメシュが杉の森の守護者フワワを討伐する遠征譚 |
| ギルガメシュと天の牛 | 女神イナンナが放った「天の牛」をギルガメシュとエンキドゥが倒す物語 |
| ギルガメシュとアッガ | キシュの王アッガによるウル包囲と、ギルガメシュの応戦 |
| ギルガメシュ、エンキドゥと冥界 | エンキドゥが冥界へ下り、その様子をギルガメシュに語る物語 |
| ギルガメシュの死 | 王ギルガメシュの死とその後の顛末を描く詩 |

これら5編は、後のアッカド語版『ギルガメシュ叙事詩』の主要なエピソード（フワワ討伐、天の牛、エンキドゥの死とその余波など）の直接・間接の源泉になったと考えられているが、物語の細部や登場人物の性格づけには版ごとに違いも大きく、単純な「原作と翻訳」の関係ではない点に注意が必要である。

## 定型的な称号：「ウルクの王」

これらの詩の随所、また後代のシュメール王名表においても、ギルガメシュは繰り返し「ウルクの王」という定型的な称号で呼ばれる。

```
𒈗 𒀕𒆠𒂵
lugal   unugki-ga
ルガル  ウヌグ・ガ（`ki`は地名の限定符で読まない）
王      ウルク-属格
「ウルクの王」
```

この称号の作り方は、[属格 -ak](/sumerian/grammar/genitive-case-ak/)で見た「名詞＋所有者＋ -ak」という構造そのものであり、`unug`（ウルク）の語末の `g` の後で `-ak` が `-ga`（子音重複＋ `-a`）という形を取っている。
