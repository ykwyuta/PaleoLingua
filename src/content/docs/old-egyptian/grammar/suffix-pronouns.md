## 接尾代名詞とは

古エジプト語には、名詞・前置詞・動詞に直接付いて人称（「私」「あなた」「彼」など）を表す一群の代名詞がある。これを**人称接尾代名詞**（suffix pronoun）と呼ぶ。独立した単語ではなく、必ず何らかの語の後ろに付属する点が特徴で、慣習的に等号（=）を使って本体の語と区切って表記する。

## 全パラダイム

| 人称 | 接尾辞 | カタカナ読み |
|---|---|---|
| 1人称単数 | =j | イ |
| 2人称単数・男性 | =k | ク |
| 2人称単数・女性 | =ṯ | チュ |
| 3人称単数・男性 | =f | フ |
| 3人称単数・女性 | =s | ス |
| 1人称複数 | =n | ン |
| 2人称複数 | =ṯn | チェン |
| 3人称複数 | =sn | セン |

（このほかに2人称・3人称の双数形 =ṯny／=sny も存在するが、使用例は比較的少ないため、ここでは代表的な単数・複数の8形をまず押さえておこう。）

Table 1の単子音記号にはこれらすべての子音（j, k, ṯ, f, s, n, ṯn, sn）が含まれているため、どの接尾辞も音声どおりに綴ることができる。

## 用法1：名詞に付けて所有を表す

接尾代名詞を名詞に直接付けると、「私の」「彼の」のような所有表現になる。「家」を意味する **pr** を例に見てみよう。

<p class="hieroglyph">𓊪𓂋𓆑</p>

```
pr=f
プル・エフ
家=彼の
「彼の家」
```

<p class="hieroglyph">𓊪𓂋𓇋</p>

```
pr=j
プル・イ
家=私の
「私の家」
```

## 用法2：前置詞に付ける

接尾代名詞は前置詞にも付き、「〜へ」「〜のために」のような表現を作る。属格・与格的な意味を持つ前置詞 **n**「〜へ、〜のために」を例にとる。

<p class="hieroglyph">𓈖𓆑</p>

```
n=f
ン・エフ
〜へ=彼
「彼へ、彼のために」
```

## 用法3：動詞に付けて主語を表す

接尾代名詞のもっとも重要な用法のひとつは、動詞に直接付いて**主語**を示すことである。動詞語根 **sḏm**「聞く」を例にとろう。

<p class="hieroglyph">𓋴𓆓𓅓𓆑</p>

```
sḏm=f
セジェム・エフ
聞く=彼
「彼は聞く」（動詞語根 sḏm + 主語を示す接尾代名詞 =f）
```

この sḏm=f という形は、エジプト学で**そのままの名前**として使われるほど重要な動詞形で、独立した記事（[sḏm=f形：古エジプト語動詞の基本形](/old-egyptian/grammar/sdm-f-verb-form/)）で詳しく扱う。ここでは、接尾代名詞が動詞の主語を表す働きを持つことをまず理解しておこう。

    <p class="plc-line"><b>ラー：</b>え、同じ =f が「彼の」にも「彼が」にもなるの？</p>
    <p class="plc-line"><b>マアト：</b>付く相手によって役割が変わるだけで、形はいつも同じ。だからこそ =j, =k, =f... の8つの形を覚えておけば、名詞にも動詞にも応用できるのよ。</p>
