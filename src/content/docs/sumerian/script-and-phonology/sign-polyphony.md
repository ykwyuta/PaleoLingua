## 同音異字の「裏返し」の現象

[音節文字としての楔形文字](/sumerian/script-and-phonology/cuneiform-syllabary/)では、同じ音を複数の異なるサインが表す「同音異字（homophony）」と、それを区別する索引番号について扱った。本記事では、その裏返しの現象、すなわち1つのサインが文脈に応じて複数の異なる音・読みを持つ「多価性（polyphony、ポリフォニー）」を見ていく。

## 実例：DUサインの複数の読み

移動や到着に関わる動詞にしばしば用いられるDUサインは、シュメール語の中でも特に多くの読みを持つサインの一つとして知られる。

```
𒁺
du
ドゥ
（読み1）行く、来る（マルー形語幹の一つ）
```

```
𒁺
gin
ギン
（読み2）行く（前の読みと近い意味だが、文法的な使用文脈が異なる）
```

```
𒁺
tum2
トゥム
（読み3）持って行く、運ぶ
```

```
𒁺
de6
デ
（読み4）持って来る、運んで来る（求心的な文脈）
```

まったく同じグリフ 𒁺 でありながら、これら4つの読みは互いに音としても意味の細部としても異なる。どの読みで解釈するかは、文脈（どの文法形式で使われているか、前後にどんな接頭辞が付いているかなど）によって決まる。

## なぜ1つのサインに複数の読みが生まれたのか

多価性は、もともと異なる単語を表す複数の絵文字が、字形の簡略化・統合の過程で偶然同じ形に収斂した結果生じたと考えられている。つまり、現在は1つの記号に見えても、その起源をたどれば複数の異なる「祖先」を持つ記号が合流した結果である場合がある。

## 同音異字との違い

| 現象 | 方向性 | 例 |
|---|---|---|
| 同音異字（homophony） | 複数のサイン → 同じ音 | `du`・`du3`・`du6`（すべて「ドゥ」） |
| 多価性（polyphony） | 1つのサイン → 複数の音 | 𒁺（`du`・`gin`・`tum2`・`de6`） |

この2つの現象は方向が正反対でありながら、どちらも「サインと音は必ずしも1対1に対応しない」という楔形文字の本質的な特徴を示している。
