## 「男性・女性」ではなく「共通性・中性」

ラテン語・ギリシア語・サンスクリット語など、多くの古い印欧諸語は男性・女性・中性の3性を区別する。しかしヒッタイト語（および他のアナトリア語派の言語）は、これらとは異なり、**共通性（common）**と**中性（neuter）**の2性しか区別しない。共通性は人間・動物など伝統的に「有生」とされる名詞を含み、中性は物・液体・抽象概念など「無生」とされる名詞を含む。

## なぜ「共通」性と呼ぶのか

「共通性」という呼び名は、この性のクラスが男性・女性の両方の指示対象を区別なく含むことに由来する。たとえば「息子」を意味する語も「娘」を意味する語も、文法上はどちらも共通性名詞として同じ格変化パターンに従う。文法上の性と、指示対象の生物学的な性別とは別の次元の情報であり、共通性名詞であっても、文脈や修飾語（「男の」「女の」に相当する語）によって初めて生物学的な性別が明示される。

## 2性体系の起源をめぐる仮説

アナトリア語派の2性体系については、大きく分けて2つの立場がある。

- **古形保持説**：印欧祖語はもともと「有生・無生」の2性体系を持っており、アナトリア語派はこの古い段階をそのまま保持した。男性・女性の区別は、アナトリア語派が分岐した後に、印欧祖語の他の枝で新たに発達したものである、とする立場。
- **簡略化説**：印欧祖語はすでに男性・女性・中性の3性を持っていたが、アナトリア語派（の祖語）において男性と女性の区別が統合され、2性体系に簡略化されたとする立場。

前者の立場は「インド・ヒッタイト仮説」と親和性が高く、アナトリア語派を印欧祖語の最古の分岐と位置づける議論の重要な論拠の一つとなっている。どちらの説が正しいかは今なお議論が続いており、断定的な結論は出ていない。

## 中性名詞の統語的な特殊性

中性名詞は、単に「無生物を指す」という意味的な特徴だけでなく、統語的にも共通性名詞とは異なるふるまいを見せる。もっとも顕著なのが、中性名詞が他動詞の主語になる際に現れる特別な格標示（能格）である。共通性名詞にはこの現象は見られない。詳しくは[中性の能格](/hittite/grammar/neuter-ergative-case/)を参照。

```
共通性名詞の例：LUGAL-uš（王が、主格）
中性名詞の例：wātar（水が／水を、主格＝対格）
```
