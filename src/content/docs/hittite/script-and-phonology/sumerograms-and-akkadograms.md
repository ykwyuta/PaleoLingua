## 借用表語文字とは何か

ヒッタイト語のテキストを開くと、大文字（学術翻字の慣習でスモールキャピタルまたは大文字で表記）で書かれた単語が頻繁に目に入る。これらは、ヒッタイト語本来の音節綴りではなく、他言語の単語をそのまま表語文字（一語一字で意味を表す文字）として流用したものである。

- **シュメログラム（Sumerogram）**：シュメール語の単語をそのまま借用して表語文字として使う。翻字では大文字で示す。例：LUGAL「王」、DINGIR「神」、URU「都市」。
- **アッカドグラム（Akkadogram）**：アッカド語の単語形（多くは屈折した形）をそのまま借用して使う。翻字ではイタリック体の大文字で示すのが慣例。例：*ANA*「〜へ、〜のために」（前置詞）、*ŠA*「〜の」（属格を表す前置詞的表現）。

これらはいずれも「この文字列をシュメール語やアッカド語として発音せよ」という意味ではなく、書記官と読者の双方が、その表語文字を見て頭の中でヒッタイト語の対応する語に変換して読む、という運用がなされていたと考えられている。ちょうど日本語で「Mr.」と書いて「ミスター」と読む、あるいは算用数字「3」を「みっつ」と読むのに近い感覚である。

## 具体例

```
LUGAL-uš URU-ri
ルガル・ウシュ ウル・リ
王（シュメログラム）-主格 都市（シュメログラム）-方向格
「王は都に（向かって）」
```

このように、シュメログラムの語幹に、ヒッタイト語の格語尾だけを音節文字（フォネティック・コンプリメント、phonetic complement）で付け足すのが一般的な運用である。この語尾は、読み手に対して「このシュメログラムをヒッタイト語のどの格形で読むべきか」を示す手がかりとしても機能する。

## なぜこれほど多用されたのか

シュメログラム・アッカドグラムが多用された背景には、以下のような実務上の理由が考えられている。

- **書記の省力化**：頻出する基本語彙（王、神、都市、家、羊など）を1つの表語文字で済ませることで、綴りの手間を省ける。
- **多言語共通の書記伝統**：シュメログラムはメソポタミア全域（アッカド語、フルリ語、ウガリト語など）の楔形文字文化圏で共通の「国際的な略号」のように機能しており、ヒッタイトの書記官もこの伝統をそのまま踏襲した。
- **専門用語の明確化**：神名・地名・官職名などをシュメログラムで固定的に書くことで、複雑な多言語文書の中でも意味の取り違えを防げる。

## 読み方が確定できない場合

シュメログラム・アッカドグラムの弱点は、対応するヒッタイト語本来の発音・語形が必ずしも判明しないという点である。ある語が常にシュメログラムでしか書かれず、音節綴りの実例が一度も見つからない場合、その語のヒッタイト語としての実際の発音は現在でも確定できないことが少なくない。研究者はこうした語について、関連する印欧諸語やアナトリア語派の同根語から発音を推測するにとどめ、断定的な復元は避けるのが通例である。
