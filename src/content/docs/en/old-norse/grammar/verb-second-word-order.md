## Not SOV, but "V2"

As noted in [Noun Cases](/en/old-norse/grammar/old-norse-noun-cases/), Old Norse word order is relatively free because case endings mark grammatical relations — but main clauses are still bound by a clear constraint: **verb-second (V2) word order**. The finite (person-inflected) verb must occupy the **second position** of the clause, no matter what comes first. This is a hallmark shared across the Germanic languages, still visible today in German, Dutch, and Swedish.

## The basic pattern: subject first

When the subject stands first, the word order looks, at a glance, just like English SVO.

```
Óðinn  mælti  þessi orð
Óðinn  mæl-ti  þessi orð
Óðinn(NOM) spoke-3SG.PAST these words(ACC)
"Óðinn spoke these words."
```

## Fronting a non-subject triggers inversion

The V2 constraint really shows its teeth when something other than the subject — an object, an adverbial phrase — is fronted for emphasis. In that case, **the verb still stays in second position, and the subject is pushed after it** (subject-verb inversion).

```
þessi orð  mælti  Óðinn
þessi orð  mæl-ti  Óðinn
these words(ACC) spoke-3SG.PAST Óðinn(NOM)
"These words, Óðinn spoke."
```

The object `þessi orð` ("these words") has been fronted for emphasis, but the verb `mælti` ("spoke") still holds the second slot, and the subject `Óðinn` is pushed behind it. Without a V2 constraint, English would render this awkwardly as "*These words spoke Óðinn*."

## Fronted adverbs trigger the same inversion

The same inversion occurs when a time or place adverbial is fronted.

```
þá  kom  konungr  til  hallar
þá  kom  konungr  til  hallar
then came king(NOM) to  hall(GEN)
"Then the king came to the hall."
```

Because `þá` ("then") stands first, the verb `kom` ("came") takes second position, and the subject `konungr` ("king") follows it. Opening a sentence with the adverb *þá* to mark a scene change is an extremely common stylistic device in saga narrative.

## V2 applies only to main clauses

The V2 constraint applies only to main (independent) clauses; subordinate clauses (introduced by *ef* "if," *því at* "because," and the like) do not necessarily place the verb second. This main-clause/subordinate-clause word-order asymmetry survives vividly in modern German today.
