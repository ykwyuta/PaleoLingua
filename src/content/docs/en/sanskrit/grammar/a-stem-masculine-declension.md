Among Sanskrit noun classes, **a-stem masculine nouns** (stems ending in short -a) form by far the most frequent group, comprising the largest single class of nouns in the dictionary. This article presents the complete paradigm of देव deva- "god" — 24 forms across eight cases and three numbers. For the overall picture, see [An Overview of Sanskrit Noun Declension](/en/sanskrit/grammar/noun-declension-overview/).

## The Declension of deva- "god"

| Case | Singular | Dual | Plural |
|---|---|---|---|
| Nominative | देवः devaḥ | देवौ devau | देवाः devāḥ |
| Vocative | देव deva | देवौ devau | देवाः devāḥ |
| Accusative | देवम् devam | देवौ devau | देवान् devān |
| Instrumental | देवेन devena | देवाभ्याम् devābhyām | देवैः devaiḥ |
| Dative | देवाय devāya | देवाभ्याम् devābhyām | देवेभ्यः devebhyaḥ |
| Ablative | देवात् devāt | देवाभ्याम् devābhyām | देवेभ्यः devebhyaḥ |
| Genitive | देवस्य devasya | देवयोः devayoḥ | देवानाम् devānām |
| Locative | देवे deve | देवयोः devayoḥ | देवेषु deveṣu |

A few regularities are worth noting.

- In the **dual**, the instrumental, dative, and ablative all merge into a single form, -ābhyām, and the genitive and locative merge into -ayoḥ (a case-syncretism pattern common across Indo-European languages when the dual is involved).
- In the **plural**, the dative and ablative likewise merge into -ebhyaḥ.
- The vocative singular deva is simply the bare stem, lacking the -ḥ (visarga) ending seen in the nominative devaḥ.
- Masculine and neuter nouns share the same a-stem class, but neuter nouns show identical nominative, accusative, and vocative forms in every number — a characteristically Indo-European feature of neuters.

## Example Sentences

```
देवः वदति।
devaḥ vadati.
god-NOM speak-3SG.PRES
"The god speaks."
```

```
अहं देवं पश्यामि।
ahaṃ devaṃ paśyāmi.
I-NOM god-ACC see-1SG.PRES
"I see the god."
```

```
देवेन सह गच्छामि।
devena saha gacchāmi.
god-INS with go-1SG.PRES
"I go with the god."
```

```
देवाय पुष्पं ददामि।
devāya puṣpaṃ dadāmi.
god-DAT flower-ACC give-1SG.PRES
"I give a flower to the god."
```

```
गृहात् देवस्य मन्दिरं गच्छामि।
gṛhāt devasya mandiraṃ gacchāmi.
house-ABL god-GEN temple-ACC go-1SG.PRES
"I go from the house to the god's temple."
```

As these examples show, the case ending alone determines a word's role in the sentence — subject, object, instrument, beneficiary, source, possessor — almost unambiguously, so sentence meaning does not depend on verb position or fixed word order. This point is developed further in [Sanskrit Word Order](/en/sanskrit/grammar/sanskrit-syntax-word-order/).

## Other A-Stem Masculine Nouns

The a-stem masculine class contains an enormous number of basic vocabulary items, all declined the same way as deva-.

| Word | Meaning |
|---|---|
| नर nara- | man, person |
| अश्व aśva- | horse |
| ग्राम grāma- | village |
| वृक्ष vṛkṣa- | tree |
| पुत्र putra- | son |
