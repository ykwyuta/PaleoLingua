## ソシュールの「予言」

1879年、若きフェルディナン・ド・ソシュールは、印欧祖語の母音交替（アプラウト）のパターンを説明するために、当時のどの印欧語にも直接の痕跡が残っていない未知の音素群の存在を理論的に想定した。これは後に「喉音理論（laryngeal theory）」と呼ばれるようになる。ソシュールの時代には、この仮説上の音を実際に確認する手立てはなく、あくまで音韻交替のパターンから逆算された理論的な要請にすぎなかった。

## ヒッタイト語の発見と喉音の直接証拠

1915年、ベドジフ・フロズニーがヒッタイト語をインド・ヨーロッパ語族の言語と認定した後、研究者たちはヒッタイト語の子音 **ḫ** が、印欧祖語の喉音のうちの少なくとも1つ（伝統的に *h₂ と呼ばれるもの）の直接的な生き残りであることに気づいた。これは言語学史上、理論的に予言されていた音がのちに実際の文献証拠として発見された、数少ない劇的な事例として知られている。

```
ḫa-a-ša-an-za
ハーシャンツァ
生む（動詞語根 ḫaš-）-分詞語尾
「生まれた（者）」
```

この語根 ḫaš-「生む」は、印欧祖語の語根 *h₂ens-（あるいは類似の再建形）に遡ると考えられており、ḫ が印欧祖語の喉音 *h₂ の反映であることを示す代表例の一つとして頻繁に引用される。

## 喉音理論の骨子

喉音理論は、印欧祖語に3つ（あるいはそれ以上）の喉音音素（*h₁, *h₂, *h₃ と表記される）を再建し、これらが隣接する母音の音色（*h₂ は /a/ 系統の母音を、*h₃ は /o/ 系統の母音を生じさせるなど）や長さに影響を与えたと説明する。多くの印欧語ではこれらの喉音は消失し、母音の質や長さの変化として痕跡を残すのみとなったが、ヒッタイト語（および他のアナトリア語派の言語）では、少なくとも一部の喉音が子音としてそのまま文字に表記され続けた。

## 言語学史における意義

ヒッタイト語における ḫ の発見は、比較言語学における再建（内的再建・比較再建）の方法論そのものの正しさを裏づける強力な証拠として広く受け止められた。理論的な推論のみによって存在が予言された音が、後に発見された独立の文献資料の中に実際に見出されたという展開は、自然科学における理論的予測と実証発見の関係にもなぞらえられ、言語学が単なる記述の学問ではなく、検証可能な予測を導ける学問であることを示す好例として、しばしば言語学史の講義で取り上げられる。
