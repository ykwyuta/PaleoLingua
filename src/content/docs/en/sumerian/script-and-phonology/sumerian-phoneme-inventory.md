## Why "reconstructed"?

Sumerian had ceased to be spoken as an everyday language by the first millennium BCE, so there is no way to directly record a native speaker's pronunciation. The phoneme inventory known today is a "reconstruction" built from indirect evidence — later Akkadian speakers' transcriptions of Sumerian, alternate spellings of the same word, and correspondences in loanwords. As a result, scholars differ on many of the details.

## Vowels

Sumerian is generally agreed to have had at least four vowel phonemes.

| Vowel | Example (CV syllabogram) |
|---|---|
| /a/ | 𒀀 `a` |
| /e/ | 𒂊 `e` |
| /i/ | 𒄿 `i` |
| /u/ | 𒌋 `u` |

Some scholars have argued for a fifth vowel, /o/, but this is not the scholarly consensus, and most introductory treatments assume a four-vowel system.

## Consonants

The traditional inventory lists consonant phonemes such as the following (shown here via a sample of CV syllabograms).

| Phoneme | Example | 
|---|---|
| /b/ | 𒁀 `ba` |
| /d/ | 𒁕 `da` |
| /g/ | 𒂵 `ga` |
| /ḫ/ (h) | 𒄩 `ha` |
| /k/ | 𒅗 `ka` |
| /l/ | 𒆷 `la` |
| /m/ | 𒈠 `ma` |
| /n/ | 𒈾 `na` |
| /r/ | 𒊏 `ra` |
| /s/ | 𒊓 `sa` |
| /š/ (sh) | 𒊭 `ša` |
| /t/ | 𒋫 `ta` |

In addition, the nasal /ŋ/ (written `ĝ` on this site — as in `ĝe26-e`, "I," from [Pronouns](/sumerian/grammar/personal-demonstrative-pronouns/)) and a glottal stop /ʔ/ are both widely accepted as part of the inventory.

## An open question: voiced/voiceless, or aspirated/unaspirated?

One of the most actively debated points in Sumerian consonant phonology concerns pairs like `b/p`, `d/t`, and `g/k`. Traditionally, following Akkadian and Latin-alphabet transliteration conventions, these have been described as a "voiced (b, d, g) versus voiceless (p, t, k)" contrast. More recent research (Jagersma, Keetman, and others), however, has suggested the real contrast may instead have been unaspirated versus aspirated, or plain versus ejective — something other than a simple voicing distinction. This site follows the traditional transliteration convention (voiced/voiceless Latin letter pairs) while noting that the actual phonetic values remain unsettled.
