## ハンムラビ王と法典の石碑

**ハンムラビ**（Ḫammu-rapi）は、バビロン第1王朝の6代目の王で、おおよそ紀元前1792年から前1750年頃(中期年代論)にかけて統治した。彼の名を冠する「ハンムラビ法典」は、全282条からなる楔形文字法文集で、高さ約2.25メートルの黒色閃緑岩（ダイオライト）の石碑に刻まれている。

石碑はもともとバビロンの公共の場か神殿域に建てられたと考えられるが、前12世紀頃、エラム王シュトルク・ナフンテ1世がバビロンを攻めた際に戦利品として彼らの都スサ（現在のイラン・フーゼスターン州）へ持ち去られた。石碑は1901〜1902年、フランスの考古学調査隊（ジャック・ド・モルガン隊）によってスサで再発見され、現在はパリのルーヴル美術館に所蔵されている。石碑上部の浮き彫りには、ハンムラビが太陽神・正義の神である**シャマシュ**（本サイトのマスコットの名の由来でもある）から、王権の象徴である「杖と輪」を授かる場面が刻まれている。

法典本体（282条の個々の法文）の前には長い**序文**が、後には**跋文**が置かれ、いずれも法文とは異なる格調高い文体で、ハンムラビが行った敬虔な事業や恩恵を受けた諸都市を列挙する。序文冒頭は、神々がハンムラビに正義を打ち立てる使命を与えたといういきさつを語り起こす、非常に長い一文（複数行にわたる従属節の連鎖）で始まる。

## 序文冒頭の一節

序文の書き出しは、天の神アヌ（Anum）への言及から始まる。以下はその最初の3語である。

<p class="cuneiform">𒄿𒉡𒈠 𒀭𒀀𒉡𒌝 𒍢𒄿𒀸</p>

```
i-nu-ma     ᵈA-nu-um                    ṣi-i-rum
イ・ヌ・マ  ア・ヌ・ウム（𒀭は神名の限定符で読まない）  ツィ・イ・ルム
〜のとき    アヌ（神名）-主格＋ミメーション          気高い、至高の-主格（Anumに一致）
「気高きアヌが……のとき」
```

この後に文はさらに「アヌンナキ神々の王、天と地の主にして国土の運命を定めるエンリル神が……エア神の長子マルドゥクに、あらゆる人類に対するエンリル神の職務を委ね、彼をイギギ神々の中で偉大な者とし、バビロンの名を気高く呼び……正義の王、私ハンムラビを立てて、国に正義を打ち立てさせ、悪しき者と邪な者を滅ぼし、強き者が弱き者を虐げぬようにと……」と続き、実際に主動詞にたどり着くまで数十行を要する長大な一文になっている。

## 語ごとの分析

| 翻字 | 楔形文字 | カタカナ読み | 形態素分析 | 意味 |
|---|---|---|---|---|
| i-nu-ma | 𒄿𒉡𒈠 | イ・ヌ・マ | inu「〜のとき」+ -ma（接続の強調小辞） | 〜のとき |
| ᵈA-nu-um | 𒀭𒀀𒉡𒌝 | ア・ヌ・ウム | Anu（神名語幹）+ -um（主格語尾＋ミメーション） | アヌ（天の神） |
| ṣi-i-rum | 𒍢𒄿𒀸 | ツィ・イ・ルム | ṣīr-（「気高い、至高の」を意味する形容詞語幹）+ -um（主格語尾） | 気高い、至高の |

## 文法メモ

- **`inūma`**：「〜のとき」を表す従属節標識の接続詞。序文全体は、この語に導かれる巨大な時の従属節から始まり、主節の動詞（「私は……を定めた」に相当する語）に至るまでに数十行を要する。
- **格語尾とミメーション**：`Anum` と `ṣīrum` はともに語末が `-um` で終わっている。これは主格単数の格語尾 `-um`（古バビロニア語の時期に見られる、格語尾の後にさらに付く鼻音 `-m`＝ミメーションを含む）であり、後代の方言ではこの `-m` は脱落し母音も短縮される。詳しくは[名詞の格変化とミメーション](/akkadian/grammar/noun-case-and-mimation/)を参照。
- **形容詞の一致**：`ṣīrum`「気高い」は名詞 `Anum` を修飾する形容詞で、性・数・格のすべてにおいて名詞と一致するため、名詞と同じ `-um` 語尾を取る。詳しくは[形容詞の格変化と一致](/akkadian/grammar/adjective-declension-agreement/)を参照。
- **限定符 `ᵈ`**：神名の前に置かれる限定符（元は楔形文字の AN 記号に由来）で、それ自体は発音されない記号である。翻字では上付きの `d`（DINGIR の略）で示す。
