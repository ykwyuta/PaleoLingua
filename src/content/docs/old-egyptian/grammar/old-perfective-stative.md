## 動作ではなく「状態」を表す動詞形

古エジプト語には、[sḏm=f形](/old-egyptian/grammar/sdm-f-verb-form/)のような「動作」を表す動詞形とは別に、主語が置かれている**結果としての状態**を表す特別な動詞形がある。これはエジプト学で**古全体相**（Old Perfective）または**擬似分詞**（Stative）と呼ばれる。

たとえば sḏm=f が「彼は聞く」という動作そのものを述べるのに対し、古全体相・擬似分詞は「彼は〜という状態にある／あった」という、動作の結果として生じた状態を表す。おおまかに言えば「彼は満足した状態にある」「彼は安らかである」のような意味あいになる。

## ḥtp を例に

「捧げ物、満足する、安らか」を意味する語根 **ḥtp** を例に、擬似分詞の考え方を見てみよう。

<p class="hieroglyph">𓎛𓏏𓊪</p>

```
ḥtp
ヘテプ
「捧げ物、満足する、安らかである」（語根）
```

これに人称語尾が付くと、「彼は安らかな状態にある」といった意味の擬似分詞の形になる。たとえば3人称単数・男性ではおおよそ **ḥtp=w** あるいは無標に近い形として現れると考えられている（正確な発音・母音は再構成が難しく、ここでは形の枠組みを示すにとどめる）。

<p class="hieroglyph">𓎛𓏏𓊪𓅱</p>

```
ḥtp=w
ヘテプ・ウ
安らか-3人称単数男性語尾
「彼は安らかな状態にある」（擬似分詞・古全体相の枠組みを示す例）
```

## 人称語尾のパラダイム（代表的な形）

擬似分詞の人称語尾は sḏm=f の接尾代名詞とは異なる独自の体系を持つ。代表的なものとして、通説的な教育文法でよく引用される語尾を挙げる（全人称・全数の語尾がすべて確実というわけではなく、ここでは主要な4つを示すにとどめる。パラダイムはこの他の人称・数にも続く）。

| 人称 | 語尾 |
|---|---|
| 1人称単数 | -kwj |
| 3人称単数・男性 | -w（またはほぼ無標） |
| 3人称単数・女性 | -tj |
| 3人称複数 | -w |

## セム語の「スタティヴ」との類型的な対応

この古全体相・擬似分詞は、機能の上でセム語派の「スタティヴ（状態動詞）」や、アッカド語の**permansive**（永続相、状態を表す接辞活用）とよく比較される。動作ではなく主語の状態を表す動詞カテゴリーを持つという発想そのものが、エジプト語とセム語派に共通するアフロ・アジア語族的な特徴のひとつだと考えられている。
