## 属格接尾辞 -ak の基本

属格接尾辞 `-ak` は「AのB」というように、所有・限定関係を表す。語順は「所有される名詞（A）＋所有者（B）＋ `-ak`」であり、日本語の「Bの」を名詞の後ろに置いたイメージに近い。

<p class="cuneiform">𒂍      𒈗𒀀</p>

```
e2      lugal-ak
エ      ルガル・アク
家      王-属格
「王の家」
```

## 音声環境による交替：-ak と -a

`-ak` の *k* は、直後に母音が続く場合にのみはっきり現れ、直後に子音が続く場合や句がそこで終わる場合には脱落し、`-a` という形で現れることが多い。

| 環境 | 現れる形 | 楔形文字 | カタカナ読み | 例 |
|---|---|---|---|---|
| 後ろに母音が続く | `-ak` | 𒀀 | アク | e2 lugal-ak-e 𒂍𒈗𒀀𒂊（エ・ルガル・アク・エ、王の家が〔能格〕） |
| 後ろに子音が続く／句末 | `-a`（先行子音が重複することもある） | 𒀀 | ア | e2 lugal-la（エ・ルガル・ラ、王の家） |

このため、同じ「王の家」という属格句でも、後にどんな要素が続くかによって `lugal-ak` と `lugal-la` のように見た目が変わる。これは属格接尾辞という文法要素自体が変化しているのではなく、あくまで発音上の交替（音韻規則）である点を押さえておきたい。

## 属格連鎖の実例

属格句は入れ子にすることで、複数段階の所有関係を1つの名詞句にまとめることができる。

<p class="cuneiform">𒉺𒇻       𒇻𒀀</p>

```
sipa       udu-ak
シパ       ウドゥ・アク
羊飼い     羊-属格
「羊の羊飼い」（＝羊を飼う羊飼い）
```

<p class="cuneiform">𒂼       𒉺𒇻    𒇻𒀀𒀀</p>

```
ama       sipa    udu-ak-ak
アマ      シパ    ウドゥ・アク・アク
母        羊飼い  羊-属格-属格
「羊の羊飼いの母」
```

上の例のように、`sipa udu-ak` 𒉺𒇻𒇻𒀀（羊の羊飼い）全体に、さらに属格接尾辞を付けることで、より大きな名詞句 `ama sipa udu-ak-ak` 𒂼𒉺𒇻𒇻𒀀𒀀（羊の羊飼いの母）を作ることができる。
