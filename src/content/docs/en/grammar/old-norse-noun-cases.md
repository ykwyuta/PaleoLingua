## Old Norse is an inflectional language

Old Norse nouns, pronouns, and adjectives change form to mark their grammatical role in the sentence. There are four cases — **nominative, accusative, genitive, and dative** — essentially the same framework used by modern German or Icelandic. Number (singular/plural) and grammatical gender (masculine/feminine/neuter), fixed per noun, are marked alongside case.

## The basic role of each case

| Case | Main function | Typical question it answers |
|---|---|---|
| Nominative | subject of the clause | "who/what (is doing X)" |
| Accusative | direct object; object of directional prepositions | "whom/what" |
| Genitive | possession, belonging | "whose/of what" |
| Dative | indirect object; object of locational prepositions | "to/for whom" |

## Declension of the masculine noun armr ("arm")

Let's look at one of the most regular declension classes, the masculine strong a-stem, using *armr* ("arm") as an example.

| Case | Singular | Plural |
|---|---|---|
| Nominative | armr | armar |
| Accusative | arm | arma |
| Genitive | arms | arma |
| Dative | armi | örmum |

(The o→ö shift seen in the dative plural *örmum* is due to u-umlaut, discussed in [Old Norse Phonology](/en/script-and-phonology/old-norse-phonology/).)

## Case in action: a sample sentence

```
konungr  sér    arm  jarls
konungr  sé-r   arm  jarl-s
king(NOM) see-3SG arm(ACC) earl-GEN
"The king sees the earl's arm."
```

`konungr` ("king") is nominative as the subject of the clause; `arm` ("arm") is accusative as the direct object; `jarls` ("of the earl") is genitive, marking possession. All three cases appear in a single short sentence, each doing a different job.

Now a dative example:

```
konungr  gefr    jarli    sverð
konungr  gef-r   jarl-i   sverð
king(NOM) give-3SG earl-DAT sword(ACC)
"The king gives the earl a sword."
```

`jarli` ("to the earl") takes the dative as the indirect object. In a double-object construction like "give X to Y," the standard pattern is indirect object in the dative and direct object in the accusative.
