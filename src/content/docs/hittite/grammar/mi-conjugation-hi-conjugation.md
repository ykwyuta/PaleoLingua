## 2つの活用パターン

ヒッタイト語の動詞は、現在形の1人称単数語尾の違いに基づいて、伝統的に**mi活用（mi-conjugation）**と**hi活用（hi-conjugation）**という2つのグループに分類される。この名称は、それぞれの活用の1人称単数現在形の語尾が -mi で終わるか、-ḫi で終わるかに由来する便宜的な呼び名である。

## 現在形の人称語尾比較

| 人称・数 | mi活用（例：ēš-「いる」） | hi活用（例：dai-「置く」） |
|---|---|---|
| 1人称単数 | eš-mi | dā-ḫḫi |
| 2人称単数 | eš-ši | dā-tti |
| 3人称単数 | ēš-zi | dā-i |
| 1人称複数 | eš-weni | tii̯a-weni |
| 2人称複数 | eš-teni | tii̯a-tteni |
| 3人称複数 | aš-anzi | tii̯-anzi |

```
ē-eš-zi
エーシュツィ
いる-3単現（mi活用）
「彼／彼女／それはいる」

da-a-i
ダーイ
置く-3単現（hi活用）
「彼／彼女はそれを置く」
```

表からわかるように、3人称単数の語尾が mi活用では -zi、hi活用では -i（多くの場合長母音を伴う）となる点が、両活用を見分ける最もわかりやすい手がかりの一つである。

## なぜ2つの活用が存在するのか

この2系統の活用の起源については、印欧語比較言語学上、hi活用の語尾（-ḫi, -tti, -i など）が、印欧祖語の**完了（perfect）**の人称語尾（伝統的に *-h₂e, *-th₂e, *-e などと再建される）に由来するという見方が広く支持されている。つまりヒッタイト語のhi活用動詞は、もともと印欧祖語で「〜した状態にある」という完了的な意味を持っていた形式が、時とともに単純現在の意味に転用されて成立したと考えられている。

これに対してmi活用は、印欧祖語の通常の現在時制の人称語尾（*-mi, *-si, *-ti など）を引き継いだ、より「古典的」な活用パターンである。

## 意味・語彙分布の傾向

hi活用とmi活用のどちらに属するかは、単語ごとに固定されており、語幹の意味によって完全に予測できるわけではない。ただし、状態や位置変化を表す動詞（「置く」「立つ」「座る」など）にhi活用動詞が比較的多く見られる傾向が指摘されており、これはhi活用の起源が印欧祖語の完了（結果状態を表す）にあるとする説と整合的であるとされる。
