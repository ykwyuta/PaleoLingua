## 音節構造の基本パターン

ヒッタイト語の音節は、母音（V）を核として、その前後に子音（C）が付く形を基本とする。理論的に推定される音節構造のパターンは、(C)(C)V(C)(C) のように表すことができ、母音の前後に0〜2個程度の子音が立ちうる。

| パターン | 例（語根・語形の一部） | 備考 |
|---|---|---|
| V | e-（指示代名詞語幹の一部など） | 単独の母音のみ |
| CV | pa-, ta-, ku- | 最も基本的な開音節 |
| CVC | kur-, tar-, pár- | 閉音節 |
| CCV(C) | šta-（例：šta-an-za「立って」の語頭） | 子音連続を含む音節 |

## 楔形文字における子音連続の表し方

楔形文字の音節記号自体は基本的にV・CV・VC・CVCの型しか持たないため、実際の語がこれより複雑な子音連続を含む場合、複数の音節記号を組み合わせて表記する。たとえば語頭に子音連続 št- を持つ語は、š(a)-ta- のように、本来不要な母音を挟んだ記号を連ねて綴られることがある。この場合、綴りに現れる母音字が実際に発音されていたのか、それとも単に楔形文字の制約による見かけ上の母音（いわゆる「空母音」）なのかは、語や文脈によって慎重に判断する必要がある。

```
iš-ta-an-za-ni
イシュタンザニ
心・魂（与位格）
「心に、魂に」
```

上の例では iš- の部分が子音連続 /išt-/ を含む語幹の一部を表しており、綴り上は iš-ta- のように音節記号を重ねて示されている。

## アクセントと音節

ヒッタイト語のアクセント（強勢）の位置については、直接的な証拠（アクセント記号など）が乏しく、確実な復元は難しい。ただし[プレネ表記](/hittite/script-and-phonology/plene-writing-vowel-length/)が強勢音節に相対的に多く現れる傾向があることから、間接的にアクセント位置を推定する手がかりとして利用されている。同系のアナトリア語派の他言語や、印欧祖語のアクセント体系との比較研究も、ヒッタイト語のアクセントを推定するうえで参考にされている。

## 語末の子音連続

ヒッタイト語の名詞の格語尾や動詞の人称語尾には、語末に子音連続を含むものがある（例：3人称複数現在の語尾 -anzi）。このような語末子音連続も、楔形文字では音節記号を組み合わせて表記されるため、語形の正確な音韻構造を復元する際には、綴り上の慣習と実際の発音を区別して考える必要がある。
