## 1つの記号には複数の「読み方」がある

楔形文字を読む上でまず押さえておきたいのは、1つの記号（サイン）が文脈に応じて複数の異なる読まれ方をするという事実である。同じ記号でも、次の3つのどれとして機能しているかによって、読み方も意味もまったく変わる。

1. **表語文字（ロゴグラム）として** — 記号がまるごと1つの単語を表す。
2. **音節文字（シラボグラム）として** — 記号がその単語の「音」だけを借りて、他の語の一部の音節を表す。
3. **限定符（デテルミナティヴ）として** — 発音されず、直後（または直前）の語の意味カテゴリーだけを示す。

## 実例：記号「𒀭」の3つの顔

天空神アンを表す記号 𒀭 を例に、この3つの読み方を実際に見てみよう。

```
𒀭
an
アン
（表語文字）天、天空神アン
```

上のように、この記号は単独で「天」または神アンそのものを表す表語文字として読まれることがある。

```
𒀭
dingir
ディンギル
（表語文字）神（一般名詞としての「神」）
```

同じ記号が、「神」を意味する一般名詞 `dingir` という別の単語の表語文字として読まれることもある。1つの記号が複数の単語を表せるこの現象は、[音節文字としての楔形文字](/sumerian/script-and-phonology/cuneiform-syllabary/)や[表語文字と限定符](/sumerian/script-and-phonology/logograms-and-determinatives/)で扱う話題ともつながっている。

```
𒀭𒋀𒆠
d nanna
ナンナ
（限定符＋固有名詞）月神ナンナ
```

さらに同じ記号が、神名の前に置かれる限定符 `d`（発音しない）としても使われる。この場合、記号そのものは声に出して読まない。

## 読み分けの手がかり

では、粘土板を前にした読み手は、この記号がどの「顔」で使われているかをどう判断するのか。主な手がかりは次の通りである。

| 手がかり | 説明 |
|---|---|
| 位置 | 名詞の直前（または直後）にあり、それ自体が独立した単語として機能していなければ限定符の可能性が高い |
| 文脈 | 前後の語から、記号が単語そのものを表しているか、他の語の音節の一部かを判断する |
| 定型句・ジャンルの知識 | 王碑文や行政文書など、頻出するジャンルの定型表現を知っていると読みの候補を絞りやすい |

## まとめ

楔形文字を読むという作業は、辞書を引くように機械的に1対1で記号と音を対応させる作業ではなく、文脈の中で「この記号は今、表語文字・音節文字・限定符のどれとして機能しているか」を都度判断していく作業である。この判断のプロセスに慣れることが、楔形文字読解の第一歩となる。
