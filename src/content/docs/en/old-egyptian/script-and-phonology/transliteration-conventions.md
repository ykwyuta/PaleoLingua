## What is Egyptological transliteration?

Transliteration is the practice of converting each hieroglyphic sign into the consonant (or consonants) it represents, written in Latin letters plus a handful of special symbols. The 24 signs covered in "[The 24 Uniliteral Signs](/en/old-egyptian/script-and-phonology/uniliteral-signs-alphabet/)" correspond exactly to the set of letters used in Egyptological transliteration.

## The Egyptological transliteration alphabet

| Letter | Conventional pronunciation guide |
|---|---|
| ꜣ | Alef-like sound (commonly held to have been a glottal-stop-like or glottal-fricative-like consonant) |
| ꜥ | Ayin-like sound (commonly held to have been pharyngeal) |
| j | "y"/"ee" |
| y | "y"/"ee" (like ꜣ and ꜥ, also functions as a semi-vowel) |
| w | "w"/"oo" |
| b | b |
| p | p |
| f | f |
| m | m |
| n | n |
| r | r |
| h | h (voiceless glottal fricative) |
| ḥ | h (stronger voiceless pharyngeal fricative) |
| ḫ | h (voiceless velar/uvular fricative) |
| ẖ | h (voiceless palatal fricative) |
| z / s | s |
| š | sh |
| q | k-like (uvular) |
| k | k (velar) |
| g | g |
| t | t |
| ṯ | ch-like |
| d | d |
| ḏ | j-like |

Notice how ḥ, ḫ, and ẖ are all loosely "h"-like sounds, and q, k, g are all loosely "k/g"-like sounds. This reflects the fact that Egyptian distinguished considerably more consonants — particularly consonants articulated deep in the throat — than modern English does.

## Transliteration has no vowel notation

Looking at the table above, the key observation is that **it contains no letters for vowels at all**. As explained in "[The Hieroglyphic Writing System](/en/old-egyptian/script-and-phonology/hieroglyphic-writing-system/)," hieroglyphic phonograms record only consonants (plus semi-vowels). Transliteration therefore also represents, in principle, only the consonant skeleton of a word — it cannot by itself tell you what vowels were actually spoken. This topic is explored further in "[Consonant Phonology and Reconstructed Sound Values](/en/old-egyptian/script-and-phonology/egyptian-consonant-phonology/)."

## Manuel de Codage (MdC): a digital-typing convention

Special symbols like ꜣ, ꜥ, ḥ, ḫ, ẖ, š, ṯ, and ḏ cannot be typed directly on an ordinary keyboard. To make it practical to work with Egyptian transliteration on computers, Egyptologists established **Manuel de Codage (MdC)**, an ASCII-only convention devised in the 1980s and still widely used today. Under MdC, ꜣ is typically written as the digit `3`, ꜥ as `o`, ḥ as capital `H`, ḫ as capital `X`, and so on — each special symbol is replaced with an ordinary letter or digit. This convention let researchers exchange precise Egyptian transliterations by email or in databases long before specialized fonts or Unicode input methods were common, and many hieroglyphic input tools and online dictionaries still accept MdC-style input today.
