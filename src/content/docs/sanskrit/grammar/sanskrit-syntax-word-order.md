サンスクリット語は、ここまでの記事で見てきたように格標示が非常に発達している([格の機能](/sanskrit/grammar/case-system-functions/)を参照)。この記事では、その豊富な格標示が統語論、特に語順や節の結合にどのような影響を与えているかを扱う。

## 基本語順：SOV

サンスクリット語の無標(何も強調しない中立的)な語順は、主語(S)・目的語(O)・動詞(V)の**SOV**型とされる。これは印欧祖語から受け継がれたとされる古い語順で、後代のラテン語やゲルマン語派の一部にも同様の傾向が見られる。

```
रामः फलं खादति।
rāmaḥ phalaṃ khādati.
ラーマハ パラン カーダティ
ラーマ-主格 果実-対格 彼は食べる
「ラーマが果実を食べる。」（S-O-V の標準的な語順）
```

## 格標示による自由な語順

しかし格語尾が名詞・代名詞の文中での役割(主語か目的語か、道具か受益者かなど)を一意に決定するため、サンスクリット語の実際の語順は驚くほど自由である。上の例文は、語順を入れ替えても文法的な役割・基本的な意味は変わらない。

```
फलं रामः खादति।    （O-S-V）
फलं खादति रामः।    （O-V-S）
खादति रामः फलं।    （V-S-O）
```

これらはすべて文法的に正しく、「ラーマが果実を食べる」という命題内容は変わらない。ただし語順の違いは、**情報構造**(何が話題で何が新情報か、何が強調されているか)の違いを反映することが多い。一般に、文頭に置かれた要素は話題や対比の対象として際立たされ、動詞に近い位置に置かれた要素は新情報として強調される傾向があるとされる。

この自由な語順は、[名詞変化の概観](/sanskrit/grammar/noun-declension-overview/)で述べたように格標示が豊富であることの直接の帰結であり、詩の韻律(チャンダス)に合わせて語順を調整する必要がある韻文において特に重要な意味を持つ。

## 形容詞・修飾語の位置

形容詞は修飾する名詞の前に置かれる傾向があるが、これも語順としては比較的自由で、詩文では名詞の後に置かれることも珍しくない。属格による所有表現も、多くの場合被修飾語の前に置かれる。

```
सुन्दरः पुष्पः / पुष्पः सुन्दरः
sundaraḥ puṣpaḥ / puṣpaḥ sundaraḥ
「美しい花」（形容詞が前でも後でも文法的に成立する）
```

## 後置詞的な要素

サンスクリット語には印欧語族に典型的な前置詞がほとんど存在せず、代わりに格語尾自体が前置詞に相当する意味(「〜において」「〜から」など)を担う。一部の副詞的な小辞(saha「〜と共に」など)は、修飾する名詞の**後**に置かれる後置詞的な用法を持つ(格自体が意味を担うため、これらは純粋な前置詞というより、格の意味を補強する副詞的小辞に近い)。

```
रामेण सह गच्छामि।
rāmeṇa saha gacchāmi.
ラーメーナ サハ ガッチャーミ
ラーマ-具格 〜と共に 私は行く
「私はラーマと共に行く。」（sahaはrāmeṇaの後に置かれる）
```

## 節の結合：分詞と絶対処格

サンスクリット語は、[分詞](/sanskrit/grammar/participles-in-sanskrit/)で見たように、定形動詞を用いた従属節(英語のwhen節・after節に相当するもの)よりも、分詞・絶対分詞(-tvā)・絶対処格構文を用いて節を結合する傾向が強い。

```
सूर्ये उदिते सः गच्छति।
sūrye udite saḥ gacchati.
スーリェー ウディテー サハ ガッチャティ
太陽-処格 昇った-処格 彼-主格 彼は行く
「太陽が昇ると、彼は行く。」（絶対処格による副詞節）
```

このように、主節と異なる主語を持つ従属的な状況は絶対処格で、主節と同じ主語を持つ動作の連続は絶対分詞(-tvā)で表現するのが、定形の従属節を使うよりも典型的なサンスクリット語らしい構文である。

## 関係代名詞 yad〜tad の相関構文

定形動詞を用いた従属節が必要な場合(特に関係節)には、関係代名詞 **यद् yad**(「〜するところの」)と指示代名詞 **तद् tad**(「その」)を組にした**相関構文**が用いられる。これは英語の関係代名詞とは異なり、従属節・主節の両方に代名詞が現れる点が特徴的である。

```
यः नरः वदति सः मम मित्रम्।
yaḥ naraḥ vadati saḥ mama mitram.
ヤハ ナラハ ヴァダティ サハ ママ ミトラム
〜するところの-主格 人-主格 彼は話す その-主格 私の 友人
「話しているその人は私の友人だ。」
```

関係代名詞節(yaḥ narah vadati「話している人」)が先行し、それを受ける形で指示代名詞(saḥ「その人」)を含む主節が続く、という相関的な構造がサンスクリット語の関係節の典型的なパターンである。
