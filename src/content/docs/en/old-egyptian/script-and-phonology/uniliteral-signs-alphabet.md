## Egyptian's "alphabet"

Hieroglyphic writing includes hundreds of distinct signs, but among them are 24 that each represent a **single consonant** — the so-called uniliteral signs. Ancient Egyptians never taught these as a stand-alone formal "alphabet," but modern instruction conventionally calls them one because they are the natural starting point for learning to read. In principle, any word can be spelled (if somewhat unidiomatically) using only uniliteral signs.

## The 24 uniliteral signs

The table below lists each sign's glyph, Gardiner code (the standard reference numbering for hieroglyphic signs), transliteration, and what it originally depicted. The special transliteration letters — ꜣ, ꜥ, ḥ, ḫ, ẖ, š, ṯ, ḏ, and so on — are covered in detail in "[Transliteration Conventions](/en/old-egyptian/script-and-phonology/transliteration-conventions/)".

|---|---|---|---|
| 𓄿 | G1 | ꜣ | Egyptian vulture |
| 𓇋 | M17 | j | Flowering reed |
| 𓇌 | M17A | y (variant of j) | Pair of reeds |
| 𓏭 | Z4 | y / ï | Pair of strokes (also used as a dual marker) |
| 𓂝 | D36 | ꜥ | Forearm |
| 𓅱 | G43 | w | Quail chick |
| 𓃀 | D58 | b | Lower leg/foot |
| 𓊪 | Q3 | p | Stool/reed mat |
| 𓆑 | I9 | f | Horned viper |
| 𓅓 | G17 | m | Owl |
| 𓈖 | N35 | n | Ripple of water |
| 𓂋 | D21 | r | Human mouth |
| 𓉔 | O4 | h | Reed shelter |
| 𓎛 | V28 | ḥ | Twisted wick |
| 𓐍 | Aa1 | ḫ | Sieve or placenta |
| 𓄡 | F32 | ẖ | Animal belly and tail |
| 𓊃 | O34 | z / s | Door bolt |
| 𓋴 | S29 | s / ś | Folded cloth |
| 𓈙 | N37 | š | Garden pool |
| 𓈎 | N29 | q | Hill slope |
| 𓎡 | V31 | k | Basket with handle |
| 𓎼 | W11 | g | Jar stand |
| 𓏏 | X1 | t | Bread loaf |
| 𓍿 | V13 | ṯ | Tethering rope |
| 𓂧 | D46 | d | Hand |
| 𓆓 | I10 | ḏ | Cobra |

Note that this is not a neat one-to-one letter correspondence like a modern alphabet — each sign began life as a picture of something concrete. Notice, too, that some consonants have more than one sign (z/s has both 𓊃 and 𓋴), and j has more than one variant form (𓇋 and 𓇌).

## Spelling a word with uniliteral signs alone

Stringing together uniliteral signs lets you spell essentially any word phonetically (though real inscriptions often preferred a logogram or a bi-/triliteral sign where one existed).

<p class="hieroglyph">𓂋𓈖</p>

```
rn
name
```

<p class="hieroglyph">𓊪𓂋</p>

```
pr
house
```
