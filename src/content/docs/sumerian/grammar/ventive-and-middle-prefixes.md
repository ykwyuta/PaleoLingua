## 「方向・態」スロットの主役たち

[動詞接頭辞連鎖の構造（概観）](/sumerian/grammar/verbal-prefix-chain-overview/)で見た②「方向／態接頭辞」スロットに現れる代表的な要素が、`mu-`（求心）と `ba-`（中在態）である。すでに[人称接辞と動詞の基本構造](/sumerian/grammar/personal-affixes-verb-basics/)で `mu-` の基本的な働きに触れたが、本記事では `ba-`・`bi2-` との対比を通じて、この接頭辞群の役割をもう少し掘り下げる。

## mu-：話し手（求心的な中心）へ向かう

`mu-` は、動作が話し手や物語上の視点の中心に向かって行われることを示す接頭辞である。

```
𒈬𒄄
mu-gi4
ム・ギ
（求心）-返す
「彼がそれをこちらへ返した」
```

## ba-：中在態、視点から離れた出来事

`ba-` は、動作主の意図性が弱い出来事や、動作の結果が主語自身に及ぶ「中在態（middle voice）」的な文脈、あるいは話し手の視点から離れた場所での出来事を示すのに用いられる。

```
𒁀𒄄
ba-gi4
バ・ギ
（中在態）-返る
「それが（あちらへ）返された」「それは戻っていった」
```

同じ語根 `gi4`（返す・戻る）でも、`mu-` と `ba-` のどちらが付くかによって、動作の方向性や視点の置き方が変わる点に注目したい。

## bi2-：非人称の処格・向格項を指す

`bi2-` は、与格や処格にあたる項が「人ではない何か（物や場所）」であることを示す人称接頭辞である。③のスロット（人称・格接頭辞）に属する。

```
𒉈𒃻
bi2-ĝar
ビ・ガル
（その中に）-置く
「彼／彼女はそれ（の中）に置いた」
```

## まとめ表

| 接頭辞 | スロット | 主な働き | カタカナ読み |
|---|---|---|---|
| `mu-` | ②方向／態 | 話し手・視点の中心への求心 | ム |
| `ba-` | ②方向／態 | 中在態、視点から離れた出来事 | バ |
| `bi2-` | ③人称・格 | 非人称の処格・向格項の指示 | ビ |
