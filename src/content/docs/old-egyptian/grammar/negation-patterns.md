## 否定辞は文の種類によって使い分けられる

古エジプト語の否定表現は、日本語の「ない」や英語の "not" のようにひとつの語で済ませるのではなく、否定する対象の**文の種類**によっていくつかの否定辞を使い分ける。中心となるのは **n** と **nn** で、これに補助的な否定表現として **nfr** が加わる。

## n：動詞形の否定

**n** は、[sḏm=f形](/old-egyptian/grammar/sdm-f-verb-form/)のような動詞形を中心とする「否定動詞形」構文で使われる、もっとも基本的な否定辞である。動詞の直前に置かれ、動作が起こらなかったことを表す。

<p class="hieroglyph">𓈖𓋴𓆓𓅓𓆑</p>

```
n sḏm=f
ン・セジェム・エフ
否定・聞く=彼
「彼は聞かなかった」（n による sḏm=f の否定）
```

n はまた、文全体を否定する一部の構文にも使われる、動詞否定の中心的な否定辞である。

## nn：副詞文・名詞文の否定

**nn** は、[副詞文と名詞文](/old-egyptian/grammar/adverbial-nominal-sentences/)の記事で扱う副詞文（「AはYにある」型）や一部の名詞文、その他の非動詞述語文を否定するのに使われる。また、動詞形の一部も nn によって否定される。

<p class="hieroglyph">𓈖𓈖𓊪𓂋𓆑</p>

```
nn pr=f
ンン・プル・エフ
否定・家=彼の
「彼の家はない」（nn による非動詞文の否定、枠組みを示す例）
```

n が主に動詞形（sḏm=f型）を否定するのに対し、nn は副詞文・名詞文のような非動詞述語文の否定に使われる、という基本的な役割分担をまず押さえておくとよい。

## nfr：補助的な否定・非存在表現

**nfr**（「良い、美しい、完全な」という語根と同じ形）は、否定辞としても用いられ、「〜がない」「まだ〜していない」といった否定存在文・否定完了のニュアンスを表す補助的な用法を持つ。n や nn ほど中心的な否定辞ではなく、より限られた構文で使われる二次的な否定手段として位置づけられており、その正確な統語的条件についてはエジプト学の中でも細部の議論が続いている。ここでは「否定に使われる語根の一つに、"良い"を意味する nfr と同じ形が存在する」という大枠だけを押さえておけば十分である。
