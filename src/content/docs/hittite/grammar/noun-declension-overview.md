## 2つの性：共通性と中性

ヒッタイト語の名詞は、文法上2つの**性**に分かれる。

- **共通性（common gender）**：人間・動物など、伝統的な「有生」に近い名詞のクラス。印欧諸語の男性・女性の区別に相当するものが融合した結果と考えられている。
- **中性（neuter）**：物・抽象概念など、伝統的な「無生」に近い名詞のクラス。

この2性体系は、ラテン語やギリシア語に見られる男性・女性・中性の3性体系とは異なり、アナトリア語派に特徴的な古い段階の名残を示すと考えられている。中性名詞の統語的なふるまいの特殊性については、[中性の能格](/hittite/grammar/neuter-ergative-case/)で詳しく扱う。

## 格の一覧と機能

| 格 | 主な機能 | 単数語尾の例（antuḫša-「人」） |
|---|---|---|
| 主格（Nominative） | 自動詞の主語、他動詞の主語（共通性名詞） | antuḫšaš |
| 対格（Accusative） | 他動詞の直接目的語 | antuḫšan |
| 属格（Genitive） | 所有・所属（「〜の」） | antuḫšaš |
| 与位格（Dative-Locative） | 間接目的語（「〜に」）、場所（「〜で」） | antuḫši |
| 奪格（Ablative） | 起点（「〜から」）、比較の基準、道具（後代） | antuḫšaz |
| 具格（Instrumental） | 手段・道具（「〜によって」） | antuḫšit |
| 能格（Ergative） | 中性名詞が他動詞の主語になる場合の特別な格 | （中性名詞にのみ存在） |

与位格と位格が単一の格に融合している点、また奪格が起点だけでなく比較や道具の意味も担うようになった点は、ヒッタイト語の格体系の大きな特徴である。

## 具体例：antuḫša-「人」の格変化（単数）

```
antuḫša-aš
アントゥフシャシュ
人-主格
「人が」（主語）

antuḫša-an
アントゥフシャン
人-対格
「人を」（目的語）

antuḫša-i
アントゥフシ
人-与位格
「人に、人のところで」
```

## 複数形について

複数形は単数形とは異なる語尾の組み合わせを持ち、主格複数と対格複数は多くの語幹で語尾が異なるものの、属格複数と与位格複数は主格・対格とは別の共通の語尾を用いる傾向がある。複数の格語尾の詳細や、格語尾が付く前の語幹の交替（音節の脱落など）は語幹の種類によって異なり、個別の語彙ごとに確認する必要がある。

## 中性名詞の主格・対格の同形性

印欧諸語の中性名詞に共通する特徴として、ヒッタイト語の中性名詞も**主格と対格が同じ形**を取る（自動詞の主語であっても他動詞の目的語であっても同じ語形になる）。この中性名詞が他動詞の主語になる場合にのみ現れる特別な格標示（能格）については、次の記事[中性の能格](/hittite/grammar/neuter-ergative-case/)で扱う。
