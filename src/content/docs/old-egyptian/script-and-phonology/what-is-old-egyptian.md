## 古エジプト語の基礎データ

古エジプト語（Ancient Egyptian）は、紀元前4千年紀末から後代のコプト語に至るまで、ナイル川流域で約4000年にわたって話され続けた言語である。人類史上もっとも長く文字記録が残る言語の一つであり、その表記体系がヒエログリフ（聖刻文字、hieroglyph）である。

| 項目 | 内容 |
|---|---|
| 話された地域 | エジプト（ナイル川流域） |
| 文字記録の期間 | 前3200年頃〜後5世紀頃（ヒエログリフ・デモティック使用終了まで。その後コプト語として20世紀初頭まで話し言葉として存続） |
| PaleoLinguaが主に扱う段階 | 中エジプト語（前2100年頃〜前1600年頃に日常語として使用され、その後も「古典エジプト語」として2000年近く文語に使われ続けた） |
| 系統 | アフロ・アジア語族の独立した一語派（セム語派・ベルベル語派・クシ語派・チャド語派などと並ぶ） |
| 文字 | ヒエログリフ（聖刻文字）。のちに神官文字（ヒエラティック）、民衆文字（デモティック）、コプト文字が派生 |
| 基本語順 | VSO（動詞－主語－目的語。動詞文の場合の語順） |
| 文法類型 | 子音語根に基づく屈折、性（男性・女性）と数（単数・双数・複数）の区別を持つ |

## エジプト語の5つの発展段階

エジプト語は、文法・語彙の変化に応じて伝統的に5つの段階に区分される。

| 段階 | おおよその時期 | 特徴 |
|---|---|---|
| 古エジプト語（Old Egyptian） | 前3200年頃〜前2100年頃 | ピラミッド・テキストなど最古期の宗教文書に見られる段階 |
| 中エジプト語（Middle Egyptian） | 前2100年頃〜前1600年頃 | 「古典エジプト語」。文学・宗教・碑文の標準語として後代まで規範であり続けた |
| 後期エジプト語（Late Egyptian） | 前1600年頃〜前700年頃 | 新王国期の日常語。定冠詞の発達など文法が大きく変化 |
| 民衆文字エジプト語（Demotic Egyptian） | 前700年頃〜後5世紀頃 | 簡略化した草書体（デモティック）で記される |
| コプト語（Coptic） | 後1世紀頃〜現在（教会での典礼言語として） | ギリシア文字＋独自字母で表記される最終段階。母音表記を持つため発音復元の重要な手がかりとなる |

## 系統：アフロ・アジア語族の一語派

エジプト語は、セム語派（アッカド語・ヘブライ語・アラビア語など）、ベルベル語派、クシ語派、チャド語派などとともにアフロ・アジア語族を構成する独立した一語派である。セム語と同様に子音語根に基づく語形成を持つ点で類型的な類似が見られるが、セム語派そのものに属するわけではなく、両者は共通の祖語から分岐した姉妹関係にあると考えられている。

## PaleoLinguaが扱う範囲：中エジプト語を中心に

エジプト学の入門文法書（ガーディナー、アラン等）が教材とするのは、主に中エジプト語である。中エジプト語は中王国時代（前2100年頃〜前1600年頃）に日常語として話されていたが、その後も新王国時代以降、宗教文書や公式碑文の規範的な文語として長く使われ続けた（ちょうどラテン語が中世以降のヨーロッパで学術語として使われ続けたのと似ている）。PaleoLinguaの古エジプト語の記事も、特に断らない限り中エジプト語の文法・語彙・文字資料を中心に扱う。

## 現存する文献

現存するヒエログリフ資料は、ピラミッドの内壁に刻まれた『ピラミッド・テキスト』（現存最古の大規模宗教文書群）、棺に記された『コフィン・テキスト』、新王国時代以降の『死者の書』といった来世に関する文書群、『シヌヘの物語』『ウェストカー・パピルス』などの物語文学、『プタハヘテプの教訓』のような処世訓（知恵文学）、そして墓碑銘・王碑文・境界碑文などの碑文資料に大別できる。これらは石碑・墓壁・パピルスなど多様な媒体に、ヒエログリフまたはその筆記体である神官文字（ヒエラティック）で記されている。
