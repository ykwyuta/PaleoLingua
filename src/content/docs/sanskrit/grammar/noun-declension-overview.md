サンスクリット語（संस्कृत saṃskṛta）の名詞は、印欧語族の中でも屈折体系がとりわけ豊かに保たれた言語として知られる。名詞・形容詞・代名詞は、**数**・**格**・**性**という3つの文法カテゴリーに従って語形変化（曲用、declension）する。この記事では、以降の各論記事（[a語幹男性名詞の格変化](/sanskrit/grammar/a-stem-masculine-declension/)、[格の機能](/sanskrit/grammar/case-system-functions/)など）を読むための見取り図として、全体像を整理する。

## 3つの数（vacana）

サンスクリット語はラテン語やギリシア語と同様、印欧祖語に遡る**双数（dual）**を単数・複数と並んで完全な文法範疇として保持している。

| 数 | サンスクリット名 | 用法 |
|---|---|---|
| 単数（singular） | एकवचन ekavacana | 1つのものを指す |
| 双数（dual） | द्विवचन dvivacana | 2つのもの、対になるものを指す（目・手・両親など） |
| 複数（plural） | बहुवचन bahuvacana | 3つ以上のものを指す |

双数は現代インド語では失われたが、古典サンスクリットでは規則的に使われ続けた。特に「目」「手」「両親」のように自然に対をなす名詞では双数が好んで用いられる。

## 8つの格（vibhakti）

サンスクリット語の名詞変化表（曲用表）は伝統的に8格の順で並べられる。この順序自体がパーニニ文法（後述）に基づく伝統的な配列であり、以下の記事でもこの順に従う。

| 格 | サンスクリット名 | 中心的な機能（概要） |
|---|---|---|
| 主格（Nominative） | प्रथमा prathamā（「第一」） | 文の主語 |
| 呼格（Vocative） | सम्बोधन sambodhana | 呼びかけ |
| 対格（Accusative） | द्वितीया dvitīyā（「第二」） | 直接目的語、運動の到達点 |
| 具格（Instrumental） | तृतीया tṛtīyā（「第三」） | 手段・道具・動作主（受動文） |
| 与格（Dative） | चतुर्थी caturthī（「第四」） | 間接目的語、目的・受益者 |
| 奪格（Ablative） | पञ्चमी pañcamī（「第五」） | 分離の起点、比較の基準 |
| 属格（Genitive） | षष्ठी ṣaṣṭhī（「第六」） | 所有・所属 |
| 処格（Locative） | सप्तमी saptamī（「第七」） | 場所・時・状況 |

伝統文法では呼格を独立の格として数えず「主格の一種」とみなす流儀もあるが、実際の語形は主格と異なることが多いため、本サイトでは学習上の便宜から8格として一貫して扱う。各格が実際にどのような意味・統語機能を担うかは、[格の機能](/sanskrit/grammar/case-system-functions/)で例文とともに詳しく扱う。

## 3つの性（liṅga）

サンスクリット語の名詞は、ラテン語やギリシア語と同じく**男性（पुंलिङ्ग puṃliṅga）**・**女性（स्त्रीलिङ्ग strīliṅga）**・**中性（नपुंसकलिङ्ग napuṃsakaliṅga）**の3性を区別する。文法上の性は必ずしも生物学的な性と一致せず、たとえば「木」を表す vṛkṣa- は男性名詞、「川」を表す nadī- は女性名詞というように、語彙ごとに固定されている。

性の違いは特に語尾変化のパターンに影響し、同じ語幹の種類（例：a語幹）であっても男性・中性では異なる語尾セットを、女性では別の語幹クラス（ā語幹やī語幹）に近い語尾セットを用いることが多い。

## 語幹の種類：母音語幹と子音語幹

サンスクリット語の名詞曲用は、語幹（stem）が母音で終わるか子音で終わるかによって大きく2つのグループに分かれる。

- **母音語幹（vowel stems）**：語幹末が -a, -ā, -i, -ī, -u, -ū, -ṛ などの母音で終わるもの。中でも -a語幹（男性・中性）と -ā語幹（女性）が名詞全体の中で圧倒的に高頻度であり、初学者が最初に習得すべき変化パターンである。[a語幹男性名詞の格変化](/sanskrit/grammar/a-stem-masculine-declension/)で詳しく扱う。
- **子音語幹（consonant stems）**：語幹末が -t, -n, -s, -c, -ah など子音で終わるもの（例：現在分詞語幹 -ant-、-an語幹の rājan-「王」、-as語幹の manas-「心」など）。母音語幹に比べ語尾添加時の連声（サンディ）変化が複雑で、語幹自体が格によって強形・弱形の交替を示すことも多い。

この2分類はあくまで見取り図であり、実際には語幹末の母音・子音の種類ごとにさらに細かいサブクラス（i語幹、u語幹、ṛ語幹、n語幹、s語幹など）が存在する。本サイトでは頻度の高いa語幹男性名詞を代表例として詳しく扱い（次の記事）、他の語幹クラスについては個別の記事で順次補っていく。

## 代名詞との関係

人称代名詞（aham「私」、tvam「あなた」）や指示代名詞（tad「それ・彼・彼女」）は、名詞と共通の格体系（8格×3数）を用いるものの、語形自体は名詞の規則変化から外れた独自のパターンを持つ。これについては[代名詞の格変化](/sanskrit/grammar/pronoun-declension/)で扱う。
