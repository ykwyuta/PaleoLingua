サンスクリット語の数詞は、名詞・形容詞と同じく性・格変化を行うが、その変化パターンは数によってかなり異なる振る舞いを見せる。この記事では基数詞1〜10を中心に、それぞれがどのように格変化するか(あるいはしないか)を確認し、続いて序数詞の作り方を扱う。

## 基数詞1〜10

| 数 | 語 | 備考 |
|---|---|---|
| 1 | एक eka | 単数のみ。代名詞的な格変化(tad型の語尾)を一部に持つ |
| 2 | द्वि dvi | 双数のみで変化。性による語形差はわずか |
| 3 | त्रि tri | 複数のみ。性によって語形が大きく異なる |
| 4 | चतुर् catur | 複数のみ。性によって語形が大きく異なる |
| 5 | पञ्च pañca | 複数のみ。性による語形差がない(不変) |
| 6 | षष् ṣaṣ | 複数のみ。性による語形差がない |
| 7 | सप्त sapta | 複数のみ。性による語形差がない |
| 8 | अष्ट aṣṭa | 複数のみ。性による語形差がない |
| 9 | नव nava | 複数のみ。性による語形差がない |
| 10 | दश daśa | 複数のみ。性による語形差がない |

5から10までの数詞は、格変化はするものの性による語形の違いを持たない(男性・女性・中性いずれの名詞を修飾する場合も同じ形を用いる)点で共通している。

## eka「1」:単数のみ、部分的に代名詞的

eka「1」は数えられる対象が単数である以上、当然ながら単数でしか用いられない。格変化そのものは名詞のa語幹(男性 eka-、中性 eka-)・ā語幹(女性 ekā-)に近いが、与格・奪格・処格の一部には[代名詞の格変化](/sanskrit/grammar/pronoun-declension/)で見た tasmai, tasmāt, tasmin のような**代名詞語尾**(-smai, -smāt, -sminなど)が用いられることがある。

```
एकः पुरुषः एकं ग्रामं गच्छति।
ekaḥ puruṣaḥ ekaṃ grāmaṃ gacchati.
エーカハ プルシャハ エーカン グラーマン ガッチャティ
一人-主格(男) 人-主格 一つ-対格(中) 村-対格 彼は行く
「一人の人が一つの村へ行く。」
```

## dvi「2」:双数のみ

dvi「2」は本質的に双数の意味を持つ語であり、双数変化のみを行う。男性の主格・呼格・対格に dvau、女性・中性に dve という形を取る。

```
द्वौ बालकौ क्रीडतः।
dvau bālakau krīḍataḥ.
ドヴォー バーラカウ クリーダタハ
二人-主格(男双) 少年-主格双 彼らは遊ぶ
「二人の少年が遊ぶ。」
```

## tri「3」・catur「4」:複数のみ、性で語形が大きく異なる

tri「3」と catur「4」は複数変化のみを行うが、eka・dviとは異なり、**性によって語幹の形自体が大きく変わる**という際立った特徴を持つ。

| 数 | 男性主格複数 | 女性主格複数 | 中性主格複数 |
|---|---|---|---|
| 3 | त्रयः trayaḥ | तिस्रः tisraḥ | त्रीणि trīṇi |
| 4 | चत्वारः catvāraḥ | चतस्रः catasraḥ | चत्वारि catvāri |

このように女性形(tisraḥ, catasraḥ)が男性・中性形とまったく異なる語幹を持つのは、サンスクリット語の数詞の中でも3と4に特有の現象である。

```
तिस्रः कन्याः गायन्ति।
tisraḥ kanyāḥ gāyanti.
ティスラハ カニャーハ ガーヤンティ
三人-主格(女) 少女たち-主格 彼女らは歌う
「三人の少女が歌う。」
```

## 11以上の数詞について

11から19までの数詞(एकादश ekādaśa「11」など)は独自の複合的な形を取り、20(विंशति viṃśati)、30(त्रिंशत् triṃśat)などの十位の数詞はī語幹・ti語幹の女性名詞として扱われる。100(शत śata)、1000(सहस्र sahasra)は中性名詞として通常の名詞のように格変化する。数が大きくなるにつれて数詞は名詞的な性格を強め、修飾する名詞に対して同格ではなく属格で結びつく傾向が強まる(例:「100人の人」は「人々の100」に近い構造を取ることがある)。

## 序数詞

序数詞(「第〜の」を表す語)は基数詞から規則的・半規則的な接尾辞によって作られ、通常の形容詞と同じくa語幹(男性・中性)・ā語幹(女性)で格変化する。

| 基数 | 序数(男性形) | 意味 |
|---|---|---|
| 1 | प्रथम prathama- | 第1の |
| 2 | द्वितीय dvitīya- | 第2の |
| 3 | तृतीय tṛtīya- | 第3の |
| 4 | चतुर्थ caturtha- | 第4の |
| 5 | पञ्चम pañcama- | 第5の |
| 6 | षष्ठ ṣaṣṭha- | 第6の |
| 7 | सप्तम saptama- | 第7の |
| 8 | अष्टम aṣṭama- | 第8の |
| 9 | नवम navama- | 第9の |
| 10 | दशम daśama- | 第10の |

```
सः प्रथमः पुत्रः।
saḥ prathamaḥ putraḥ.
サハ プラタマハ プトラハ
彼-主格 第一の-主格(男) 息子-主格
「彼が最初の息子だ。」
```

序数詞は「1」「2」「3」に対応する prathama-, dvitīya-, tṛtīya- が基数詞 eka, dvi, tri とは語根を共有しない独自の語形である点に注意したい(英語の first, second, third が one, two, three と語根を共有しないのと類似した現象である)。
