## もう一つのシュメール語、エメサル

本サイトでここまで扱ってきたシュメール語は、標準的な方言・文体である「エメギル（eme-gir15、直訳「王の言葉」）」に基づくものである。これとは別に、特定のジャンル・文脈でのみ用いられる「エメサル（eme-sal、直訳「か細い／上品な言葉」）」と呼ばれる特殊な文体（方言というより社会言語学的な変種、レジスターとされることが多い）が存在する。

## エメサルが使われる場面

エメサルが現れる文脈は、主に次の2つに限られる。

| 使用場面 | 説明 |
|---|---|
| 神話・文学作品中の女神の台詞 | 物語の中で女神が発言する部分がエメサルで書かれることがある |
| 哀歌（バラグ、エルシェンマなど） | ガラ（gala）と呼ばれる神官が朗唱する哀歌のジャンルでは、地の文も含めてエメサルで書かれる |

このことから、エメサルは単なる地域方言ではなく、特定のジャンル・話者に結び付いた文体的な変種（レジスター）として機能していたと考えられている。

## 語彙の違い：nin と gašan

エメサルとエメギルの違いは、規則的な音韻対応を示す語もあれば、まったく別の単語に置き換わる語もあり一様ではない。よく知られた例が、「女主人、女神」を意味する語である。

```
𒎏
nin
ニン
（エメギル）女主人、女神
```

```
𒃽
gašan
ガシャン
（エメサル）女主人、女神
```

`nin` と `gašan` は意味は同じ「女主人・女神」だが、語形も表記に使われるサインもまったく異なる。これは規則的な音韻変化というより、エメサルの語彙が独自の単語セットを持つ場合があることを示す例である。

## 学習上の位置づけ

エメサルは本サイトの入門的な例文にはほとんど登場しないが、讃歌や哀歌といったジャンルの原典を読む際には必須の知識となる。エメサルとエメギルの対応関係の詳細（規則的な音韻対応の一覧など）は現在も研究が進んでいる分野であり、本記事ではまず「シュメール語には話者・ジャンルによって使い分けられる特殊な文体が存在する」という事実を押さえておきたい。
