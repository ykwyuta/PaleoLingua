## サンユクタークシャラとは何か

サンスクリット語には、母音を挟まずに複数の子音が連続する**子音連結（consonant cluster）**が非常に多く現れる。デーヴァナーガリー文字はこれを、単に子音字を横に並べるのではなく、複数の子音字を1つの視覚的な合字（連結文字、**サンユクタークシャラ（संयुक्ताक्षर saṃyuktākṣara、「結合した音節文字」）**）にまとめて表記するのが原則である。この仕組みは、[デーヴァナーガリー文字の概要](/sanskrit/script-and-phonology/devanagari-script-overview/)で説明した**ヴィラーマ（्）**の応用形にほかならない。

## 合字が作られる仕組み

原理は単純である。子音字Aに母音を伴わせず（ヴィラーマを付けて）、直後の子音字Bに直接つなげる。文字として書く際には、多くの場合ヴィラーマの記号そのものは表に現れず、2つの子音字の字形が視覚的に融合・簡略化される。

| 段階 | 表記 | 説明 |
|---|---|---|
| 1. 単独の子音（母音付き） | क + त | ka, ta（それぞれ独立した音節） |
| 2. ヴィラーマで母音を消す | क् + त | k（母音なし）+ ta |
| 3. 合字として結合 | क्त | kta（1つの合字グリフ） |

क्त（kta）のように、多くの場合は前の子音字の右側部分（垂直画）が省略されて後続の子音字と直接つながる形になる。合字の字形パターンには一定の規則性があるが、子音の組み合わせによって簡略化のされ方が大きく異なるため、初学者にとっては個別に字形を覚える必要がある部分でもある。

## 代表的な合字の例

| 合字 | 構成要素 | IAST | 例語 |
|---|---|---|---|
| क्ष | क् + ष | kṣa | क्षत्रिय kṣatriya「武人階級」 |
| ज्ञ | ज् + ञ | jña | ज्ञान jñāna「知識」 |
| त्र | त् + र | tra | पुत्र putra「息子」 |
| द्व | द् + व | dva | द्वार dvāra「扉」 |
| श्व | श् + व | śva | अश्व aśva「馬」 |
| स्त | स् + त | sta | स्तुति stuti「賛歌」 |
| ह्म | ह् + म | hma | ब्रह्मन् brahman（ब्राह्मण brāhmaṇaにも同要素） |

このうち क्ष（kṣa）と ज्ञ（jña）は特に**不規則な合字**として知られる。元の2文字の字形からはにわかに想像しにくい、独自の慣用的な字形へと簡略化されているためで、初学者はこれらを個別の記号としてほぼ丸ごと暗記することになる。一方 त्र（tra）や द्व（dva）のような合字は、構成要素の字形がある程度残っており、規則性を見出しやすい。

## 3つ以上の子音が連結する場合

サンスクリット語では3つの子音が連続することも珍しくない。たとえば **कार्त्स्न्य** kārtsnya「全体性」のような語では、rtsny のように複数の子音が連なる。この場合、合字はさらに複雑な形に積み重なる（あるいは実務上は一部を分離して書く慣習が用いられる場合もある）。合字の複雑さは、写本や版によって字形の慣習が異なることもあり、[サンディ（連声）](/sanskrit/script-and-phonology/sandhi-external-internal/)の規則によって語境界で新たな子音連結が生じることも、合字の多様性に拍車をかけている。

## 合字の翻字

IASTなどラテン文字による翻字では、合字を1つの記号にまとめる必要はなく、単純に子音字を並べて書けばよい。

| デーヴァナーガリー合字 | IAST翻字 |
|---|---|
| क्ष | kṣ（+母音があれば kṣa などとなる） |
| ज्ञ | jñ（+母音があれば jña などとなる） |
| त्र | tr（+母音があれば tra などとなる） |

つまり、デーヴァナーガリーでは視覚的な結合（合字化）という形で示される情報が、IAST翻字では単なる文字の並びとして表現される。この対応関係を理解しておくと、合字を見て身構える必要がなくなり、翻字を介して構成子音を素早く分解できるようになる。
