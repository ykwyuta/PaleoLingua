## 位取りのない十進法

古代エジプトの数字体系は、現代の私たちが使う位取り記数法（アラビア数字のように、同じ「1」でも位置によって1・10・100を表すような仕組み）とは異なり、**位取りを持たない十進法（非位取り十進法）**であった。10の各べき乗（1・10・100・1000・10000・100000・1000000）ごとに専用の記号があり、数はそれらの記号を必要な回数だけ**繰り返して並べる（＝単純な加算）**ことで表された。

## 1を表す記号：単なる縦線の反復

もっとも基本的な数字記号は、1を表す単純な縦の線（ガーディナー番号 Z1）である。

<p class="hieroglyph">𓏤</p>

```
1
ワン（学習用の便宜的な呼び方。エジプト語の実際の数詞は wꜥ などの語で発音された）
数字の「1」を表す縦線1本
```

2から9までの数は、この縦線を必要な数だけ**繰り返して並べる**ことで表される。たとえば3は縦線3本、7は縦線7本というように、単純な反復・加算によって数が構成される。これは現代の位取り記数法とは根本的に異なる発想であり、たとえば「23」のような数字を作るのに、「2」と「3」という異なる記号を位置で組み合わせる必要はなく、それぞれの位のべき乗の記号を必要な数だけ並べればよい。

## 10以上のべき乗：専用記号（ガーディナー番号のみで紹介）

10・100・1000・10000・100000・1000000のそれぞれの位には、1本の縦線とはまったく異なる専用の絵文字的記号が割り当てられている。これらのグリフはこの記事の検証済み文字一覧には含まれていないため、実際のUnicode文字は示さず、ガーディナー番号と、その記号が元々何を描いたものかという説明にとどめる。

| 位 | ガーディナー番号 | 元の絵 |
|---|---|---|
| 10 | V20 | かかとの骨（足枷、ホブル）の形 |
| 100 | V1 | とぐろを巻いた縄 |
| 1000 | M12 | 蓮（ハス）の花 |
| 10000 | D50 | 曲げた指 |
| 100000 | I8 | オタマジャクシ（カエルの幼生） |
| 1000000 | C11 | 両腕を高く掲げてひざまずく神ヘフ（Heh、「無限・永遠」を象徴する神） |

## 加算による数の構成

エジプト式の数の書き方では、それぞれの位の記号を必要な回数だけ並べて、それらを単純に足し合わせることで数を表す。たとえば「1000000＋100000＋100＋10＋3」のように、大きな位から小さな位へと記号を並べ、読み手はそれぞれの記号の個数を数えて合計を求める。位取り記数法に慣れた現代人にとっては、同じ記号を何度も繰り返し描く必要がある点が非効率に感じられるかもしれないが、記念碑や行政記録において数量を視覚的に明確に示すには十分機能する体系だった。
