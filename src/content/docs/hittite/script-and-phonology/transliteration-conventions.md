## なぜ翻字規則が必要か

楔形文字そのものは専門家以外にはほぼ読めないため、ヒッタイト学（Hittitology）の研究・教育では、楔形文字をラテン文字に置き換えた**翻字（transliteration）**を用いるのが標準的な方法である。翻字にはアッシリア学（Assyriology）と共通の記号法が多く用いられ、1つの記号列を見ただけで「これは音節記号なのか、シュメログラムなのか、限定符なのか」を判別できるように工夫されている。

## 基本ルール一覧

| 記号・書式 | 意味 | 例 |
|---|---|---|
| 小文字＋ハイフン | 音節記号どうしの境界 | e-eš-zi（「彼はいる」） |
| 大文字（ローマン体） | シュメログラム | LUGAL「王」 |
| 大文字＋ピリオド区切り | 複数の記号から成る合成シュメログラム | LUGAL.GAL「大王」 |
| イタリック体の大文字 | アッカドグラム | *ANA*「〜へ」 |
| 上付き文字 | 限定符（決定詞） | ᴰIŠTAR（女神イシュタル） |
| 下付き数字（索引番号） | 同じ発音で複数ある記号を区別する | da, dá（=da₂）, dà（=da₃） |

## 音節記号の境界とハイフン

1語の中で複数の音節記号が連続する場合、記号どうしの境界を明示するために**ハイフン**で結ぶ。たとえば「彼はいる、存在する」を意味する語は e-eš-zi のように翻字され、e、eš、zi という3つの音節記号から成ることが一目でわかる。

## 限定符（上付き文字）

人名・神名・地名・職業名などの前後には、その語の意味範疇を示す**限定符（determinative）**と呼ばれる記号が添えられる。翻字ではこれを上付き文字で示す。たとえば神名の前に置かれる限定符 D（シュメール語 DINGIR「神」に由来）を上付きにして ᴰIŠTAR（女神イシュタル）のように書く。限定符自体は発音されなかったと考えられている。詳しくは[限定符（決定詞）](/hittite/script-and-phonology/determinatives-in-hittite/)を参照。

## 同音異字の区別：索引番号

楔形文字には、同じ音価を持ちながら字形の異なる記号が複数存在する場合が多い。これらを翻字上で区別するため、頻度の高い記号から順にアクセント記号や下付きの索引番号を付ける慣習がある。

```
da   （索引なし。最も基本的な da 記号）
dá   （= da₂。2番目に基本的な da の音を持つ別字形）
dà   （= da₃。3番目の別字形）
```

この索引番号は発音の違いを表すものではなく、あくまで「元の粘土板でどの字形が使われていたか」を区別するための書記学上の情報である。

## 欠損・修復・誤記を示す記号

粘土板は破損していることが多く、翻字にはテキストの物理的な状態を示す記号も用いられる。

| 記号 | 意味 |
|---|---|
| `[ ]`（角括弧） | 破損により失われた部分。文脈から推定して補った箇所 |
| `⸢ ⸣`（半括弧） | 部分的に破損しているが、辛うじて判読できる箇所 |
| `< >`（山括弧） | 書記官が書き落としたと推定される、本来あるべき記号の補い |
| `<< >>`（二重山括弧） | 書記官が誤って余分に書いてしまったと考えられる記号の指摘 |

これらの記号により、読者は「実際に粘土板に残っている文字」と「研究者が推定・復元した部分」とを明確に区別できる。
