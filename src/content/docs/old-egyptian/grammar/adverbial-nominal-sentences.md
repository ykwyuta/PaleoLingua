## 動詞を使わない文もある

古エジプト語には、[sḏm=f形](/old-egyptian/grammar/sdm-f-verb-form/)のような動詞文とは別に、動詞を用いない**非動詞文**が2種類ある。**副詞文**（Adverbial Sentence）と**名詞文**（Nominal Sentence）である。

## 副詞文：主語＋副詞的述語

副詞文は「主語＋副詞的（前置詞句的）述語」という構造を持ち、「AはYに（で）ある」という意味を表す。語順は主語が先に来る、通常の語順である。

<p class="hieroglyph">𓊪𓂋𓆑𓄤</p>

```
pr=f nfr
プル・エフ・ネフェル
家=彼の・良い
「彼の家は良い（状態にある）」（副詞文の枠組みを示す例）
```

このように、副詞文では主語となる名詞句がまず置かれ、その後に場所・状態などを表す副詞的な要素（前置詞句や形容詞的な語）が続く。

## 名詞文：2つの名詞句を等号で結ぶ

名詞文は「AはBである」というように、2つの名詞句を等号的に結びつける文型である。エジプト語の名詞文では、指示詞 **pw**（「これ、それ」）が繋辞（コピュラ）のような役割を果たす「A pw」という構文がよく使われる。

<p class="hieroglyph">𓈖𓍿𓂋𓊪𓅱</p>

```
nṯr pw
ネチェル・プウ
神・これ
「これは神である」（名詞文、A pw構文）
```

「A pw」の語順は、A（述語となる名詞句）が先に来て、pw があとに続く点に注意したい。pw はもとは「これ、それ」を意味する指示詞だが、この構文の中では「〜は…である」という等式関係を作る繋辞的な要素として機能する。

## 独立代名詞と pw の組み合わせ

[従属代名詞と独立代名詞](/old-egyptian/grammar/dependent-independent-pronouns/)の記事で見た独立代名詞も、この名詞文の主語（あるいは強調された述語）として現れることがある。たとえば「ntf pw」型の構文は「それは彼である」のように、独立代名詞 ntf「彼は」と pw を組み合わせて、強調をともなった等式的な名詞文を作る。副詞文・名詞文はいずれも動詞を使わずに文を成立させる古エジプト語の重要な仕組みであり、動詞文（sḏm=f型）と並ぶもう一つの柱として理解しておこう。
