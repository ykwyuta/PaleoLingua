## ヒッタイト語の基礎データ

ヒッタイト語（Hittite）は、現存する文献の中で**インド・ヨーロッパ語族の言語として最も古い時代の姿を伝える言語**である。紀元前2千年紀の中央アナトリア（現在のトルコ中部）で、ヒッタイト王国の公用語として楔形文字で記録された。

| 項目 | 内容 |
|---|---|
| 話された地域 | 中央アナトリア（現トルコ中部）。首都ハットゥシャ（現ボアズキョイ／ボアズカレ） |
| 文字記録の期間 | 前17世紀頃〜前1180年頃（ヒッタイト王国の滅亡まで） |
| 系統 | インド・ヨーロッパ語族アナトリア語派（現存最古の枝分かれ） |
| 文字 | 楔形文字（メソポタミアから借用した音節文字＋シュメログラム・アッカドグラム） |
| 基本語順 | SOV（主語－目的語－動詞）が基本だが、文頭に接続詞＋接語代名詞連鎖が置かれる |
| 文法類型 | 2性（有生／共通性・中性）、2種類の動詞活用（mi活用・hi活用）、格変化に能格的な中性主語標示を持つ |
| 発見・解読 | 1906年以降ハットゥシャで大量の粘土板文書が発掘され、1915年にチェコの学者ベドジフ・フロズニーがインド・ヨーロッパ語族の言語であることを立証した |

## アナトリア語派とインド・ヨーロッパ語族

ヒッタイト語は、ルウィ語・パライ語・リュキア語・リディア語・カリア語などとともに、インド・ヨーロッパ語族の**アナトリア語派**を構成する。アナトリア語派はインド・ヨーロッパ祖語から最も早い段階で分岐した枝と考えられており、この考えは「インド・ヒッタイト仮説」（Indo-Hittite hypothesis、E. Sturtevant提唱）とも呼ばれる。ヒッタイト語には、印欧祖語の音韻を再建するうえで決定的な手がかりとなった特徴がある。それが[喉音（ḫ音）](/hittite/script-and-phonology/laryngeals-in-hittite/)の直接的な文字表記であり、19世紀末にソシュールが理論的に予言した「喉音理論」を裏づける実例として言語学史上きわめて重要な位置を占める。

## 時代区分

ヒッタイト語の文献は、文法・書記法の特徴に応じて3段階に区分される。

| 段階 | おおよその時期 | 特徴 |
|---|---|---|
| 古ヒッタイト語（Old Hittite） | 前17世紀〜前15世紀頃 | 『アニッタ文書』など最古期の文書。後代の写本を通じて伝わることが多い |
| 中ヒッタイト語（Middle Hittite） | 前15世紀〜前14世紀頃 | 過渡期。文法・正書法の変化が進行中 |
| 新（後期）ヒッタイト語（New/Neo-Hittite） | 前14世紀〜前13世紀頃 | 帝国最盛期の文書。現存する写本の多くがこの段階の言語を反映する |

## 文字とその由来

ヒッタイト語は独自の文字を持たず、メソポタミアの[楔形文字を借用](/hittite/script-and-phonology/cuneiform-hittite-writing-system/)して表記された。これはシュメール語・アッカド語に由来する音節文字体系に加え、[シュメログラム・アッカドグラム](/hittite/script-and-phonology/sumerograms-and-akkadograms/)と呼ばれる借用表語文字を多用する点が特徴で、アッカド語の楔形文字運用をほぼそのまま継承しつつ、独自のインド・ヨーロッパ語族の言語を書き表す工夫が随所に見られる。

## 現存する文献

ハットゥシャの王宮文書庫跡から出土した数万点の粘土板断片には、王の年代記・条約文書（[隣国との条約](/hittite/readings/kbo-treaty-formula/)を含む）、[ヒッタイト法典](/hittite/readings/hittite-laws-excerpt/)、儀礼文書、神話（[イルヤンカ神話](/hittite/readings/illuyanka-myth-excerpt/)など）、祈祷文（[疫病の祈り](/hittite/readings/plague-prayers-mursili/)など）が含まれる。これらは粘土板という耐久性の高い媒体に刻まれたため、火災で宮殿が焼け落ちた際にかえって「焼成」されて保存状態が良くなったという幸運な経緯がある。
