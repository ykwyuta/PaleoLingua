[動詞語根](/sanskrit/grammar/verbal-roots-dhatu/)で見たように、サンスクリット語の各動詞語根は10のガナ（gaṇa、クラス）のいずれかに属し、そのガナごとに決まった方法で**現在語幹**を作る。この記事ではまず10クラスの全体像を整理し、続いてセマティック活用とアセマティック活用の違い、そして最も基本的な第1類動詞 भू bhū-「なる」の現在時制人称変化を詳しく見る。

## 10のガナと現在語幹の作り方

| ガナ | 名称 | 現在語幹の作り方 | 例（語根→現在語幹） |
|---|---|---|---|
| 第1類 | भ्वादि bhvādi | 語根 + -a-（セマティック） | bhū- → bhava- |
| 第2類 | अदादि adādi | 語根に直接語尾（アセマティック） | ad- → ad- |
| 第3類 | जुहोत्यादि juhotyādi | 語根を重複（畳字）した上で直接語尾（アセマティック） | hu- → juho-/juhu- |
| 第4類 | दिवादि divādi | 語根 + -ya-（セマティック） | div- → dīvya- |
| 第5類 | स्वादि svādi | 語根 + -no-/-nu-（アセマティック） | su- → suno-/sunu- |
| 第6類 | तुदादि tudādi | 語根 + -a-（アクセント位置が第1類と異なるセマティック） | tud- → tuda- |
| 第7類 | रुधादि rudhādi | 語根の中に -na-/-n- を挿入（アセマティック） | rudh- → ruṇadh-/rundh- |
| 第8類 | तनादि tanādi | 語根 + -o-/-u-（アセマティック、第5類に類似） | tan- → tano-/tanu- |
| 第9類 | क्र्यादि kryādi | 語根 + -nā-/-nī-（アセマティック） | krī- → krīṇā-/krīṇī- |
| 第10類 | चुरादि curādi | 語根 + -aya-（セマティック） | cur- → coraya- |

## セマティック活用とアセマティック活用

10クラスは大きく2つのグループに分けられる。

- **セマティック（thematic）活用**（第1・4・6・10類）：語根と人称語尾の間に必ず母音 -a-（テーマ母音）が挟まる。この -a- のおかげで人称語尾自体は全クラス共通の単純な形になり、語根と語尾の境目でのサンディ（連声）も比較的単純になる。
  
- **アセマティック（athematic）活用**（第2・3・5・7・8・9類）：語根（または語根に接辞を加えた語幹）に人称語尾が直接付く。テーマ母音がないため、語幹末の音と語尾頭の音が直接接触し、複雑なサンディが生じやすい。またこれらのクラスの多くは、単数と複数・双数とで語幹の形が異なる**強語幹・弱語幹の交替**を示す（例：第2類の語根 as-「ある」は、3人称単数では強語幹を保つ asti「彼はある」だが、3人称複数では弱語幹に縮まった santi「彼らはある」のように、強語幹asと弱語幹sが交替する）。

セマティック活用はテーマ母音のおかげで規則性が高く、初学者はまず第1類（bhvādi）から学び始めるのが一般的である。

## 第1類動詞 bhavati「なる」の現在時制

第1類動詞の代表として、語根 भू bhū-「なる、ある」から作られる現在語幹 bhava- の並立行（パラスマイパダ、能動態）の人称変化を示す。

| 人称・数 | 形 | 分析 |
|---|---|---|
| 1人称単数 | भवामि bhavāmi | bhava- + -āmi |
| 2人称単数 | भवसि bhavasi | bhava- + -si |
| 3人称単数 | भवति bhavati | bhava- + -ti |
| 1人称双数 | भवावः bhavāvaḥ | bhava- + -āvaḥ |
| 2人称双数 | भवथः bhavathaḥ | bhava- + -athaḥ |
| 3人称双数 | भवतः bhavataḥ | bhava- + -ataḥ |
| 1人称複数 | भवामः bhavāmaḥ | bhava- + -āmaḥ |
| 2人称複数 | भवथ bhavatha | bhava- + -atha |
| 3人称複数 | भवन्ति bhavanti | bhava- + -anti |

## 例文

```
सः भवति।
saḥ bhavati.
サハ バヴァティ
彼-主格 彼はなる（ある）
「彼は存在する。／彼は〜になる。」
```

```
वयं मित्राणि भवामः।
vayaṃ mitrāṇi bhavāmaḥ.
ヴァヤン ミトラーニ バヴァーマハ
私たちは 友人たち-主格 私たちはなる
「私たちは友人になる。」
```

```
त्वं कदा गृहं गच्छसि?
tvaṃ kadā gṛhaṃ gacchasi?
トヴァン カダー グリハン ガッチャシ
あなたは いつ 家-対格 あなたは行く
「あなたはいつ家へ行くのですか。」
```

3つ目の例文の gacchasi は同じセマティック活用（第1類）の動詞 gam-「行く」（現在語幹 gaccha-）の2人称単数形で、bhavasi とまったく同じ語尾 -si を取っていることが確認できる。このように、セマティック動詞は語根が異なっても人称語尾のパターンが共通しているため、一度覚えれば応用が利きやすい。
