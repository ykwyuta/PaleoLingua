## シュメール語の格標識体系

シュメール語は名詞の後ろに格接尾辞を付加することで、その名詞が文中で果たす役割（動作主、対象、場所、方向など）を示す膠着語である。研究者によって呼称や分類の細部は多少異なるが、一般的に次のような格が認められている。

| 格 | 接尾辞 | 楔形文字 | カタカナ読み | 主な用法 |
|---|---|---|---|---|
| 絶対格 | 無標（∅） | ― | （読まない） | 自動詞の主語、他動詞の目的語 |
| 能格 | `-e` | 𒂊 | エ | 他動詞の主語（動作主） |
| 属格 | `-ak` | 𒀀 | アク | 所有・限定（「AのB」） |
| 与格 | `-ra` | 𒊏 | ラ | 動作の受け手・受益者（主に人・神） |
| 処格 | `-a` | 𒀀 | ア | 場所（「〜において」、主に無生物） |
| 向格（処格・方向格） | `-e` | 𒂊 | エ | 方向・到達点（「〜へ」、能格と同形だが機能が異なる） |
| 終端格 | `-še3` | 𒂠 | シェ | 到達点・目的（「〜まで」「〜のために」） |
| 奪格・具格 | `-ta` | 𒋫 | タ | 起点・手段（「〜から」「〜によって」） |
| 共格 | `-da` | 𒁕 | ダ | 同伴（「〜と一緒に」） |
| 等格 | `-gin7` | 𒁶 | ギン | 比較・類似（「〜のように」、索引番号7は読まない） |

## 格接尾辞の付く位置

格接尾辞は、これまでに見た名詞句の並び順（名詞→形容詞→属格句→指示詞→複数標識→格接尾辞）の一番最後、すなわち名詞句全体の末尾にただ一度だけ付加される。名詞句がどれだけ長くなっても、格接尾辞は句全体に対して1つだけである。

<p class="cuneiform">𒂍   𒈗𒀀𒂊</p>

```
e2   lugal-ak-e
エ   ルガル・アク・エ
家   王-属格-能格
「王の家が（〜を建てた等）」
```

## この記事の位置づけ

各格の詳細（特に属格・与格・処格・終端格など）は、それぞれ個別の記事でより深く扱う。まずはこの一覧表で「シュメール語には格接尾辞という仕組みがあり、それぞれの接尾辞に固有の役割がある」という全体像を掴んでおきたい。
