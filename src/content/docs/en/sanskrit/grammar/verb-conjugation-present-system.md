As seen in [Verbal Roots (dhātu)](/en/sanskrit/grammar/verbal-roots-dhatu/), every Sanskrit verbal root belongs to one of ten gaṇas (classes), and each gaṇa builds its **present stem** by a fixed method. This article first surveys all ten classes, then explains the distinction between thematic and athematic conjugation, and finally walks through the full personal-ending paradigm of the most basic class-1 verb, भू bhū- "to become."

## The Ten Gaṇas and How They Form the Present Stem

| Gaṇa | Name | How the present stem is formed | Example (root → present stem) |
|---|---|---|---|
| Class 1 | भ्वादि bhvādi | root + -a- (thematic) | bhū- → bhava- |
| Class 2 | अदादि adādi | endings added directly to the root (athematic) | ad- → ad- |
| Class 3 | जुहोत्यादि juhotyādi | root reduplicated, then endings added directly (athematic) | hu- → juho-/juhu- |
| Class 4 | दिवादि divādi | root + -ya- (thematic) | div- → dīvya- |
| Class 5 | स्वादि svādi | root + -no-/-nu- (athematic) | su- → suno-/sunu- |
| Class 6 | तुदादि tudādi | root + -a- (thematic, but with different accent placement than class 1) | tud- → tuda- |
| Class 7 | रुधादि rudhādi | -na-/-n- infixed into the root (athematic) | rudh- → ruṇadh-/rundh- |
| Class 8 | तनादि tanādi | root + -o-/-u- (athematic, similar to class 5) | tan- → tano-/tanu- |
| Class 9 | क्र्यादि kryādi | root + -nā-/-nī- (athematic) | krī- → krīṇā-/krīṇī- |
| Class 10 | चुरादि curādi | root + -aya- (thematic) | cur- → coraya- |

## Thematic vs. Athematic Conjugation

The ten classes fall into two broad groups.

- **Thematic conjugation** (classes 1, 4, 6, 10): the vowel -a- (the "thematic vowel") is always inserted between the root and the personal ending. Because of this -a-, the personal endings themselves take a simple form shared across all thematic classes, and sandhi at the root/ending boundary is relatively straightforward.

- **Athematic conjugation** (classes 2, 3, 5, 7, 8, 9): personal endings attach directly to the root (or to the root plus a class-specific affix), with no thematic vowel in between. Because the stem-final sound and the ending's initial sound come into direct contact, more complex sandhi tends to result. Many of these classes also show an alternation between **strong and weak stem grades** depending on number — for example, the class-2 root as- "to be" keeps its strong stem in the third-person singular asti "he is," but shrinks to the weak stem in the third-person plural santi "they are," alternating between the strong stem as- and the weak stem s-.

Because the thematic vowel makes their conjugation highly regular, beginners typically start with class 1 (bhvādi).

## The Present Tense of bhavati "Becomes"

As the representative class-1 verb, here is the parasmaipada (active voice) personal-ending paradigm of the present stem bhava-, built from the root भू bhū- "to become, to be."

| Person/Number | Form | Analysis |
|---|---|---|
| 1st singular | भवामि bhavāmi | bhava- + -āmi |
| 2nd singular | भवसि bhavasi | bhava- + -si |
| 3rd singular | भवति bhavati | bhava- + -ti |
| 1st dual | भवावः bhavāvaḥ | bhava- + -āvaḥ |
| 2nd dual | भवथः bhavathaḥ | bhava- + -athaḥ |
| 3rd dual | भवतः bhavataḥ | bhava- + -ataḥ |
| 1st plural | भवामः bhavāmaḥ | bhava- + -āmaḥ |
| 2nd plural | भवथ bhavatha | bhava- + -atha |
| 3rd plural | भवन्ति bhavanti | bhava- + -anti |

## Example Sentences

```
सः भवति।
saḥ bhavati.
he-NOM become-3SG.PRES
"He exists. / He becomes."
```

```
वयं मित्राणि भवामः।
vayaṃ mitrāṇi bhavāmaḥ.
we-NOM friend.PL-NOM become-1PL.PRES
"We become friends."
```

```
त्वं कदा गृहं गच्छसि?
tvaṃ kadā gṛhaṃ gacchasi?
you-NOM when house-ACC go-2SG.PRES
"When are you going home?"
```

In the third example, gacchasi is the second-person singular form of another class-1 (thematic) verb, gam- "to go" (present stem gaccha-), and it takes exactly the same ending -si seen in bhavasi. Because thematic verbs share the same personal-ending pattern regardless of root, learning it once pays off across a huge range of verbs.
