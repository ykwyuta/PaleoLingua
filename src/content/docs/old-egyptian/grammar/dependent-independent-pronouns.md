## 古エジプト語の代名詞は3系列

[人称接尾代名詞](/old-egyptian/grammar/suffix-pronouns/)の記事で見た接尾代名詞に加えて、古エジプト語にはさらに2系列の代名詞がある。動詞の直接目的語などに使う**従属代名詞**（dependent pronoun）と、強調・単独用法に使う**独立代名詞**（independent pronoun）である。あわせて3系列の代名詞が、それぞれ異なる文法的役割を担っている。

## 従属代名詞：動詞の直接目的語

従属代名詞は、主に動詞の直接目的語として、あるいは一部の小辞（パーティクル）の後に使われる代名詞である。

| 人称 | 従属代名詞 |
|---|---|
| 1人称単数 | wj |
| 2人称単数・男性 | ṯw |
| 2人称単数・女性 | ṯn / ṯm（あまり一般的でない形） |
| 3人称単数・男性 | sw |
| 3人称単数・女性 | sy / st |
| 1人称複数 | n |
| 2人称複数 | ṯn |
| 3人称複数 | sn |

## 独立代名詞：強調・単独用法・名詞文の主語

独立代名詞は、それだけで単独の単語として現れ、強調（「〜こそが」）や、話題化、あるいは「A pw」型の名詞文の主語として使われる（[副詞文と名詞文](/old-egyptian/grammar/adverbial-nominal-sentences/)を参照）。

| 人称 | 独立代名詞 |
|---|---|
| 1人称単数 | jnk（「私は／私こそが」） |
| 2人称単数・男性 | ntk |
| 2人称単数・女性 | nt.t |
| 3人称単数・男性 | ntf |
| 3人称単数・女性 | nts |
| 1人称複数 | jnn |
| 2人称複数 | nttn |
| 3人称複数 | ntsn |

## 3系列を並べて比較する

[人称接尾代名詞](/old-egyptian/grammar/suffix-pronouns/)の記事にあるパラダイム表とあわせて、1人称単数・2人称単数男性・3人称単数男性の3人称について、接尾代名詞・従属代名詞・独立代名詞を並べてみよう。

| 人称 | 接尾代名詞 | 従属代名詞 | 独立代名詞 |
|---|---|---|---|
| 1人称単数 | =j | wj | jnk |
| 2人称単数・男性 | =k | ṯw | ntk |
| 3人称単数・男性 | =f | sw | ntf |

同じ「私」「あなた」「彼」を表すのに、これほど形の異なる3系列が使い分けられている点が、古エジプト語代名詞体系の大きな特徴である。接尾代名詞は所有と動詞の主語、従属代名詞は主に動詞の目的語、独立代名詞は強調・単独用法・名詞文の主語、というように役割が明確に分かれている。
