## 2つの地理的方言群

アッカド語は、単一の均質な言語ではなく、メソポタミアの南北で発達した2つの大きな方言群に分かれる。

| 方言群 | 中心地域 | 主要都市 |
|---|---|---|
| バビロニア方言群 | メソポタミア南部（バビロニア） | バビロン、ニップル、ウル、ウルク |
| アッシリア方言群 | メソポタミア北部（アッシリア） | アッシュル、ニネヴェ、ニムルド（カルフ） |

この南北の区分は、[アッカド語とは何か](/akkadian/script-and-phonology/what-is-akkadian/)で触れたように、政治的な境界であると同時に、音韻・語彙・語法の面でも一定の違いを伴う言語的な境界でもある。

## バビロニア方言群の時代区分

| 時代 | おおよその年代 | 代表的な文書ジャンル |
|---|---|---|
| 古アッカド語（Old Akkadian） | 前2350年頃〜前2150年頃 | アッカド王国（サルゴン朝）の王碑文、行政文書。バビロニア・アッシリアの方言分岐以前の共通段階 |
| 古バビロニア語（Old Babylonian, OB） | 前2000年頃〜前1600年頃 | ハンムラビ法典などの法典、私信、数学・占い文書。後世まで規範とされる古典的文語の基盤 |
| 中バビロニア語（Middle Babylonian, MB） | 前1600年頃〜前1000年頃 | カッシート王朝期の行政文書、境界石碑文（クドゥル）。周辺地域（エジプトなど）で使われた「周辺アッカド語」を含む外交書簡（アマルナ文書）もこの時期の言語層に近い |
| 新バビロニア語（Neo-Babylonian, NB） | 前1000年頃〜前600年頃 | 経済・法律文書のアーカイブ、王碑文 |
| 後期バビロニア語（Late Babylonian, LB） | 前600年頃〜西暦1世紀頃 | 天文日誌、経済文書。楔形文字によるアッカド語文書としては最後の段階 |

## アッシリア方言群の時代区分

| 時代 | おおよその年代 | 代表的な文書ジャンル |
|---|---|---|
| 古アッシリア語（Old Assyrian, OA） | 前2000年頃〜前1600年頃 | アナトリアのカニシュ（キュルテペ）遺跡から出土した商人の[商業書簡・契約文書](/akkadian/readings/old-assyrian-trade-letter/) |
| 中アッシリア語（Middle Assyrian, MA） | 前1600年頃〜前1000年頃 | 中アッシリア法典、行政文書 |
| 新アッシリア語（Neo-Assyrian, NA） | 前1000年頃〜前600年頃 | [王の年代記・戦勝碑文](/akkadian/readings/neo-assyrian-royal-inscription/)、王家の書簡、占いの報告書 |

## 文語標準としての「標準バビロニア語」

古バビロニア語の時代以降、文学・宗教・学術文書には、話し言葉としての各時代・各地域の方言とは別に、**標準バビロニア語（Standard Babylonian, SB）**と呼ばれる文語規範が用いられるようになった。標準バビロニア語は古バビロニア語を基礎としつつ、後代の言語的特徴も部分的に取り込んだ、いわば「文語コイネー（共通文語）」であり、実際の話し言葉ではなく書き言葉としてのみ機能した点が特徴である。

『ギルガメシュ叙事詩』の標準版や『エヌマ・エリシュ（創世叙事詩）』、各種の占い文書集成などの文学・学術文書は、たとえアッシリアの書記官によって新アッシリア時代に書き写された写本であっても、多くの場合この標準バビロニア語で書かれている。これは、古典中国語における漢文や、中世ヨーロッパにおけるラテン語が果たしたのと似た役割――話し言葉の変化から独立した、地域・時代を超えた学術・文学共通語としての役割――を、標準バビロニア語がメソポタミア世界で担っていたことを示している。

なお、この文語の規範性ゆえに、[王号](/akkadian/script-and-phonology/what-is-akkadian/)などの伝統的表現は時代が下っても同じ形で使われ続けた。たとえば「女王」を意味する語 *šarratum* のような単語は、新アッシリア・新バビロニア時代の王碑文にも古バビロニア語とほぼ同じ綴りで現れる。

<p class="cuneiform">𒊭𒅈𒊏𒌈</p>

```
šarratum
シャ・アル・ラ・トゥム
女王（女性・単数・主格）
```

## 地理と方言のまとめ

バビロニアとアッシリアという南北2つの中心地は、政治的にはしばしば別々の王国を形成しつつ、同じ楔形文字書記文化と、標準バビロニア語という共通の文語規範を共有し続けた。この結果、アッカド語の文献は「どの時代・どの地域の話し言葉を反映しているか」（古バビロニア語・中アッシリア語など）と「どの文語規範で書かれているか」（標準バビロニア語かどうか）という、2つの軸で分類する必要がある。
