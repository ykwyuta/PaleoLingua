サンスクリット語は分詞（कृदन्त kṛdanta、語根に接尾辞を付けて作る形容詞的・副詞的派生語）が非常に発達しており、定形動詞（人称変化する動詞）を使わずに分詞だけで複雑な文意を組み立てることも多い。この記事では現在分詞（能動・中動）、過去受動分詞、そして絶対分詞（連続体）の3つを扱う。

## 現在能動分詞（-ant/-at）

パラスマイパダ（能動態）の現在語幹に接尾辞 **-ant**（弱語幹では -at）を付けて作る。格変化は子音語幹（-ant語幹）のパターンに従う。

```
भवत्- bhavat-（bhū-「なる」の現在語幹bhava- + -ant）
主格単数（男性）：भवन् bhavan
「なりつつある（もの）」
```

```
गच्छन् बालकः पतति।
gacchan bālakaḥ patati.
ガッチャン バーラカハ パタティ
行きつつある-主格 少年-主格 彼は倒れる
「歩いている（最中の）少年が転ぶ。」
```

現在能動分詞は、このように主節の動詞（patati「彼は倒れる」）と主語を共有しながら、付帯状況（「〜しながら」）を表す形容詞的な修飾語として働く。

## 現在中動分詞（-māna/-āna）

アートマネーパダ（中動態）の現在語幹には接尾辞 **-māna**（セマティック動詞）または **-āna**（アセマティック動詞）を付ける。中動態は主語自身に動作の結果が及ぶ意味合い（再帰的・自己利益的なニュアンス）を持つ。

```
लभमानः labhamānaḥ（labh-「得る」の中動現在語幹labha- + -māna、主格単数男性）
「得つつある（もの）」
```

```
फलं लभमानः सः हसति।
phalaṃ labhamānaḥ saḥ hasati.
パラン ラバマーナハ サハ ハサティ
果実-対格 得つつある-主格 彼-主格 彼は笑う
「果実を得ながら、彼は笑う。」
```

## 過去受動分詞（-ta/-na）

過去受動分詞（पूर्व कृदन्त、または कर्मणि भूत कृदन्त）は、語根（多くは弱語勢形）に接尾辞 **-ta** または **-na** を付けて作る、サンスクリット語で最も高頻度に使われる分詞の一つである。受動的な意味（「〜された」）と完了的な意味（「〜し終えた」）を併せ持つ。

| 語根 | 過去受動分詞 | 意味 |
|---|---|---|
| कृ kṛ-「する」 | कृत kṛta- | された、なされた |
| गम् gam-「行く」 | गत gata- | 行った |
| भू bhū-「なる」 | भूत bhūta- | なった、存在した |
| दृश् dṛś-「見る」 | दृष्ट dṛṣṭa- | 見られた |
| भिद् bhid-「割る」 | भिन्न bhinna- | 割られた（-na接尾辞） |

過去受動分詞はそれ自体が形容詞として、あるいは動詞的な述語として機能する。定形動詞を使わずに、この分詞だけで過去の出来事を述べる構文はサンスクリット語（特に古典期の散文）に極めて頻繁に現れる。

```
रामेण फलं गृहीतम्।
rāmeṇa phalaṃ gṛhītam.
ラーメーナ パラン グリヒータム
ラーマ-具格 果実-主格(中性) 取られた-主格(中性)
「ラーマによって果実が取られた。」
```

この例文には定形動詞（人称変化した動詞）が一切現れないが、動作主を表す具格（rāmeṇa）と過去受動分詞（gṛhītam、中性主格で目的語 phalam に一致）だけで、受動的な過去の出来事が完結して表現されている。

## 絶対分詞（連続体、-tvā）

絶対分詞（गेरुण्ड gerund、または連続体・不変化分詞、अव्ययं कृदन्त avyayaṃ kṛdanta とも呼ばれる）は、「〜してから」「〜した上で」という連続する動作を表す不変化の分詞で、接尾辞 **-tvā** を語根に付けて作る。接頭辞が付いた語根の場合は -tvā の代わりに **-ya** を用いる。

```
गत्वा gatvā（gam- + tvā）
「行ってから」
```

```
सः गृहं गत्वा भोजनं करोति।
saḥ gṛhaṃ gatvā bhojanaṃ karoti.
サハ グリハン ガットヴァー ボージャナン カローティ
彼-主格 家-対格 行ってから 食事-対格 彼はする
「彼は家に行ってから、食事をする。」
```

```
आगम्य āgamya（ā- + gam- + ya、接頭辞付きなので-tvāの代わりに-ya）
「来てから」
```

絶対分詞は主節の主語と同一の主語を持つ動作の連続を表すのに用いられ、[絶対処格構文](/sanskrit/grammar/case-system-functions/)（主節と異なる主語を持つ副詞節）とは補完的な関係にある。
