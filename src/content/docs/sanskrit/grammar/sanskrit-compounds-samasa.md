サンスクリット語は複合語（समास samāsa）の生産性が非常に高く、複数の単語を格語尾を介さずに1語へと融合させることで、簡潔かつ含蓄のある表現を作り出す。古典期の詩や哲学文献では、しばしば10語以上が連結された長大な複合語も見られる。伝統文法はサマーサを意味・構造の違いに基づいて5つの主要な種類に分類する。

## タットプルシャ（तत्पुरुष tatpuruṣa）：従属複合語

タットプルシャは、前項が後項に対して格関係（属格・与格・処格など）で従属する複合語である。複合語全体の意味・品詞は後項によって決まる（後項が主要部となるため「主要部後置型」と呼ばれる）。

```
राजपुरुषः rājapuruṣaḥ
राज rāja（王）+ पुरुष puruṣa（人）
「王の人」（＝王の家来）
```

この例では、rāja「王」と puruṣa「人」の間に本来あるべき属格関係（「王の（属格）人」）が、格語尾を省いた複合によって表現されている。前項がどの格関係を担うかによって、タットプルシャはさらに具格タットプルシャ、与格タットプルシャなどに細分される。

## カルマダーラヤ（कर्मधारय karmadhāraya）：同格限定複合語

カルマダーラヤはタットプルシャの一種で、前項と後項が格関係ではなく**同格（形容詞的な修飾）**の関係にある複合語である。

```
नीलोत्पलम् nīlotpalam
नील nīla（青い）+ उत्पल utpala（蓮）
「青い蓮」
```

前項の nīla「青い」が後項 utpala「蓮」を形容詞的に修飾している点で、単なる属格関係のタットプルシャとは区別される。

## ドヴァンドヴァ（द्वन्द्व dvandva）：並列複合語

ドヴァンドヴァは、2つ以上の名詞を「〜と〜」という意味で対等に並べる複合語である。全体の数（単数・双数・複数）は構成要素の数に応じて決まる。

```
रामलक्ष्मणौ rāmalakṣmaṇau
राम rāma（ラーマ）+ लक्ष्मण lakṣmaṇa（ラクシュマナ）
「ラーマとラクシュマナ」（2人なので複合語全体が双数形になる）
```

```
मातापितरौ mātāpitarau
मातृ mātṛ（母）+ पितृ pitṛ（父）
「母と父」（両親）
```

## バフヴリーヒ（बहुव्रीहि bahuvrīhi）：所有複合語

バフヴリーヒは、複合語自体が構成要素のどちらでもなく、複合語全体が指し示す**別の何か（外部の対象）を修飾する形容詞**として働く点が最大の特徴である（外心複合語とも呼ばれる）。

```
पीताम्बरः pītāmbaraḥ
पीत pīta（黄色い）+ अम्बर ambara（衣）
文字通りには「黄色い衣」だが、バフヴリーヒとしては「黄色い衣を持つ者」＝クリシュナ（神）を指す形容詞・呼称
```

「pītāmbara」という語自体は「衣」を意味しない。あくまで「黄色い衣を(持つ)者」という、複合語の外部にある人物（この場合クリシュナ）を指す形容詞として機能する。この点が、複合語自体が意味の中心を持つタットプルシャやカルマダーラヤとの決定的な違いである。バフヴリーヒという名称自体も自己言及的な例で、「多くの（bahu）米（vrīhi）を持つ者」＝「金持ち」を意味するバフヴリーヒ複合語である。

## アヴヤイーバーヴァ（अव्ययीभाव avyayībhāva）：副詞的複合語

アヴヤイーバーヴァは、前項に不変化詞（副詞・前置詞的小辞）を置き、複合語全体が**不変化の副詞**として機能する複合語である。

```
यथाशक्ति yathāśakti
यथा yathā（〜に従って）+ शक्ति śakti（能力）
「能力に応じて」（副詞）
```

複合語全体が格変化しない（中性の主格・対格単数形に固定される）点が、他の4種の複合語（すべて通常の名詞・形容詞として格変化する）と異なる。

## 5種の複合語の見分け方（まとめ）

| 種類 | 前項と後項の関係 | 複合語全体の品詞・意味の中心 |
|---|---|---|
| タットプルシャ | 前項が後項に格関係で従属 | 後項（名詞） |
| カルマダーラヤ | 前項が後項を形容詞的に修飾（同格） | 後項（名詞） |
| ドヴァンドヴァ | 前項・後項が対等に並列 | 前項＋後項の総体 |
| バフヴリーヒ | 前項・後項がともに、複合語の外部にある対象を形容 | 複合語外部の指示対象（外心的） |
| アヴヤイーバーヴァ | 前項の不変化詞が後項を修飾 | 不変化の副詞 |
