## メソポタミアからの借用

ヒッタイト人は自前の文字を発明せず、メソポタミアで発達した楔形文字（cuneiform）を借用して自らの言語を書き表した。この借用は、前2千年紀前半に中央アナトリアで活動していたアッシリア商人（カールム時代の古アッシリア語楔形文字）や、シリア・北メソポタミア方面のフルリ語系書記伝統を介して行われたと考えられている。そのため、ヒッタイトの楔形文字の字形・運用ルールは、同時代の古バビロニア語やフルリ語の楔形文字運用と多くの共通点を持つ。

楔形文字は粘土板を湿った状態のまま、葦や木の尖筆（スタイラス）を斜めに押し当てて記される。押し当てた跡がくさび形（cuneus はラテン語で「くさび」の意）になることからこの名がある。書き終えた粘土板は天日干しされるか、あるいは重要な文書は窯で焼成され、長期保存に耐える記録媒体となった。

## 音節文字としての運用

ヒッタイト楔形文字の中核は、母音1つ（V）、子音＋母音（CV）、母音＋子音（VC）、子音＋母音＋子音（CVC）の音価を持つ**音節記号**である。

| 型 | 例（翻字） | 説明 |
|---|---|---|
| V | a, i, u | 母音単独の記号 |
| CV | pa, ta, ku | 子音＋母音 |
| VC | ap, it, un | 母音＋子音 |
| CVC | kur, pár, tar | 子音＋母音＋子音（使用頻度は上の3型より低い） |

ヒッタイト語の音節文字体系は、シュメール語・アッカド語の音節目録をほぼそのまま流用しているため、1つの子音に対して複数の母音を持つ記号（pa, pi, pu 等）を組み合わせて語を綴る。詳しい翻字の表記慣習については[翻字規則](/hittite/script-and-phonology/transliteration-conventions/)を参照。

## 表語文字（シュメログラム・アッカドグラム）との併用

ヒッタイト語のテキストの大きな特徴は、音節記号だけでなく、シュメール語の単語をそのまま表語文字として流用する**シュメログラム**や、アッカド語の単語形をそのまま流用する**アッカドグラム**を非常に高い頻度で用いる点である。たとえば「王」を表す語は、ヒッタイト語本来の語形で綴られることもあれば、シュメール語由来の LUGAL という表語文字1つで書かれることも多い。

```
LUGAL-uš
ルガル・ウシュ
王（シュメログラム）+ ヒッタイト語の主格語尾 -uš
「王は」
```

このように、シュメログラムの語幹にヒッタイト語の格語尾だけを音節文字で付け足す混合表記が広く行われた。詳しくは[シュメログラムとアッカドグラム](/hittite/script-and-phonology/sumerograms-and-akkadograms/)で扱う。

## 書字方向と書記官の養成

ヒッタイト楔形文字は左から右へ、行を上から下へ進める形で記される。書記官（シュメログラムで DUB.SAR「粘土板を書く者」と表記される）は専門の書記学校で養成され、シュメール語・アッカド語の語彙表（語彙リスト）を教材として学びながら、多言語にまたがる複雑な書記システムを習得した。ハットゥシャの文書庫からは、こうした語彙リストや文法練習の写本も多数出土している。
