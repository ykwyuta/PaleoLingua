サンスクリット語の動詞形は、名詞のように語幹に直接語尾を付けるだけでは説明できない。動詞の出発点となるのは**語根（धातु dhātu）**と呼ばれる、それ自体では活用しない抽象的な基本形であり、そこにさまざまな接辞（プラティヤヤ）を加えることで、現在形・未来形・完了形・使役形・受動形など多様な派生形が作られる。この記事では語根そのものの性質と、[10種の動詞クラス](/sanskrit/grammar/verb-conjugation-present-system/)へのつながりを扱う。

## ダートゥパータ（धातुपाठ dhātupāṭha）の伝統

ダートゥパータは、パーニニ文法（अष्टाध्यायी Aṣṭādhyāyī）に付随する伝統的な**語根一覧**で、約2000の動詞語根を10のクラス（गण gaṇa、後述）ごとにグループ分けして列挙したものである。各語根には慣習的に単純な現在時制の意味（「行く」「見る」「話す」など）を表す注記が添えられているが、実際の古典文献における語根の意味は、接頭辞（उपसर्ग upasarga）の有無や組み合わせによって大きく広がったり変化したりする。

たとえば語根 गम् gam-「行く」は単独では「行く」を意味するが、接頭辞 आ ā- を付けた आगम् āgam- は「来る」、अव ava- を付けた अवगम् avagam- は「理解する」という異なる意味を持つようになる。

## 語根の基本構造

サンスクリット語の動詞語根は、多くの場合**単音節**で、子音（C）と母音（V）が組み合わさった比較的単純な形を取る。

| 構造の例 | 語根 | 意味 |
|---|---|---|
| CV | भू bhū- | 〜になる、ある |
| CVC | गम् gam- | 行く |
| CVC | पठ् paṭh- | 読む |
| CCVC | क्रुध् krudh- | 怒る |
| CṚC | कृ kṛ- | する、作る |

語根はそれ自体では活用できない抽象的な単位であり、実際に文中で使われる動詞形にするには、必ず時制・法を示す接辞（現在語幹形成接辞など）と人称語尾を付加する必要がある。この点は、そのまま格語尾を付ければ使える名詞語幹（例：deva-）とは対照的である。

## パーニニ文法における語根の位置づけ

パーニニの『アシュタディヤーイー』は、サンスクリット語の全語形を、有限個の語根・接辞・規則の組み合わせから導き出す、生成文法的な体系として組み立てられている。この体系において語根（dhātu）は、名詞語幹を作る基礎となる語根とともに、語彙全体の出発点となる最も基本的な単位として位置づけられる。

- 動詞の人称形（तिङ् tiṅ 語尾を取る形）はすべて「語根＋（現在語幹形成接辞など）＋人称語尾」という手続きで導かれる。
- 名詞化された派生語（動作名詞、行為者名詞など）や分詞も、語根に特定の接辞（कृत् kṛt 接辞）を加えることで作られる（[分詞](/sanskrit/grammar/participles-in-sanskrit/)を参照）。
- 複合語（[サマーサ](/sanskrit/grammar/sanskrit-compounds-samasa/)）の構成要素としても、語根から派生した形が頻繁に用いられる。

このように、パーニニ文法において語根はサンスクリット語彙のほぼすべてを生み出す「種」のような存在であり、ダートゥパータはその種を体系的に一覧化した基礎資料である。

## 語根と10のガナ（現在語幹クラス）の関係

ダートゥパータでは、各語根がどの**ガナ（gaṇa、「クラス」の意）**に属するかによってグループ分けされている。ガナとは、その語根が現在系（現在形・未完了過去形・命令法・願望法などを含む語幹体系）を作る際にどのような接辞・語幹形成パターンを用いるかによる分類であり、10種類存在する。

| ガナ番号 | 名称（代表語根に由来） | 例 |
|---|---|---|
| 第1類 | भ्वादि bhvādi（bhū-にちなむ） | भवति bhavati「なる」 |
| 第2類 | अदादि adādi（ad-にちなむ） | अत्ति atti「食べる」 |
| 第3類 | जुहोत्यादि juhotyādi（juhoti にちなむ） | जुहोति juhoti「捧げる」 |
| 第4類 | दिवादि divādi（div-にちなむ） | दीव्यति dīvyati「遊ぶ」 |
| 第5類 | स्वादि svādi（su-にちなむ） | सुनोति sunoti「絞る」 |
| 第6類 | तुदादि tudādi（tud-にちなむ） | तुदति tudati「突く」 |
| 第7類 | रुधादि rudhādi（rudh-にちなむ） | रुणद्धि ruṇaddhi「妨げる」 |
| 第8類 | तनादि tanādi（tan-にちなむ） | तनोति tanoti「広げる」 |
| 第9類 | क्र्यादि kryādi（krī-にちなむ） | क्रीणाति krīṇāti「買う」 |
| 第10類 | चुरादि curādi（cur-にちなむ） | चोरयति corayati「盗む」 |

これら10クラスの詳しい語幹形成のしくみ（語根に直接語尾を付ける athematic な類と、語根と語尾の間に -a- を挟む thematic な類の違いなど）は、[動詞活用：現在体系](/sanskrit/grammar/verb-conjugation-present-system/)で扱う。
