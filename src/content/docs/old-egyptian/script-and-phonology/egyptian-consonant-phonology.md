## 母音は文字に残っていない

「[ヒエログリフとは何か](/old-egyptian/script-and-phonology/hieroglyphic-writing-system/)」と「[翻字の規則](/old-egyptian/script-and-phonology/transliteration-conventions/)」で見たとおり、ヒエログリフの表音文字は子音（と半母音 j・w）のみを書き表し、母音は原則として文字に記録されない。そのため、古代エジプト人が実際にどのような母音でこれらの単語を発音していたかは、ヒエログリフの綴りそのものからは直接分からない。この記事では、失われた母音を現代の学者がどのように部分的に再建しているか、そして学習用に使われる慣習的な発音がどのようなものかを解説する。

## 手がかり1：コプト語

エジプト語の最終段階であるコプト語（Coptic）は、ギリシア文字に独自の字母を加えて表記され、**母音を明示的に書く**。コプト語は中エジプト語などのより古い段階から直接発達した言語であるため、コプト語の単語の母音パターンを手がかりに、それ以前の段階の母音をある程度遡って推定することができる。ただし、コプト語自体もエジプト語のもっとも新しい段階であり、数千年におよぶ音変化を経た後の姿である点には注意が必要である。

## 手がかり2：アッカド語・ギリシア語による転写

古代の外国語資料の中には、エジプトの人名や地名、外来語をそれぞれの文字体系で書き取った例が残っている。アッカド語の楔形文字文書（外交文書など）やギリシア語の資料は、いずれも母音を表記する文字体系であるため、そこに転写されたエジプトの固有名詞を調べることで、当時の母音の音価を間接的に推測できる。たとえば新王国時代のファラオの名前がアッカド語文書中でどう綴られているかは、母音再建の重要な手がかりの一つとなっている。

## 手がかり3：比較アフロ・アジア語族の証拠

エジプト語はセム語派・ベルベル語派・クシ語派・チャド語派などとともにアフロ・アジア語族を構成する（「[古エジプト語とは何か](/old-egyptian/script-and-phonology/what-is-old-egyptian/)」参照）。これらの同族語における対応する語根の母音パターンを比較することでも、エジプト語の母音についてある程度の推定が可能になる。ただし、これはあくまで比較言語学的な推定であり、確実な証拠ではない。

## 学習用の慣習的な「e」挿入読み

これらの手がかりを総合しても、エジプト語のすべての単語の母音を確実に再建することはできない。そこで現代のエジプト学の教科書や学習教材では、**発音のしやすさのためだけに**、子音と子音のあいだに慣習的な「エ（e）」の音を挿入して読む方法が広く用いられている。たとえば、「良い、美しい」を意味する nfr は、慣習的に「ネフェル（nefer）」と読まれる。

**この「ネフェル」という読み方は、古代の実際の発音を再建したものでは決してなく、あくまで現代の学習者が発音しやすくするための便宜的な約束事にすぎない**。本サイトで示すカタカナ表記もすべてこの慣習に基づくものであり、この点はどの記事でも繰り返し注意しておきたい。

<p class="hieroglyph">𓄤</p>

```
nfr
ネフェル（学習用の慣習的な読み。実際の古代の発音とは異なる）
良い、美しい、完全な
```

## ꜣ と ꜥ をめぐる論争

翻字に使われる ꜣ（アレフ）と ꜥ（アイン）は、エジプト学の慣習として「ア」に近い音で読まれることが多い。しかし、この読み方はあくまで発音上の便宜であり、これらの文字が古代において実際に母音だったと考える研究者はほとんどいない。通説では、ꜣ と ꜥ は、セム語のアレフ（ʾ、声門閉鎖音）やアイン（ʿ、有声咽頭摩擦音）に類似した**子音**――すなわち声門音・咽頭音的な音――であったと考えられている。つまり、これらは母音ではなく、喉の奥で調音される特殊な子音だった可能性が高いということになる。それにもかかわらず「ア」と読む慣習が広まっているのは、これらの子音がヨーロッパの諸言語には存在しないため、学習上の便宜として母音的に読む習慣が定着したためである。
