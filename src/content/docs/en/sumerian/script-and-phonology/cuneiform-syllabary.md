## Types of syllabic signs

Cuneiform is a mixed writing system: alongside logograms (one sign per word), it makes heavy use of syllabograms — signs that represent sound alone. Sumerian syllabograms fall mainly into three shapes.

| Type | Structure | Examples |
|---|---|---|
| V | vowel only | `a`, `i`, `u` |
| CV | consonant + vowel | `ba`, `du`, `mu`, `ra` |
| VC | vowel + consonant | `ab`, `en`, `ur` |
| CVC | consonant + vowel + consonant | `dam`, `kur`, `lugal` |

By stringing these together, scribes could spell out Sumerian words and grammatical suffixes sound by sound.

## Example: spelling a word syllabically

The word for "child," *dumu*, is spelled with two CV syllabograms, `du` + `mu`, written `du-mu` (transliteration convention marks syllable breaks with a hyphen).

```
du-mu
child
```

## Polyvalence and homophony: index numbers

Cuneiform syllabograms show two related complications: "polyvalence," where a single sign can be read with more than one sound, and "homophony," where the same sound can be written with several different signs. To distinguish homophonous signs in scholarly transliteration, a subscript index number is added after the sound value.

| Transliteration | Meaning |
|---|---|
| `du` | no index number = the most common/basic sign for this sound |
| `du3` | a different sign for the same sound /du/ (e.g., the verbal root "to build") |
| `du6` | yet another sign for /du/ (e.g., the word for "mound") |

The index number is purely a scholarly notation for *which sign* is being used — it does not indicate any difference in pronunciation.
