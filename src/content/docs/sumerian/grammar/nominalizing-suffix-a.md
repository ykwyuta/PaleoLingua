## 動詞を名詞句に変える -a

シュメール語には、動詞（の語幹＋接頭辞群）の後ろに付くことで、その動詞句全体を「〜した（もの・こと）」という名詞的な単位に変える接尾辞 `-a` がある。これは英語の関係代名詞節や、日本語の「〜した」という連体修飾（例：「建てた家」の「建てた」）に近い働きをする。

```
𒂍𒆕𒀀
e2  du3-a
エ  ドゥ・ア
家  建てる-名詞化
「建てられた家」「（誰かが）建てた家」
```

## 動詞句全体を包み込む

`-a` は語根だけでなく、接頭辞群を伴った動詞句全体の末尾に付く。そのため、主語や与格項などを含んだ長い節も、まるごと1つの名詞句に変えることができる。

```
𒈗𒂊  𒂍  𒈬𒆕𒀀
lugal-e   e2   mu-du3-a
ルガル・エ エ   ム・ドゥ・ア
王-能格   家   建てた-名詞化
「王が建てた家」
```

この `e2 ... mu-du3-a`（王が建てた家）全体が、より大きな文の中で1つの名詞句として、たとえば「〜の中で」のように別の格接尾辞を伴ってさらに使われることもある。

## 注意：属格の -a とは別物

[属格 -ak](/sumerian/grammar/genitive-case-ak/)の記事で見たように、属格接尾辞 `-ak` は後続環境によって `-a` という形で現れることがある。この名詞化の `-a` とは語源も機能もまったく異なる別の形態素であるが、見た目が同じ `-a` になるため混同しやすい。

| `-a` の種類 | 由来 | 判別の手がかり |
|---|---|---|
| 属格の `-a` | `-ak` の音韻的な変異形 | 名詞句の後（例：lugal-la「王の」） |
| 名詞化の `-a` | 独立した接尾辞 | 動詞（句）の後（例：du3-a「建てた」） |

直前の要素が名詞句か動詞句かを見極めることが、この2つの `-a` を区別する最大の手がかりとなる。
