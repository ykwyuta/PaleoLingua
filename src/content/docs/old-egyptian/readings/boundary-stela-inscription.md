## 背景：ヌビア国境に刻まれた王の言葉

中王国時代の王センウセレト3世（第12王朝、在位前1870年代〜前1830年代頃）は、ヌビア（現在のスーダン北部にあたる地域）のセムナおよびウロナルティに境界碑文を建てさせた。これらの碑文は、ナイル川沿いにおけるエジプトの支配領域の南限を示すものであり、交易目的を除いてヌビア人がこの境界を越えることを禁じる警告文と、王自身の軍事的な武勇を讃える文言とを含んでいる。

## ジャンルとしての王碑文

境界碑文は、パピルスに書かれる物語文学や教訓文学とは異なり、石に刻まれて公の場に恒久的に設置される「王碑文（記念碑文）」というジャンルの好例である。読み手を強く意識した宣言的・命令的な文体が特徴で、王の権威と国土の秩序を、通行人や後世の人々に向けて視覚的・言語的に誇示する役割を担っていた。

## 例：「国土」と「王」を表す短句

以下は、境界碑文というジャンルに繰り返し現れる、国土の支配と王権というテーマを反映した例示的な短句であり、実際のセムナ碑文の本文からの逐語引用ではない。

<p class="hieroglyph">𓈖𓋴𓅱 𓈖 𓏏𓄿</p>

```
nsw     n      tꜣ
ネスウ  ン     タア
王      〜の    地・国
```

「nsw n tꜣ」は「その地の王」を表す例示句である。境界碑文というジャンル全体を貫くのは、まさにこの「王がこの国土を支配し、その境界を定める」という宣言の精神である。
