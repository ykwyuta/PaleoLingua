## 内乱の時代に発せられた布告

**テリピヌ王の布告**は、ヒッタイト古王国末期（前16世紀頃）に王位に就いたテリピヌが発した文書で、王位継承をめぐる暗殺・内紛が相次いだ混乱の時代を収拾するために、明確な継承順位のルールを定めたことで知られる。文書の前半は、初代王ラバルナやハットゥシリ1世の治世を理想的な時代として振り返る歴史的な序文となっており、後半でその教訓をふまえた具体的な規定が示される、という構成を取る。

## 王位継承順位の規定

布告の中心をなすのが、誰が次の王になるべきかを定めた継承順位の規定である。

以下は、この規定の趣旨を伝える、学習用に単純化した例文である（特定の1行の逐語引用ではなく、規定の内容を要約的に示す文である点に注意されたい）。

```
DUMU.NÍTA-aš 1-aš LUGAL-uš ki-ša-ru
ドゥムニータシュ・イアシュ・ルガルウシュ・キシャル
息子（主格）　第一の（主格）　王（主格）　なれ-命令法3単（中動態）
「（王の）第一の息子が王となるように」

ták-ku DUMU.NÍTA-aš 1-aš NU.GÁL
タック・ドゥムニータシュ・イアシュ・ヌガル
もし　息子　第一の　いない
「もし第一の息子がいなければ」

nu-za ku-iš DUMU.NÍTA-aš 2-aš LUGAL-uš ki-ša-ru
ヌザ・クイシュ・ドゥムニータシュ・2アシュ・ルガルウシュ・キシャル
そして（再帰）　第二の息子（の中の誰か）　王（主格）　なれ-命令法3単
「第二の（順位の）息子の誰かが王となるように」
```

## 「パンク」による裁定

テリピヌの布告のもう一つの重要な柱が、**パンク（panku）**と呼ばれる集会・共同体の制度である。布告は、王族内で流血事件が起きた場合、加害者に対する処罰を被害者の一族が私的に報復するのではなく、パンク（王族・高官からなる合議体）が審議し裁定を下すべきだと定めている。これは、王位継承をめぐる暗殺の連鎖を断ち切ろうとする、当時としては先進的な統治上の工夫と評価されている。

## 歴史的意義

テリピヌの布告は、単なる法律文書としてだけでなく、ヒッタイト王国の初期の歴史（ラバルナ、ハットゥシリ1世、ムルシリ1世らの事績）を伝える貴重な歴史叙述としても評価されている。また、王位継承の明確なルール化とパンクによる裁定制度は、その後のヒッタイト王国の政治体制に長く影響を与えたと考えられている。
