## 独立代名詞と接語代名詞

アッカド語の人称代名詞には、文中で単独の語として機能する**独立人称代名詞**（「私」「あなた」「彼」など）と、名詞や動詞の語尾に直接付いて所有者や目的語を表す**接語人称代名詞**（enclitic pronoun、付属代名詞・接尾代名詞とも呼ばれる）の2系統がある。この2つは形がまったく異なり、それぞれ別の統語的役割を担う。

## 独立人称代名詞のパラダイム

独立代名詞は、主に主語を強調したい場合や、動詞のない名詞文（「AはBである」型の文）の主語として使われる（動詞には人称接辞がすでに含まれているため、独立代名詞は必須ではなく強調用法が中心になる）。

| 人称 | アッカド語 | 楔形文字 | カタカナ読み | 意味 |
|---|---|---|---|---|
| 1人称単数 | anāku | 𒀀𒈾𒆪 | ア・ナ・ク | 私 |
| 2人称単数（男性） | atta | 𒀜𒋫 | アト・タ | あなた（男） |
| 2人称単数（女性） | atti | 𒀜𒋾 | アト・ティ | あなた（女） |
| 3人称単数（男性） | šū | 𒋗𒌋 | シュ・ウ | 彼 |
| 3人称単数（女性） | šī | 𒅆𒄿 | シ・イ | 彼女 |
| 1人称複数 | nīnu | 𒉌𒄿𒉡 | ニ・イ・ヌ | 私たち |
| 2人称複数（男性） | attunu | 𒀜𒌅𒉡 | アト・トゥ・ヌ | あなたたち（男） |
| 2人称複数（女性） | attina | 𒀜𒋾𒈾 | アト・ティ・ナ | あなたたち（女） |
| 3人称複数（男性） | šunu | 𒋗𒉡 | シュ・ヌ | 彼ら |
| 3人称複数（女性） | šina | 𒅆𒈾 | シ・ナ | 彼女ら |

<p class="cuneiform">𒀀𒈾𒆪</p>

```
a-na-ku
ア・ナ・ク
私（1人称単数・独立代名詞）
「私」
```

<p class="cuneiform">𒋗𒌋</p>

```
šu-u
シュ・ウ
彼（3人称単数男性・独立代名詞）
「彼」
```

表を見ると、2人称と3人称では男性形と女性形が語尾の母音（`-a`系と`-i`系）で区別されていることが分かる。また複数形は、単数形の語幹に `-nu`（2人称）や `-na`（女性複数）のような要素が加わった形になっている。

## 名詞に付く接語代名詞（所有接尾辞）

接語代名詞が名詞に付くと「私の〜」「あなたの〜」のような所有表現になる。`bītum`（家、𒁉𒌈 bi-tum ビ・トゥム）を例に見てみよう。名詞に接語代名詞が付くとき、名詞は主格語尾のミメーション（`-um` の `-m`）を失った形（`bīt-`）に代名詞が続く。

| 人称 | 接語形 | 例 | 楔形文字 | カタカナ読み | 意味 |
|---|---|---|---|---|---|
| 1人称単数 | -ī | bītī | 𒁉𒋾 | ビ・ティ | 私の家 |
| 2人称単数（男性） | -ka | bītka | 𒁉𒀉𒅗 | ビ・イト・カ | あなたの家（男） |
| 2人称単数（女性） | -ki | bītki | 𒁉𒀉𒆠 | ビ・イト・キ | あなたの家（女） |
| 3人称単数（男性） | -šu | bītšu | 𒁉𒀉𒋗 | ビ・イト・シュ | 彼の家 |
| 3人称単数（女性） | -ša | bītša | 𒁉𒀉𒊭 | ビ・イト・シャ | 彼女の家 |
| 1人称複数 | -ni | bītni | 𒁉𒀉𒉌 | ビ・イト・ニ | 私たちの家 |

<p class="cuneiform">𒁉𒋾</p>

```
bi-ti
ビ・ティ
家-私の
「私の家」
```

<p class="cuneiform">𒁉𒀉𒅗</p>

```
bi-it-ka
ビ・イト・カ
家-あなたの（男）
「あなたの家」
```

<p class="cuneiform">𒁉𒀉𒊭</p>

```
bi-it-ša
ビ・イト・シャ
家-彼女の
「彼女の家」
```

このように、`bītum`（家）に接尾辞を付け替えるだけで所有者を表せる。この接尾辞の形は、独立代名詞の3人称（`šū`／`šī`）と語頭の子音（š-）が共通しているのが分かるだろう（`-šu`「彼の」、`-ša`「彼女の」）。

## 動詞に付く場合：直接目的語

同じ接語代名詞のセットは、名詞だけでなく**動詞にも直接付き、直接目的語（「〜を」）を表す**という重要な用法がある。たとえば `iprus`（彼は決めた、G語幹の過去形）に3人称単数男性の目的語接尾辞 `-šu`（彼を）を付けると `iprusšu`（彼は彼を決めた＝彼のことに決着をつけた）となる。

<p class="cuneiform">𒅁𒊒𒊻𒋗</p>

```
ip-ru-us-šu
イプ・ル・ウス・シュ
彼は決めた-彼を
「彼は彼を決めた」
```

名詞に付くか動詞に付くかで意味は「所有」か「目的語」かに変わるが、使われる接尾辞の形自体はほぼ共通しており、アッカド語の代名詞体系が名詞句と動詞句をまたいで統一的に機能していることがうかがえる。
