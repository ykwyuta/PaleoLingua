## サンスクリット語の基礎データ

サンスクリット語（संस्कृत saṃskṛta、「洗練された（言葉）」の意）は、インドを中心に3000年以上にわたって用いられてきた古典語であり、**インド・ヨーロッパ語族の中でも最も古い段階の姿を伝える言語の一つ**である。祭式・哲学・文学・科学（文法学、天文学、医学など）のほぼすべての伝統的知識がこの言語で記録されており、南アジアの古典文明を理解するうえで欠かせない言語である。

| 項目 | 内容 |
|---|---|
| 話された（用いられた）地域 | 南アジア（現在のインド・パキスタン・ネパールを中心とする広い範囲）。後には東南アジアにも仏教・ヒンドゥー教の伝播とともに広がった |
| 文献の期間 | 前1500年頃（『リグ・ヴェーダ』最古層）〜現在（学術語・宗教儀礼語として現役） |
| 系統 | インド・ヨーロッパ語族インド・イラン語派インド・アーリア語（古インド・アーリア語）に属する |
| 文字 | 歴史的には多数の文字（ブラーフミー系文字群）で書かれたが、現代の標準はデーヴァナーガリー文字 |
| 基本語順 | SOV（主語－目的語－動詞）が基本だが、語順は比較的自由（格変化が文法関係を担うため） |
| 文法類型 | 高度な屈折語。3性（男性・女性・中性）、3数（単数・両数・複数）、8格を持つ名詞体系と、複雑な動詞活用体系を持つ |
| 規範文法 | 前4世紀頃のパーニニによる『アシュターディヤーイー』が、古典サンスクリット語の規範を確立した |

## インド・イラン語派とインド・ヨーロッパ語族

サンスクリット語は、アヴェスター語（古代イランの祭式言語）などとともにインド・イラン語派を構成し、さらに大きなインド・ヨーロッパ語族に属する。ラテン語・ギリシア語・ゲルマン語派・スラヴ語派などと同じ祖語（インド・ヨーロッパ祖語）から分岐したと考えられており、格変化の体系や動詞活用の仕組み、基礎語彙（例えば「父」を意味する pitṛ とラテン語 pater、英語 father の対応）に、その血縁関係がはっきりと現れている。19世紀初頭、ウィリアム・ジョーンズがサンスクリット語とギリシア語・ラテン語の類似性を指摘したことが、比較言語学という学問分野そのものの出発点になったことでも知られる。サンスクリット語は音韻・形態の両面で古い特徴を多く保存しているため、印欧祖語の再建における最重要言語の一つに数えられる。

## ヴェーダ語と古典サンスクリット語

サンスクリット語の歴史は、大きく2つの段階に分けて捉えられることが多い。

| 段階 | おおよその時期 | 特徴 |
|---|---|---|
| ヴェーダ語（Vedic Sanskrit） | 前1500年頃〜前500年頃 | 『リグ・ヴェーダ』をはじめとする4つのヴェーダ文献の言語。[ヴェーダ語アクセント（スヴァラ）](/sanskrit/script-and-phonology/vedic-accent-svara/)を持ち、古典期より音韻・形態の面でより古態を残す |
| 古典サンスクリット語（Classical Sanskrit） | 前4世紀頃〜 | パーニニの文法によって規範化された言語。叙事詩（『マハーバーラタ』『ラーマーヤナ』）、劇作（カーリダーサなど）、哲学文献、科学文献の言語として、現在に至るまで用いられ続けている |

ヴェーダ語と古典サンスクリット語は連続体の両端であり、断絶した別言語というより、規範文法によって「凍結」された古典期以降の姿と、それ以前のより自由で変異に富んだ姿という関係にある。

## 文字――デーヴァナーガリーとその前史

現在サンスクリット語を書き表す標準的な文字は[デーヴァナーガリー文字](/sanskrit/script-and-phonology/devanagari-script-overview/)であるが、これはサンスクリット語専用に作られた文字ではない。サンスクリット語は歴史的には、ブラーフミー文字に由来する多数の地域文字（グランタ文字、シャーラダー文字、ベンガル文字、タミル文字圏でのグランタ系文字など）で書き写されてきた。デーヴァナーガリーが標準として定着したのは近世以降のことであり、口頭伝承（特にヴェーダ文献の暗誦伝統）の重要性を考えると、文字そのものよりも音の正確な伝承が長らく優先されてきた言語だと言える。

## なぜサンスクリット語を学ぶのか

サンスクリット語が重要視される理由は多岐にわたる。第一に、ヒンドゥー教・仏教・ジャイナ教の宗教儀礼・哲学文献の大半がこの言語で記されており、南アジアの思想史を理解する鍵となる。第二に、パーニニの文法学は、記述の精密さにおいて20世紀の構造言語学に先駆けると評されるほど高度に体系化されており、言語学史上の金字塔である。第三に、比較言語学の観点から、サンスクリット語（特にヴェーダ語）は印欧祖語の音韻・形態を再建するための最重要資料の一つであり、[母音階梯（グナ・ヴリッディ）](/sanskrit/script-and-phonology/vowel-gradation-guna-vrddhi/)のような現象は、印欧諸語のアブラウト研究に大きな影響を与えてきた。

## 現存する文献

サンスクリット語文献の量は膨大である。ヴェーダ文献（讃歌・祭儀書・森林書・奥義書）、二大叙事詩（『マハーバーラタ』『ラーマーヤナ』）、プラーナ文献、カーリダーサに代表される古典劇・詩、パンチャタントラなどの説話文学、パーニニ以来の文法学書、そして仏教・ジャイナ教の膨大な文献群まで、ジャンルは多岐にわたる。これらの一端は本サイトの「読解・例文」カテゴリでも紹介していく。
