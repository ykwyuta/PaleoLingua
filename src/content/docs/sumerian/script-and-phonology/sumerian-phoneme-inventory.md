## なぜ「推定」音素なのか

シュメール語は紀元前1千年紀までに日常語としては話されなくなっており、ネイティブ話者の発音を直接録音することはできない。現在知られている音素目録は、後代のアッカド語話者による音写、同一語の異表記、借用語の対応関係などの間接的な証拠から再構築された「推定」の体系である。そのため、細部については研究者ごとに異なる説が存在する。

## 母音

シュメール語には、少なくとも4つの母音音素が確認されている。

| 母音 | 例（CV音節記号） | カタカナ読み |
|---|---|---|
| /a/ | 𒀀 `a` | ア |
| /e/ | 𒂊 `e` | エ |
| /i/ | 𒄿 `i` | イ |
| /u/ | 𒌋 `u` | ウ |

5番目の母音 /o/ の存在を主張する説もあるが、これは学界の定説とはなっておらず、多くの入門書は4母音体系を採用している。

## 子音

子音についても、伝統的な目録では次のような音素が挙げられる（下記はCV音節記号の一部）。

| 音素 | 例 | カタカナ読み |
|---|---|---|
| /b/ | 𒁀 `ba` | バ |
| /d/ | 𒁕 `da` | ダ |
| /g/ | 𒂵 `ga` | ガ |
| /ḫ/（h） | 𒄩 `ha` | ハ |
| /k/ | 𒅗 `ka` | カ |
| /l/ | 𒆷 `la` | ラ（ル系） |
| /m/ | 𒈠 `ma` | マ |
| /n/ | 𒈾 `na` | ナ |
| /r/ | 𒊏 `ra` | ラ |
| /s/ | 𒊓 `sa` | サ |
| /š/（sh） | 𒊭 `ša` | シャ |
| /t/ | 𒋫 `ta` | タ |
| /z/ | 𒍝 `za` | ザ |

この他に、鼻音 /ŋ/（本サイトでは `ĝ` と表記、例：[代名詞](/sumerian/grammar/personal-demonstrative-pronouns/)の記事に出てきた `ĝe26-e`「私」）や、声門閉鎖音 /ʔ/ の存在も広く認められている。

## 係争点：有声・無声か、それとも有気・無気か

シュメール語の子音体系で特に議論が続いているのが、`b/p`・`d/t`・`g/k` のような対の性質である。伝統的にはアッカド語やラテン文字翻字の慣習に従って「有声音（b, d, g）対無声音（p, t, k）」の対立として記述されてきたが、近年の一部の研究（イェーガーズマ、キートマンなど）は、実際には「無気音対有気音」あるいは「無標音対放出音（エジェクティブ）」のような、有声・無声とは異なる音声的対立だった可能性を指摘している。本サイトでは伝統的な翻字慣習（ラテン文字の有声・無声のペア）をそのまま踏襲しつつ、実際の音価については確定していない点に留意されたい。
