## 限定符とは何か

限定符（デテルミナティヴ、決定符、determinative）は、単語の**末尾**に添えられる、それ自体は**発音されない**補助記号である。表音文字だけで綴られた単語は、エジプト語が母音を書かないこともあって同じ子音の並びを持つ複数の単語（同綴異義語）と区別がつきにくい場合がある。限定符は、その単語がどのような意味カテゴリーに属するかを視覚的に示すことで、読み手の理解を助ける役割を果たす。

## 代表的な限定符

| 限定符 | ヒエログリフ | ガーディナー番号 | 分類 |
|---|---|---|---|
| 歩く脚 | 𓂻 | D54 | 移動・「行く」系の動詞 |
| 座る男 | 𓀀 | A1 | 人・職業（男性） |
| 座る女 | 𓁐 | B1 | 人・職業（女性） |
| 前髪（サイドロック）の子供 | 𓀔 | A17 | 子供 |
| パピルスの巻物 | 𓏛 | Y1 | 抽象概念・書くこと |
| 標柱上の神 | 𓅆 | G7 | 神格（特にホルス神） |
| 複数形記号（3本の線） | 𓏥 | Z2 | 複数形 |

## 例：移動を表す動詞と限定符

「出て行く、出発する」といった移動を表す動詞には、歩く脚を描いた限定符 𓂻（D54）がしばしば添えられる。これはエジプト語の動詞語根そのものは移動と直接関係なくとも、限定符によって「これは動作・移動に関する語だ」と読み手に伝える働きをする。

<p class="hieroglyph">𓊪𓂋𓇋𓂻</p>

```
prj
ペリ
出る、出発する（語根 pr + j ＋ 移動の限定符）
```

## 例：人を表す限定符

職業や身分を表す語には、性別に応じて座る男（𓀀）または座る女（𓁐）の限定符が添えられることが多い。子供を表す語には、前髪を垂らした子供の姿の限定符（𓀔）が使われる。神の名や神格を表す語には、標柱の上に鷹（ホルス神）が乗った形の限定符（𓅆）が添えられる。

## 例：抽象概念と複数形

具体的な形を持たない抽象的な概念（考え・感情・行為など）を表す語には、パピルスの巻物の限定符 𓏛（Y1）が添えられることが多い。これは「文字で書かれるようなもの」を象徴していると考えられている。また、単語が複数形であることを示すには、3本の短い線を並べた複数形記号 𓏥（Z2）が使われる。これは限定符の一種と見なされることもあれば、独立した文法標識として扱われることもある。

## 限定符は読まれない

限定符は発音されないため、実際にエジプト語を音読する際には無視してよい。あくまで書記官が読み手の理解を助けるために添えた、いわば「無言の見出しラベル」のようなものだと考えるとよい。
