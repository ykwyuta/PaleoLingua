[名詞変化の概観](/sanskrit/grammar/noun-declension-overview/)では8格の一覧を示したが、この記事では各格が実際の文の中でどのような意味的・統語的役割を担うかを、例文とともに掘り下げる。1つの格が複数の異なる機能を持つ場合があること、また異なる格同士の機能が部分的に重なる場合があることに注目してほしい。

## 主格（Nominative）：文の主語

主格は文の**主語**を標示する、最も基本的な格である。

```
बालकः क्रीडति।
bālakaḥ krīḍati.
バーラカハ クリーダティ
少年-主格 彼は遊ぶ
「少年が遊ぶ。」
```

## 呼格（Vocative）：呼びかけ

呼格は対話の相手に**呼びかける**際に用いられる。文の他の要素とは統語的に独立している。

```
हे राम, अत्र आगच्छ।
he rāma, atra āgaccha.
ヘー ラーマ アトラ アーガッチャ
おお ラーマ-呼格 ここに 来い
「おおラーマよ、ここに来なさい。」
```

## 対格（Accusative）：直接目的語と運動の到達点

対格の中心的機能は他動詞の**直接目的語**の標示だが、「〜へ向かって」という**運動の到達点**を表す用法もある。

```
सः ग्रामं गच्छति।
saḥ grāmaṃ gacchati.
サハ グラーマン ガッチャティ
彼-主格 村-対格 彼は行く
「彼は村へ行く。」（運動の到達点）
```

## 具格（Instrumental）：手段・道具・動作主

具格は「〜によって」を表し、**手段・道具**を示すほか、受動文における**動作主（意味上の主語）**も具格で標示される。

```
सः हस्तेन लिखति।
saḥ hastena likhati.
サハ ハステーナ リカティ
彼-主格 手-具格 彼は書く
「彼は手で書く。」（手段）
```

```
रामेण पत्रं लिख्यते।
rāmeṇa patraṃ likhyate.
ラーメーナ パトラン リキュヤテー
ラーマ-具格 手紙-主格 書かれる
「ラーマによって手紙が書かれる。」（受動文の動作主）
```

能動文の主語が受動文では具格に転じる点に注意したい。この対応は、対格が能動文の目的語から受動文の主語（主格）へ変わることとちょうど対をなす。

## 与格（Dative）：間接目的語・目的

与格は「〜に」を表す**間接目的語**のほか、「〜のために」という**目的・受益者**も表す。

```
गुरुः शिष्याय पुस्तकं ददाति।
guruḥ śiṣyāya pustakaṃ dadāti.
グルフ シシュヤーヤ プスタカン ダダーティ
師-主格 弟子-与格 本-対格 彼は与える
「師は弟子に本を与える。」（間接目的語）
```

```
सः जलाय गच्छति।
saḥ jalāya gacchati.
サハ ジャラーヤ ガッチャティ
彼-主格 水-与格 彼は行く
「彼は水を求めて行く。」（目的）
```

## 奪格（Ablative）：分離の起点・比較の基準

奪格は「〜から」という**分離の起点**を表す最も基本的な用法に加え、「〜よりも」という**比較の基準**を表す独自の用法を持つ（サンスクリット語には比較級の語尾がなく、この奪格用法が比較構文の中心を担う）。

```
वृक्षात् पत्रं पतति।
vṛkṣāt patraṃ patati.
ヴリクシャート パトラン パタティ
木-奪格 葉-主格 それは落ちる
「木から葉が落ちる。」（分離の起点）
```

```
रामः लक्ष्मणात् बलवत्तरः।
rāmaḥ lakṣmaṇāt balavattaraḥ.
ラーマハ ラクシュマナート バラヴァッタラハ
ラーマ-主格 ラクシュマナ-奪格 より強い-主格
「ラーマはラクシュマナよりも強い。」（比較の基準）
```

## 属格（Genitive）：所有・所属

属格は「〜の」という**所有・所属**関係を表す。動詞と直接結びつく他の格と異なり、属格は基本的に名詞句内部で別の名詞を修飾する。

```
रामस्य पुत्रः वनं गच्छति।
rāmasya putraḥ vanaṃ gacchati.
ラーマスヤ プトラハ ヴァナン ガッチャティ
ラーマ-属格 息子-主格 森-対格 彼は行く
「ラーマの息子が森へ行く。」
```

### 属格と与格の重なり

「与える」「捧げる」のような授与動詞では、受け手を属格で表す用法も文献上見られ、与格とほぼ同じ意味範囲を担うことがある。ただし標準的な用法としては、動詞に直接支配される受け手は与格、名詞を修飾する所有関係は属格、という役割分担がある。

## 処格（Locative）：場所・時・状況（絶対処格を含む）

処格は「〜において」という**場所**、「〜のときに」という**時**を表すほか、独立した副詞的な状況を表す**絶対処格構文**（locative absolute）にも用いられる。

```
गृहे बालकः तिष्ठति।
gṛhe bālakaḥ tiṣṭhati.
グリヘー バーラカハ ティシュタティ
家-処格 少年-主格 彼は立つ
「家の中に少年が立っている。」（場所）
```

```
सूर्ये उदिते बालकाः क्रीडन्ति।
sūrye udite bālakāḥ krīḍanti.
スーリェー ウディテー バーラカーハ クリーダンティ
太陽-処格 昇った-処格 少年たち-主格 彼らは遊ぶ
「太陽が昇ると、少年たちは遊ぶ。」（絶対処格：主節と別主語を持つ副詞節）
```

絶対処格構文は、処格に置かれた名詞とそれに一致する分詞（ここでは udite「昇った」）が組になって、主節とは別の主語を持つ副詞的な従属節を作る構文である。この構文は[分詞](/sanskrit/grammar/participles-in-sanskrit/)の記事でも扱う。
