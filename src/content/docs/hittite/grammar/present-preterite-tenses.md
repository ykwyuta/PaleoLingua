## わずか2つの時制

ヒッタイト語の定形動詞（人称・数に応じて活用する動詞）は、**現在形（present）**と**過去形（preterite、プレテリトゥム）**という、たった2つの時制しか区別しない。英語やラテン語に見られるような独立した未来時制や完了時制は、動詞の語形変化としては存在しない。

- **現在形**：現在の状態・動作に加え、習慣的な事柄や、文脈によっては未来の予定・意志も表す。
- **過去形（プレテリトゥム）**：過去に起こった出来事や状態を表す、単一の過去時制。英語の過去形と完了形の区別に相当するような文法的な区別は、動詞の語形自体には存在しない。

未来の出来事や完了した状態を明確に示す必要がある場合は、時を表す副詞（「明日」「すでに」など）や文脈、あるいは特定の構文によって補われる。

## mi活用・hi活用における過去形語尾

過去形は、[mi活用とhi活用](/hittite/grammar/mi-conjugation-hi-conjugation/)のどちらに属する動詞かによって、それぞれ異なる人称語尾を取る。

| 人称・数 | mi活用の過去形（例：ēš-「いる」） | hi活用の過去形（例：dai-「置く」） |
|---|---|---|
| 1人称単数 | eš-un | dā-ḫḫun |
| 2人称単数 | eš-ta | dā-šta |
| 3人称単数 | ēš-ta | dā-š |
| 1人称複数 | eš-uen | tii̯a-uen |
| 2人称複数 | eš-ten | tii̯a-ten |
| 3人称複数 | ēš-er | tii̯-er |

```
ē-eš-ta
エーシュタ
いる-3単過
「彼／彼女／それはいた」

da-a-š
ダーシュ
置く-3単過
「彼／彼女はそれを置いた」
```

## 過去形における語幹の変化

過去形の語尾が付く際、語幹の母音が現在形と異なる形を取る動詞もある（上表の dai- → dā- のような交替）。こうした語幹交替のパターンは動詞ごとに異なり、暗記が必要な部分である。

## 中性名詞の能格との関わり

過去形・現在形いずれの時制であっても、動詞が他動詞であり主語が中性名詞である場合には、[中性の能格](/hittite/grammar/neuter-ergative-case/)で説明した能格標示が適用されうる。時制の区別と格標示の体系は独立した文法カテゴリーであり、互いに組み合わさって文を構成する。
