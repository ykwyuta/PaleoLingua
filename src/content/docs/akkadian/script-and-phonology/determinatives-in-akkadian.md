## 限定符とは何か

限定符（デテルミナティヴ、決定符）は、それ自体は発音されない補助記号で、直前・直後に置かれた単語がどの意味カテゴリー（神・地名・木製品・職業・女性など）に属するかを読み手に示す働きを持つ。楔形文字は本来1つの記号で単語や音節を表すが、限定符だけは例外的に「読まれないラベル」として機能する。翻字では慣例として上付き文字で示す。

限定符を置く位置は、種類によって単語の前だったり後だったりする。この点も含めて、代表的な6種類の限定符を見ていこう。

## 神名の前：`d`（DINGIR）

神名の前には、神を表す限定符 `d`（元はシュメール語 dingir「神」に由来する表語文字 DINGIR）が置かれる。本サイトのマスコットキャラクターの一人、太陽神シャマシュの名前がその好例である。

<p class="cuneiform">𒀭𒌓</p>

```
dUTU
（ディンギル）ウトゥ
Šamaš「シャマシュ神（太陽神）」――dは神名限定符、UTUは「太陽」を表す表語文字
```

読むときは限定符 `d` を発音せず、単に「シャマシュ」と読む。

## 地名の後：`ki`

地名（都市名・国名など）の後には、限定符 `ki`（シュメール語 ki「土地」に由来）が置かれる。アッシリアの中心都市アッシュルの名を例に見てみよう。

<p class="cuneiform">𒀸𒋩𒆠</p>

```
aš-šurki
アッシュル（キ）
Aššur「アッシュル（都市名）」――kiは地名限定符（発音しない）
```

## 木製品の前：`giš`

木で作られた道具・家具の前には、限定符 `giš`（シュメール語で「木」を意味する表語文字 GIŠ に由来）が置かれる。「椅子」を意味する語 `kussûm` は、しばしばシュメログラム `GU.ZA`（もとはシュメール語で「膝」を意味する語に由来する椅子の表語文字）に、この限定符を添えて書かれる。

<p class="cuneiform">𒄑𒄖𒍝</p>

```
giš GU.ZA
ギシュ・グ・ザ
kussûm「椅子、玉座」――gišは木製品を示す限定符（発音しない）
```

## 職業名の前：`lu2`

人物・職業を表す語の前には、限定符 `lu2`（シュメール語で「人」を意味する表語文字 LU2 に由来）が置かれる。「鍛冶屋」を意味する `nappāḫum` は、シュメログラム `SIMUG`（「鍛冶屋」を表す表語文字）に、この限定符を添えて書かれることが多い。

<p class="cuneiform">𒇽𒌣</p>

```
lu2 SIMUG
ルー・シムグ
nappāḫum「鍛冶屋」――lu2は職業・人物を示す限定符（発音しない）
```

## 女性名・女性を表す語の前：`munus`

女性の個人名や、女性であることを示す語の前には、限定符 `munus`（シュメール語で「女性」を意味する表語文字 MUNUS/SAL に由来）が置かれる。「王」を意味する `LUGAL`（šarrum）に `munus` を添えると、「女王」を意味する語になる。

<p class="cuneiform">𒊩𒈗</p>

```
MUNUS.LUGAL
ムヌス・ルガル
šarratum「女王」――munusは女性を示す限定符（発音しない）で、LUGAL「王」に性の対立を加えている
```

これは音節綴りでは `ša-ar-ra-tum` となる。

<p class="cuneiform">𒊭𒅈𒊏𒌈</p>

```
ša-ar-ra-tum
シャ・アル・ラ・トゥム
šarratum「女王」（女性・主格・単数、-atum は女性を示す接辞）
```

## 都市名の前：`uru`

都市名の前には、限定符 `uru`（シュメール語で「都市」を意味する表語文字 URU に由来）が置かれることも多い。先ほど地名の後に `ki` を置く例で見たアッシュルは、時代や書記官の慣習によっては、代わりに（あるいは併用して）都市名の前に `uru` を置いて書かれることもある。

<p class="cuneiform">𒌷𒀸𒋩</p>

```
uru aš-šur
ウル・アッシュル
Aššur「アッシュル（都市名）」――uruは都市名を示す限定符（発音しない）
```

このように同じ都市名でも「後ろに `ki`」「前に `uru`」という2通りの書き方があり、実際にはどちらも広く用いられた。新アッシリア時代・新バビロニア時代の文書では、`uru` を前置する書き方がより一般的になる傾向がある。

## 限定符のまとめ

| 限定符 | 楔形文字 | 位置 | 分類 | 例 |
|---|---|---|---|---|
| `d`（DINGIR） | 𒀭 | 名詞の前 | 神名 | `d`UTU（Šamaš） |
| `ki` | 𒆠 | 名詞の後 | 地名 | aš-šur`ki`（Aššur） |
| `giš` | 𒄑 | 名詞の前 | 木製品 | `giš`GU.ZA（kussûm） |
| `lu2` | 𒇽 | 名詞の前 | 職業・人物 | `lu2`SIMUG（nappāḫum） |
| `munus` | 𒊩 | 名詞の前 | 女性 | `munus`.LUGAL（šarratum） |
| `uru` | 𒌷 | 名詞の前 | 都市名 | `uru`aš-šur（Aššur） |
