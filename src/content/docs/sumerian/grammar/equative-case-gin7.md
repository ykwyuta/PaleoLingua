## 等格とは何か

シュメール語には、「〜のように」「〜のごとく」という類似・比較を表す専用の格接尾辞 `-gin7` がある。日本語の「〜のように」、英語の "like ~" に相当するこの接尾辞は「等格（equative case）」と呼ばれ、[格接尾辞の一覧](/sumerian/grammar/case-suffixes-overview/)で見た10種類ほどの格の一つに数えられる。

```
𒈗𒁶
lugal-gin7
ルガル・ギン
王-等格
「王のように」
```

索引番号の `7` は発音しない。読むときは番号を無視して単に「ギン」と読めばよい（[翻字と翻読の基本ルール](/sumerian/script-and-phonology/transliteration-conventions/)を参照）。

## 神々・天体にたとえる定型比喩

シュメール語の讃歌・王碑文では、王や神の輝きや力を、太陽神ウトゥや天空神アンなどの神格・天体にたとえる `-gin7` 比喩がきわめて多く用いられる。

```
𒌓𒁶
utu-gin7
ウトゥ・ギン
ウトゥ（太陽神）-等格
「太陽神ウトゥのように（輝いて）」
```

このような比喩は、王の栄光や神殿の輝きを描写する常套句として、複数の讃歌・碑文に繰り返し現れる定型表現である。

## 名詞句全体への付加

`-gin7` は他の格接尾辞と同様、名詞句全体の末尾にただ一度だけ付く。属格句などで名詞句が長くなっても、比較の対象全体を `-gin7` でまとめて示すことができる。

| 接尾辞 | カタカナ読み | 意味 |
|---|---|---|
| `-gin7` | ギン | 〜のように、〜のごとく（類似・比較） |

## まとめ：他の格との違い

`-gin7` は、与格 `-ra`（受け手）や処格 `-a`（場所）のような文中の役割（誰が・どこで）を示す格ではなく、名詞と名詞を「たとえる」という修辞的な関係を示す点で独特である。文法的な機能というより、比喩表現を作るための専用装置と考えるとわかりやすい。
