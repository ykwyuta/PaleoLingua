Sanskrit verb forms cannot be explained simply by attaching endings directly to a stem, the way nouns work. The starting point of every verb form is the **root** (धातु dhātu) — an abstract base that never inflects on its own. A wide range of derivational affixes (pratyaya) are added to the root to build present, future, perfect, causative, passive, and other forms. This article covers the nature of the root itself and its connection to the [ten verb classes](/en/sanskrit/grammar/verb-conjugation-present-system/).

## The Dhātupāṭha (धातुपाठ) Tradition

The Dhātupāṭha is the traditional **root list** attached to Pāṇinian grammar (अष्टाध्यायी Aṣṭādhyāyī), enumerating roughly 2,000 verbal roots grouped into ten classes (गण gaṇa, discussed below). Each root is conventionally glossed with a basic present-tense meaning ("go," "see," "speak," and so on), but in actual classical usage a root's meaning can shift substantially depending on which preverb (उपसर्ग upasarga), or combination of preverbs, is prefixed to it.

For example, the root गम् gam- "to go" means simply "go" on its own, but with the preverb आ ā- prefixed, आगम् āgam- means "to come," while with अव ava- prefixed, अवगम् avagam- means "to understand" — a rather different sense entirely.

## The Basic Structure of Roots

Sanskrit verbal roots are typically **monosyllabic**, showing relatively simple consonant-vowel (C, V) combinations.

| Structure | Root | Meaning |
|---|---|---|
| CV | भू bhū- | to become, to be |
| CVC | गम् gam- | to go |
| CVC | पठ् paṭh- | to read |
| CCVC | क्रुध् krudh- | to become angry |
| CṚC | कृ kṛ- | to do, to make |

A root is an abstract unit that cannot inflect by itself; to become a usable verb form in a sentence it must always take a tense/mood-forming affix (such as a present-stem-forming suffix) plus a personal ending. This contrasts with a noun stem such as deva-, which can take case endings directly.

## The Place of Roots in Pāṇinian Grammar

Pāṇini's Aṣṭādhyāyī builds a generative-grammar-like system in which every Sanskrit word form is derived from a finite set of roots, affixes, and rules. Within that system, the root (dhātu) — alongside the roots that underlie noun stems — functions as the single most basic unit from which the entire vocabulary is generated.

- Every finite verb form (forms taking तिङ् tiṅ endings) is derived by the procedure "root + [present-stem-forming affix, etc.] + personal ending."
- Nominal derivatives (action nouns, agent nouns) and participles are likewise formed by adding specific affixes (कृत् kṛt affixes) to a root — see [Participles in Sanskrit](/en/sanskrit/grammar/participles-in-sanskrit/).
- Root-derived forms are also frequently used as constituents of compounds ([samāsa](/en/sanskrit/grammar/sanskrit-compounds-samasa/)).

In this way, roots function within Pāṇinian grammar as the "seeds" from which nearly the entire Sanskrit lexicon is generated, and the Dhātupāṭha is the foundational resource that systematically catalogues those seeds.

## How Roots Relate to the Ten Gaṇas (Present-Stem Classes)

The Dhātupāṭha groups roots according to which **gaṇa** ("class") they belong to. A gaṇa is a classification based on which affixes and stem-formation pattern a given root uses to build its present system (the stem family covering the present indicative, imperfect, imperative, optative, and so on). There are ten such classes.

| Gaṇa | Name (from a representative root) | Example |
|---|---|---|
| Class 1 | भ्वादि bhvādi (after bhū-) | भवति bhavati "becomes" |
| Class 2 | अदादि adādi (after ad-) | अत्ति atti "eats" |
| Class 3 | जुहोत्यादि juhotyādi (after juhoti) | जुहोति juhoti "offers" |
| Class 4 | दिवादि divādi (after div-) | दीव्यति dīvyati "plays" |
| Class 5 | स्वादि svādi (after su-) | सुनोति sunoti "presses out" |
| Class 6 | तुदादि tudādi (after tud-) | तुदति tudati "strikes" |
| Class 7 | रुधादि rudhādi (after rudh-) | रुणद्धि ruṇaddhi "obstructs" |
| Class 8 | तनादि tanādi (after tan-) | तनोति tanoti "extends" |
| Class 9 | क्र्यादि kryādi (after krī-) | क्रीणाति krīṇāti "buys" |
| Class 10 | चुरादि curādi (after cur-) | चोरयति corayati "steals" |

The detailed stem-formation mechanics of these ten classes — including the split between athematic classes, which add endings directly to the root, and thematic classes, which insert -a- between root and ending — are covered in [Verb Conjugation: The Present System](/en/sanskrit/grammar/verb-conjugation-present-system/).
