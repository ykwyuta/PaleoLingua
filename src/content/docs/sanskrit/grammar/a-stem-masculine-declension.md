サンスクリット語の名詞の中でも、語幹末が短母音 -a で終わる**a語幹（अ-कारान्त a-kārānta）男性名詞**は圧倒的に高頻度のクラスであり、辞書に載る名詞の中でも最大のグループを形成する。この記事では代表例 देव deva-「神」を用いて、8格×3数の全24形を示す。全体像については[名詞変化の概観](/sanskrit/grammar/noun-declension-overview/)を参照。

## deva-「神」の格変化表

| 格 | 単数 | 双数 | 複数 |
|---|---|---|---|
| 主格 | देवः devaḥ | देवौ devau | देवाः devāḥ |
| 呼格 | देव deva | देवौ devau | देवाः devāḥ |
| 対格 | देवम् devam | देवौ devau | देवान् devān |
| 具格 | देवेन devena | देवाभ्याम् devābhyām | देवैः devaiḥ |
| 与格 | देवाय devāya | देवाभ्याम् devābhyām | देवेभ्यः devebhyaḥ |
| 奪格 | देवात् devāt | देवाभ्याम् devābhyām | देवेभ्यः devebhyaḥ |
| 属格 | देवस्य devasya | देवयोः devayoḥ | देवानाम् devānām |
| 処格 | देवे deve | देवयोः devayoḥ | देवेषु deveṣu |

いくつかの規則性に注目したい。

- **双数**では具格・与格・奪格が -ābhyām に、属格・処格が -ayoḥ にそれぞれ統合されている（格の区別が数の減少とともに一部失われる現象は印欧諸語に広く見られる）。
- **複数**でも同様に、与格・奪格が -ebhyaḥ に統合されている。
- **呼格**単数 deva は語幹そのままの形であり、主格 devaḥ の語尾 -ḥ（ヴィサルガ）が取れた形になっている。
- 男性名詞と中性名詞は同じa語幹クラスに属するが、中性名詞では主格・対格・呼格が全数において同形になる（中性名詞に特有の印欧語的特徴）。

## 例文

```
देवः वदति।
devaḥ vadati.
デーヴァハ ヴァダティ
神-主格  彼が言う
「神が話す。」
```

```
अहं देवं पश्यामि।
ahaṃ devaṃ paśyāmi.
アハン デーヴァン パシュヤーミ
私は 神-対格  私は見る
「私は神を見る。」
```

```
देवेन सह गच्छामि।
devena saha gacchāmi.
デーヴェーナ サハ ガッチャーミ
神-具格 〜と共に 私は行く
「私は神と共に行く。」
```

```
देवाय पुष्पं ददामि।
devāya puṣpaṃ dadāmi.
デーヴァーヤ プシュパン ダダーミ
神-与格 花-対格 私は与える
「私は神に花を捧げる。」
```

```
गृहात् देवस्य मन्दिरं गच्छामि।
gṛhāt devasya mandiraṃ gacchāmi.
グリハート デーヴァスヤ マンディラン ガッチャーミ
家-奪格 神-属格 神殿-対格 私は行く
「私は家から神の神殿へ行く。」
```

これらの例文からも分かるように、格語尾だけで文の中の役割（主語・目的語・道具・受益者・起点・所有者）がほぼ一意に決まるため、動詞の位置や語順に依存せずに文意を組み立てることができる。この点は[サンスクリット語の語順](/sanskrit/grammar/sanskrit-syntax-word-order/)で詳述する。

## 他のa語幹男性名詞の例

a語幹男性名詞は語彙数が非常に多く、以下のような基本語彙が同じパターンで変化する。

| 語 | 意味 |
|---|---|
| नर nara- | 人、男 |
| अश्व aśva- | 馬 |
| ग्राम grāma- | 村 |
| वृक्ष vṛkṣa- | 木 |
| पुत्र putra- | 息子 |
