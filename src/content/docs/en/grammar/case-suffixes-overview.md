## Sumerian's case-marking system

Sumerian is agglutinative: it attaches case suffixes to the end of a noun phrase to mark the role that phrase plays in the clause (agent, patient, location, direction, and so on). Terminology and exact groupings vary somewhat between grammarians, but the following cases are widely recognized.

| Case | Suffix | Main function |
|---|---|---|
| Absolutive | unmarked (∅) | subject of intransitive verbs, object of transitive verbs |
| Ergative | `-e` | subject (agent) of transitive verbs |
| Genitive | `-ak` | possession/specification ("B's A") |
| Dative | `-ra` | recipient/beneficiary of an action (mainly humans and gods) |
| Locative | `-a` | location ("in/at," mainly for inanimates) |
| Locative-terminative (directive) | `-e` | direction/goal ("onto/towards" — same form as the ergative but a distinct function) |
| Terminative | `-še3` | goal or purpose ("to/until," "for the sake of") |
| Ablative-instrumental | `-ta` | source or means ("from," "by means of") |
| Comitative | `-da` | accompaniment ("together with") |
| Equative | `-gin7` | comparison/similarity ("like") |

## Where the case suffix attaches

Case suffixes attach at the very end of the noun phrase order already introduced (noun → adjective → genitive phrase → demonstrative → plural marker → case suffix). No matter how long the phrase grows, only a single case suffix attaches — to the phrase as a whole, not to each word inside it.

```
e2   lugal-ak-e
house king-GEN-ERG
"the king's house (as agent, e.g. of building something)"
```
