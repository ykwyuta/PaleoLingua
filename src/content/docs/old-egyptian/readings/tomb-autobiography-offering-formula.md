## 背景：墓壁の「自伝」と「供物定式文」

エジプトの墓壁や石碑には、しばしば2つの要素が組み合わさって記されている。一つは「自伝（オートバイオグラフィー）」と呼ばれる一人称の記述で、故人が自らの官職や功績を列挙し、生前の名声や徳を後世に伝えようとするものである。もう一つは「ḥtp-dj-nsw」（「王が与える供物」の意）と呼ばれる定型化された祈願文で、パン・ビール・牛・鳥といった供物が、死者の霊（カー、kꜣ）のために絶えず捧げられるよう願うものである。この定式文はしばしば、王に代わって実際に供物を授ける神（多くはオシリスやアヌビス）を呼びかける形をとる。

「ḥtp-dj-nsw」定式文は、エジプト碑文全体の中でも最も頻繁に現れる表現の一つであり、身分の高低を問わず、可能な限り多くの人々がこの祈願文を自らの墓に刻もうとした。

## 例：供物定式文の骨格

以下は、「ḥtp-dj-nsw」定式文の構造を示す例示的な短句であり、特定の一つの碑文からの逐語引用ではなく、この定式文に繰り返し現れる典型的な語を用いて構成したものである。

<p class="hieroglyph">𓎛𓏏𓊪 𓂧𓇋 𓈖𓋴𓅱 … 𓈖 𓎡𓄿</p>

```
ḥtp     dj      nsw     ...   n      kꜣ
ヘテプ  ディ    ネスウ  …    ン     カア
供物    与える  王      …    〜のために  カー（死者の霊）
```

「ḥtp dj nsw」は文字通り「王が与える供物」を意味し、その後には供物を受け取る死者（またはその霊カー）を示す語句が続く。ここでは、ワークシート語彙にある「nsw」（王）の音のみを写した表記（n-s-w）を用いたが、実際の碑文では多くの場合、王権を象徴する「スゲ」の記号を先頭に置く「敬称転置（honorific transposition）」という慣習に従って書かれる――発音上は最後に読まれる王の称号を、書記上は敬意を表して文頭に配置するのである（この慣習については[文字と音韻：書字方向と配置](/old-egyptian/script-and-phonology/writing-direction-orientation/)で詳しく扱う）。

## 理解度チェックの前に：定式文の意義

この定式文がこれほど頻繁に用いられた背景には、「死後も供物が絶えないこと」がエジプト人にとって極めて重要な関心事であったという事情がある。実際に毎日供物を捧げ続けることは不可能であるため、この祈願文自体が「呪文的な効力」を持ち、唱えられる（あるいは読まれる）たびに供物を代わりに供給すると信じられていた。
