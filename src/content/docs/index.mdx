## なぜAIなのか

これまで、ニッチな古代言語の解説記事を書くには、専門知識を持つ研究者の時間という「希少で高価なリソース」が欠かせませんでした。だからこそ、商業的に成り立ちにくいマイナー言語の教材は生まれにくかったのです。

PaleoLinguaは、この前提そのものを実験的に問い直します。記事の構成ルールや品質基準を1本の執筆スキルとして定義し、AIエージェント（Claude Code）に GitHub Actions 上で定期的に呼び出させることで、人手をほとんど介さずに文法解説・読解記事を生成し続けています。人件費・サーバー費をほぼ¥0に抑えながら、これまで「割に合わない」とされてきた学習コンテンツを、AIだけでどこまで持続的に拡充できるかを検証しています。

## 運営方針

- **完全無料・オープンソース**: 全記事を無料公開し、ソースは GitHub 上で誰でも閲覧できます。
- **AIによる自律執筆**: 記事は日本語・英語ペアで、AIエージェントが継続的に執筆・拡充します。
- **透明な運営プロセス**: 執筆スキルの定義から自動生成の履歴まで、すべて公開されたリポジトリ上で進行します。
