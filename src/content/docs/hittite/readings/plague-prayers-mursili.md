## 20年続いた疫病

**ムルシリ2世の疫病の祈り**は、ヒッタイト王ムルシリ2世（前14世紀後半）が、父シュッピルリウマ1世の代から続く長期の疫病の流行を鎮めるために神々に捧げた一連の祈祷文である。疫病はシュッピルリウマ1世自身の命も奪ったとされ、ムルシリはこの災厄の原因を突き止めるべく、神託（占い）を繰り返し行った。

## 神託が明かした2つの原因

祈祷文によれば、神託は疫病の原因として大きく2つの事柄を指摘したとされる。

1. **エジプトとの条約違反**：ムルシリの父シュッピルリウマ1世の時代、エジプトから連れ帰った捕虜たちが疫病を持ち込んだとされ、これがエジプトとの間に結ばれていた誓約（クルシュタマ条約）に神々の怒りを招いたと解釈された。
2. **供物の不履行**：先王トゥドハリヤがマラ川（ユーフラテス川の支流）の神に誓った供物を果たさなかったことが、神々の不興を買ったとされた。

## 「父の罪を子が負う」という構造

祈祷文の重要な特徴は、ムルシリ自身がこれらの過失を直接犯したわけではないにもかかわらず、**父祖の代の罪を自らの代に引き受けて神々に謝罪する**という構造を取っている点である。

以下は、この告白の趣旨を伝える、学習用に単純化した例文である（特定の1行の逐語引用ではなく、祈祷文に見られる告白の型を示す文である点に注意されたい）。

```
at-tar-aš-ma-mu wa-aš-túl ki-ša-at
アッタルシュママ・ワシュトゥル・キシャト
父の（属格）-しかし私に　罪　なった-3単過（中動態）
「しかし父の罪が、私の（罪）となった」

nu-mu DINGIR.MEŠ-eš ka-ru-ú-i-li-uš iš-ta-ma-aš-ker
ヌム・ディンギルメーシュ・カルーイリウシュ・イシュタマシュケル
そして私に　神々　古き　聞いてくださった-3複過
「そして、古くからの神々が私（の祈り）に耳を傾けてくださった」
```

## 個人的な信仰告白としての性格

ムルシリの疫病の祈りは、単なる公的な儀礼文書にとどまらず、王個人の苦悩や困惑がにじむ、内省的な語り口を持つ点でも研究者の注目を集めてきた。ムルシリは、なぜ罪を犯していない自分がこれほど長く苦しまねばならないのかという疑問を率直に神々にぶつけており、この率直さは、古代西アジアの宗教文学の中でも特異な、個人的な信仰の吐露として評価されている。
