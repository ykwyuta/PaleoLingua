## エジプト語の前置詞の役割

古エジプト語には格変化がなく、名詞同士や名詞と動詞の関係の多くは**前置詞**によって表される。前置詞は数が限られている一方で、それぞれ非常に多義的（ポリセミー）であり、文脈によって訳し分ける必要がある。ここでは代表的な5つの前置詞を見ていこう。

## m：もっとも頻出する前置詞

**m** は「〜の中に、〜から、〜として、〜でもって」など非常に幅広い意味を持つ、エジプト語でもっとも使用頻度の高い前置詞である。場所（「〜の中に」）、材料・手段（「〜でもって」）、様態（「〜として」）など、文脈に応じて様々な意味を担う。

## n：「〜へ、〜のために」（与格）

**n** は「〜へ、〜のために」を意味する、与格的な働きをする前置詞である。すでに[属格構文](/old-egyptian/grammar/genitive-constructions/)の記事で見たように、間接属格の属格形容詞 n(y) もこの n から派生した語である。

<p class="hieroglyph">𓈖𓆑</p>

```
n=f
ン・エフ
〜へ=彼
「彼へ、彼のために」（前置詞 n に接尾代名詞 =f が付いた形）
```

## r：「〜へ、〜に対して、〜より」（比較級にも）

**r** は「〜へ、〜に向かって、〜に対して」を意味する前置詞で、さらに「AはBよりも大きい」のような比較の構文にも使われる（英語の "than" に近い働き）。

## ḥr：「〜の上に、〜のために」（もとは「顔」）

**ḥr** は「〜の上に、〜のゆえに」を意味する前置詞で、もともとは「顔」を意味する名詞 ḥr（Table 2の D2番の記号）に由来する。「顔」を意味する語が「〜の上に」という空間的な前置詞に転じるのは、身体部位語彙が前置詞・空間表現に発展する、言語学でよく見られるパターンの一例である。

## ẖr：「〜の下に、〜を運んで」

**ẖr** は「〜の下に」を意味する前置詞で、「〜を携えて、〜を運んで」という付帯的な意味でも使われる。

## 前置詞は接尾代名詞を直接受け取る

これらの前置詞の目的語が代名詞である場合、[人称接尾代名詞](/old-egyptian/grammar/suffix-pronouns/)が前置詞に直接付く。すでに見た n=f「彼へ」のように、前置詞＋接尾代名詞という組み合わせは、エジプト語の文の中で非常に高い頻度で現れる基本パターンである。

    <p class="plc-line"><b>マアト：</b>そのとおり。あとは n=f みたいに、前置詞に接尾代名詞が直接くっつく形にも早めに慣れておくといいわね。</p>
