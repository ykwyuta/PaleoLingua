## 1つの記号、複数の読み

楔形文字を学ぶ上で避けて通れない特徴が「多音性（polyphony、ポリフォニー）」である。これは、まったく同じ1つの記号（グリフ）が、文脈に応じて複数の異なる音・単語を表すという現象を指す。[翻字の慣例](/akkadian/script-and-phonology/transliteration-conventions/)で見た `du`・`du₂`・`du₃` は「複数の異なる記号が同じ音を表す」逆方向の現象（同音異字、ホモフォニー）だったが、多音性はその裏返しにあたる。

## 実例：UDサインの複数の読み

「太陽」「日」を意味する記号として使われるUDサインは、アッカド語の楔形文字の中でも特に多くの読みを持つサインの一つである。

<p class="cuneiform">𒌓</p>

```
u4
ウ
（読み1）シュメール語由来の音節「ウ」。日・時を表す語などに用いられる
```

<p class="cuneiform">𒌓</p>

```
tu2
トゥ
（読み2）シュメール語由来の別の音節「トゥ」
```

<p class="cuneiform">𒌓</p>

```
tam
タム
（読み3）シュメール語由来のさらに別の音節「タム」
```

<p class="cuneiform">𒌓</p>

```
utu
ウトゥ
（読み4）シュメール語の太陽神・太陽を表す語（表語文字としての読み）
```

<p class="cuneiform">𒌓</p>

```
UD
（アッカド語での読み）Šamaš「シャマシュ神、太陽」――アッカド語文中での表語文字としての読み
```

まったく同じグリフ 𒌓 でありながら、これらの読みは互いに音としても言語としても異なる。本サイトのマスコットキャラクター、太陽神シャマシュの名は、まさにこのUDサインを表語文字として用いた `UD`（読みとしては `dUTU`）に由来する。

## なぜこれほど多くの読みが1つの記号に集まったのか

多音性が生じた理由は複数ある。第一に、楔形文字は数百年から千年以上にわたり、シュメール語という孤立言語と、アッカド語というセム語族の言語という、文法構造も音韻体系も大きく異なる2つの言語を書き表すために使われ続けた。ある記号がシュメール語の複数の同義語・類義語（例えば「日」「太陽」「白い」に関わる複数のシュメール語）を表す表語文字として使われるようになると、その記号は自動的にそれらすべての語の音を「読み」として引き継ぐことになる。第二に、字形の簡略化・統合の過程で、もともと別々だった複数の絵文字が偶然同じ形に収斂した場合もある。第三に、アッカド語話者はシュメール語の表語文字をアッカド語の対応語（この場合は「太陽」を意味する `šamšu`/`Šamaš`）の読みとしても流用したため、シュメール語由来の音節的な読みに加えて、アッカド語の意味に基づく新しい読みまでもが同じ記号に加わることになった。

## 読み手はどうやって区別するのか

同じ記号が複数の読みを持つ以上、読み手は文脈だけを頼りに正しい読みを選ばなければならない。手がかりとなるのは、その記号が単独で単語として使われているか、他の記号と組み合わさって音節綴りの一部として使われているか、前後にどんな限定符や音声補語が付いているか、そして何より、その文書がどのような種類の文章（行政文書か、文学作品か、神々への祈願文か）であるかといった総合的な判断である。

なお、多音性そのものは下付きの索引番号では解決できない。索引番号はあくまで「同じ音を表す複数の異なる記号」（同音異字）を区別するための道具であり、「同じ記号が持つ複数の異なる音」（多音性）を区別するものではない。多音性を解消できるのは文脈だけである。

## 同音異字との違い

| 現象 | 方向性 | 例 |
|---|---|---|
| 同音異字（homophony） | 複数の記号 → 同じ音 | `du` 𒁺・`du₂` 𒌅・`du₃` 𒆕（いずれも「ドゥ」） |
| 多音性（polyphony） | 1つの記号 → 複数の音 | 𒌓（`u4`・`tu2`・`tam`・`utu`・アッカド語で`šamaš`） |

この2つの現象は方向がちょうど逆でありながら、どちらも「楔形文字の記号と音は必ずしも1対1に対応しない」という、この文字体系の本質的な特徴を示している。
