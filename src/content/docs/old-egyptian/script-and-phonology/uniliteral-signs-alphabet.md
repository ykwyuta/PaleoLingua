## エジプト語の「アルファベット」

ヒエログリフには数百種類の記号があるが、その中に24個だけ、**1つの子音だけを表す表音文字（単子音記号、uniliteral sign）**がある。これらは実際の古代エジプトでは正式な「アルファベット」として単独で教えられていたわけではないが、現代のエジプト語学習では便宜上「エジプトのアルファベット」と呼ばれ、最初に習得すべき基礎となる。単子音記号だけで（多少不自然ではあっても）どんな単語も理論上は綴ることができる。

## 24の単子音記号

下の表は、グリフ・ガーディナー番号（記号を分類するための標準的な番号体系）・翻字（ローマ字転写）・その記号が元々何を描いた絵かを示す。翻字に使われる ꜣ・ꜥ・ḥ・ḫ・ẖ・š・ṯ・ḏ などの特殊記号については「[翻字の規則](/old-egyptian/script-and-phonology/transliteration-conventions/)」で詳しく扱う。

| ヒエログリフ | ガーディナー番号 | 翻字 | 元の絵 |
|---|---|---|---|
| 𓄿 | G1 | ꜣ | ハゲワシ |
| 𓇋 | M17 | j | 葦（アシ） |
| 𓇌 | M17A | y（j の異形） | 葦2本 |
| 𓏭 | Z4 | y / ï | 斜線2本（双数マーカーとしても使用） |
| 𓂝 | D36 | ꜥ | 前腕 |
| 𓅱 | G43 | w | ウズラのひな |
| 𓃀 | D58 | b | 下脚部（足） |
| 𓊪 | Q3 | p | 腰掛け／葦の敷物 |
| 𓆑 | I9 | f | 角のあるヘビ（ツノクサリヘビ） |
| 𓅓 | G17 | m | フクロウ |
| 𓈖 | N35 | n | 水面の波紋 |
| 𓂋 | D21 | r | 人の口 |
| 𓉔 | O4 | h | 葦で編んだ小屋 |
| 𓎛 | V28 | ḥ | よじれた芯（灯心） |
| 𓐍 | Aa1 | ḫ | 篩（ふるい）または胎盤 |
| 𓄡 | F32 | ẖ | 動物の腹と尾 |
| 𓊃 | O34 | z / s | 扉のかんぬき |
| 𓋴 | S29 | s / ś | 折りたたんだ布 |
| 𓈙 | N37 | š | 庭園の池 |
| 𓈎 | N29 | q | 丘の斜面 |
| 𓎡 | V31 | k | 取っ手付きのかご |
| 𓎼 | W11 | g | 壺の台 |
| 𓏏 | X1 | t | パンの塊 |
| 𓍿 | V13 | ṯ | 動物をつなぐ綱 |
| 𓂧 | D46 | d | 手 |
| 𓆓 | I10 | ḏ | コブラ |

このように、日本語のローマ字表のような1対1対応の「アルファベット」というより、それぞれの記号が元は何かを描いた絵から出発している点に注意したい。中には z/s のように同じ子音に複数の記号が使われる例（𓊃 と 𓋴）や、j に対して複数の異形（𓇋 と 𓇌）がある例も含まれる。

## 単子音記号だけで単語を綴る

単子音記号だけを並べれば、原則としてどんな単語でも音だけを綴ることができる（実際の碑文では、表語文字や二・三子音記号を使う方が一般的な場合も多い）。

<p class="hieroglyph">𓂋𓈖</p>

```
rn
レン
名前
```

<p class="hieroglyph">𓊪𓂋</p>

```
pr
ペル
家
```

このカタカナ読みは現代エジプト学の慣習的な発音の目安であり、古代の実際の発音を厳密に再現したものではない点に注意されたい（子音と子音のあいだに便宜上「エ」の音を挟んでいる）。
