## エジプト学翻字とは

翻字（transliteration）とは、ヒエログリフの各記号が表す子音を、ラテン文字（およびいくつかの特殊記号）に置き換えて示したものである。「[単子音記号：ヒエログリフの「アルファベット」24字](/old-egyptian/script-and-phonology/uniliteral-signs-alphabet/)」で見た24字は、そのままエジプト学翻字で使われる文字の集合と一致する。

## エジプト学翻字のアルファベット

| 翻字文字 | 発音の目安（慣習的） |
|---|---|
| ꜣ | アレフに似た音（通説では声門閉鎖音的または声門摩擦音的な子音） |
| ꜥ | アイン（通説では咽頭音的な子音） |
| j | イ |
| y | イ（ꜣ ꜥ と同様に半母音的な役割も担う） |
| w | ウ |
| b | ブ行 |
| p | プ行 |
| f | フ行 |
| m | ム行 |
| n | ン、ヌ行 |
| r | ル行 |
| h | ハ行（無声声門摩擦音） |
| ḥ | ハ行（強い無声咽頭摩擦音） |
| ḫ | ハ行（無声軟口蓋・口蓋垂摩擦音） |
| ẖ | ハ行（無声硬口蓋摩擦音） |
| z / s | サ行 |
| š | シャ行 |
| q | カ行（口蓋垂音） |
| k | カ行（軟口蓋音） |
| g | ガ行 |
| t | タ行 |
| ṯ | チャ行 |
| d | ダ行 |
| ḏ | ヂャ行 |

これらの記号のうち、ḥ・ḫ・ẖ のように「ハ行」に分類される音が複数ある点や、q・k・g のようにいずれも「カ・ガ行」に近い音が複数ある点に注意したい。これは、エジプト語が現代の日本語や英語よりも多くの子音の区別（特に喉の奥で調音される音）を持っていたためである。

## 翻字には母音が存在しない

上の表を見て気づく重要な点は、**母音を表す文字が一切含まれていない**ことである。これは「[ヒエログリフとは何か](/old-egyptian/script-and-phonology/hieroglyphic-writing-system/)」で説明したとおり、ヒエログリフの表音文字が子音（と半母音）しか書き表さないためである。したがって翻字もまた、原則として子音の並びのみを示すものであり、実際にどのような母音で発音されていたかは翻字だけからは分からない。この点については「[古エジプト語の子音体系と再建音価](/old-egyptian/script-and-phonology/egyptian-consonant-phonology/)」で詳しく扱う。

## マヌエル・ド・コダージュ（MdC）：デジタル入力用の表記法

ꜣ・ꜥ・ḥ・ḫ・ẖ・š・ṯ・ḏ のような特殊記号は、通常のキーボードでは直接入力できない。そこでエジプト学の分野では、コンピュータ上でヒエログリフのテキストを扱うために、**マヌエル・ド・コダージュ（Manuel de Codage、通称MdC）**と呼ばれるASCII文字だけで翻字を表現する取り決めが1980年代に定められ、広く使われている。たとえば、ꜣ を数字の `3`、ꜥ を `o`、ḥ を大文字 `H`、ḫ を大文字 `X` のように、特殊記号を通常のアルファベットや数字に置き換えて表記する。この方式のおかげで、専門的なフォントやUnicode入力環境がなくても、研究者同士がメールやデータベース上でエジプト語の翻字を正確にやり取りできるようになった。現在では多くのヒエログリフ入力ソフトウェアやオンライン辞書がMdC形式の入力を受け付けている。
